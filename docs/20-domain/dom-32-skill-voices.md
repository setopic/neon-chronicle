# スキルの声

## 定義

スキルの声は、[スキル](./dom-03-jobs-and-skills.md)が主人公の頭の中で話す1行の文である。[イベント](./dom-06-events.md)に、スキルの選ぶ条件を持つ選択肢があるときだけ話す。条件を満たしていればその選択肢を勧め、満たしていなければ、いまの腕では足りないとからかう。

声が話すのは、いまの体で積んだ腕前から見えることだけである。前の周の行いや記憶には触れない。前の周を主人公に返すのは、街の人々が話す[前の周の跡](./dom-27-traces-of-last-life.md)と、前の周の自分が戻ってくる[記憶の断片](./dom-08-memory-fragments-and-endings.md)の役目である。

## 属性

文は`game/lang/*.json`にある。ほかのノードの概念に、次の属性を足す。

| 対象 | 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| 選択肢 | 勧める声 | 文 | スキルの選ぶ条件を持つ選択肢では○ | 条件を満たしているときに、その条件のスキルが話す文 |
| スキル | からかう声 | 文 | ○ | そのスキルを条件に持つ選択肢の条件を、満たしていないときに話す文。どの選択肢でも同じ文を使う |

声の主の名前は、スキルの名前をそのまま使う。3つの声は、次のように書き分ける。

| スキル | 話し方 |
| --- | --- |
| ハッキング | 短く冷たい。数字と手順で話す |
| 格闘 | 荒っぽい命令形。体の感覚で話す |
| 交渉 | 軽口。相手の弱みと値段を見て話す |

## 不変条件

- [ ] 声は、スキルの選ぶ条件を持つ選択肢ごとに1行だけ話す。評判だけを条件に持つ選択肢では話さない
- [ ] 選ぶ条件に複数のスキルがあるときは、最初に挙げたスキルが話す
- [ ] 声は、前の周の行いや記憶に触れない
- [ ] 勧める声は、選んだ結果の中身を先に明かさない

## ライフサイクル

イベントが待っているイベントになると、スキルの選ぶ条件を持つ選択肢ごとに、声が1行ずつ出る。待っている間にスキルのレベルが上がって条件を満たすと、からかう声は勧める声に替わる。選択肢を選ぶと、声も消える。声はログには残らない。

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| スキルの声 | スキルが主人公の頭の中で話す1行の文。スキルの選ぶ条件を持つ選択肢のあるイベントでだけ話す | |
| 勧める声 | 選ぶ条件を満たしている選択肢について、スキルの声がその選択肢を勧める文 | |
| からかう声 | 選ぶ条件を満たしていない選択肢について、スキルの声がいまの腕では足りないと言う文 | |
