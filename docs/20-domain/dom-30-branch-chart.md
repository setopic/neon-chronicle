# 分岐図

## 定義

分岐図は、周をまたいで進む話の段と、エンディングを、選択肢ごとに並べた図である。どの選択肢を選んだか、どの選択肢がどの先の選択肢を開くかが分かる。読むだけで、ゲームの状態は変えない。

## 属性

分岐図は、データから組み立てるので、自分の値を持たない。

| 行 | 何を並べるか |
| --- | --- |
| 話ごとに1行 | 人物のイベント・勢力の話のイベント・元の持ち主の話のイベントを、話ごとに段の順で並べる |
| 最後の1行 | 最後の仕事のイベント「中枢の扉」と、そのエンディングの選択肢 |

段は箱で描き、箱の中に選択肢を並べる。前の選択の条件と話の条件は、条件の側の選択肢から、開く側の選択肢へ線で結ぶ。

| 状態 | 描き方 |
| --- | --- |
| 選択肢を選んだ段 | 段の名前と選択肢の名前を出し、選んだ選択肢の印を塗る |
| まだ選択肢を選んでいない段 | 段の名前と選択肢の名前を「？？？」にする |
| エンディングの行 | どれかのエンディングにたどり着くまで「？？？」にし、たどり着いたエンディングの印を塗る |

## 不変条件

- [ ] まだ選択肢を選んでいない段の名前と選択肢は、分岐図に出ない
- [ ] 分岐図を開いても、ゲームの状態は変わらない

## ライフサイクル

1. 最初の周から、街と人物の画面のタブで分岐図を開ける。どの段も「？？？」である
2. 話の段で選択肢を選ぶと、その段の名前と選択肢が出て、選んだ選択肢の印が塗られる
3. エンディングにたどり着くと、エンディングの行が出る
4. 最初からやり直すと、話の進み具合とクロニクルが無くなるので、分岐図も最初の状態に戻る
