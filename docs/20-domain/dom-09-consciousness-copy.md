# 意識の写しと目覚め

## 定義

[主人公](./dom-01-world.md)が周ごとに新しい[体](./dom-02-life-and-body.md)で目覚める仕組みを、世界の中で説明するものである。[ヨミ・システムズ](./dom-01-world.md)の研究部門は、抜き取った意識の写しを[中枢サーバー](./dom-08-memory-fragments-and-endings.md)に保管し、体が倒れるたびに新しい体へ読み込み直している。これが反復計画である。

ふつうの被験体は、ヨミ・システムズの施設で目覚めて、その命令で働く。主人公の意識の写しは、読み込み先が書き換えられていて、裏通りの診療所で目覚める。そのため主人公は、ヨミ・システムズの命令を受けずに、どの[仕事](./dom-03-jobs-and-skills.md)にも就ける。読み込み先を書き換えた人物は、[DOM-10](./dom-10-characters.md)が決めている。

読み込み先を書き換えたとき、主人公の意識の写しは、反復計画の記録の上で、壊れて廃棄した写しにされた。ヨミ・システムズの装置は、廃棄の領域にある写しを監視しない。主人公の記憶も、同期のたびに廃棄の領域の写しへ送られる。そのため研究部門は、何周たっても主人公に気づかない。気づき始めるのは、[記憶の断片](./dom-08-memory-fragments-and-endings.md)「計画書」が戻ってからである。計画の中身を含む記憶が廃棄の領域へ送られ、それを見つけた研究部門が、読み込み先を辿り始める。

主人公の顔と体は、周ごとに替わる。そのため、顔を見て主人公だと分かる者はいない。前の周に主人公と関わった者が、話し方や仕事の手口から、同じ人ではないかと疑うことはある。前の周の主人公を確かに覚えている者は、DOM-10が決めている。

## 属性

ゲームの仕組みは、世界の中で次のように説明する。どれも新しい数値は持たず、すでにある仕組みの理由だけを決める。

| 仕組み | 世界の中での説明 |
| --- | --- |
| 新しい体で目覚める（[DOM-05](./dom-05-rebirth.md)の転生） | 体が倒れると、ヨミ・システムズの装置が意識の写しを新しい体へ読み込む |
| [記憶ポイント](./dom-05-rebirth.md) | 周が終わる瞬間の同期で、意識の写しへ送り返せた記憶の量 |
| [永続強化](./dom-05-rebirth.md) | 同期で残った記憶を使って、意識の写しを改良すること |
| スキルが[開始レベル](./dom-03-jobs-and-skills.md)に戻る | 腕前のうち、知っていることと手順は意識の写しに残る。手の速さは体の神経に焼き付いたもので、体と一緒に失われる。スキルのレベルは、この神経の慣れの度合いである |
| [クレジット](./dom-03-jobs-and-skills.md)が0に戻る | 体ごとに身元が新しくなる。前の身元の口座は体に結びつけて登録してあるので、体が倒れると凍結される |
| 前の体と、その体のインプラントが戻らない | 倒れた体は、倒れた場所に残される。体と[インプラント](./dom-04-implants.md)は拾った者が闇市場へ売り、裏通りの診療所には戻らない |
| [残るインプラント](./dom-04-implants.md)が残る | 体ではなく、稼ぎを受け取る裏通りの診療所の口座の取引記録に組み込むものだから |
| [記憶の断片](./dom-08-memory-fragments-and-endings.md)が戻る | 意識を抜き取られる前の記憶は、写しの奥に壊れたまま残っている。腕前が当時に近づくと、同期のときにつながって戻る |

永続強化ごとの説明は次のとおりである。

| 永続強化 | 世界の中での説明 |
| --- | --- |
| 記憶の残響 | 前の体で覚えた動きの型を、学習の手本として意識の写しに残す |
| 闇市場のコネ | 連絡先と取引の手口を、意識の写しの中に覚えておく |
| 才能の継承 | 腕前の型を、次の体の神経へ読み込む手順として意識の写しに持たせる |
| 侵入の型・格闘の型・交渉の型 | 1つの腕前の動きを、意識の写しに深く刻む |
| 深層の保管 | 同期で失われる記憶の一部を、深い層に退けておく |
| 前金の段取り | 目覚めてすぐ受けられる仕事の手配を覚えておき、その前金を受け取る |
| 値切りの手口 | 闇市場の相場と値切り方を、意識の写しの中に覚えておく |

永続強化は、どれも意識の写しの改良であり、体の劣化は変えない。

次の仕組みは、遊ぶ人の側の仕組みとし、世界の中では説明しない。どれも、物語の外で遊び方を選ぶためのものである。

| 仕組み | 扱い |
| --- | --- |
| エンディングのあとも転生して遊び続けられること（[DOM-08](./dom-08-memory-fragments-and-endings.md)） | 本当の体に戻っても、全員が目覚めても、次の周は使い捨ての体で目覚める。その理由は世界の中で決めない |
| [縛りの上乗せ](./dom-21-challenges.md) | 縛りを守り通した周に記憶ポイントが増える理由は、世界の中で決めない |
| [話の選び直し](./dom-31-choosing-again.md) | すでに選んだ選択をやり直せる理由は、世界の中で決めない |

## 不変条件

- [ ] 意識の写しは1つである。同じ主人公が、2つの体で同時に目覚めることはない
- [ ] 意識を抜き取った体は、眠ったまま目覚めない。目覚めるのは、意識の写しを読み込んだ体だけである
- [ ] 同期で送り返せるのは記憶だけである。体・腕前・身元は送り返せない
- [ ] 主人公が目覚めるのは、いつも裏通りの診療所である

## ライフサイクル

1. 体が倒れる瞬間に、その周の記憶を意識の写しへ同期する。残った量が記憶ポイントになる
2. 残った記憶で、意識の写しを改良する（永続強化）
3. ヨミ・システムズの装置が、意識の写しを新しい体へ読み込む。書き換えられた読み込み先のとおり、裏通りの診療所で目覚める

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 意識の写し | ヨミ・システムズの中枢サーバーに保管されている、主人公の意識のデータ。体が倒れるたびに、新しい体へ読み込まれる | |
| 反復計画 | ヨミ・システムズの研究部門が動かしている計画。抜き取った意識を使い捨ての体に入れて汚れ仕事をさせ、体が倒れたら意識の写しを新しい体へ読み込み直す | |
| 被験体 | 反復計画に意識を使われている人。主人公もその1人である | |
| 意識を抜き取る | 人の意識の写しを取ったうえで、その人の体の側の意識を眠らせて止めること。体は眠ったまま残り、眠った体から写しを取り直すと、抜き取ったときの状態の写しになる。データを盗み出す意味の「抜き取る」（被験体の名簿を抜き取るなど）とは別である | |
| 同期 | 体が倒れる瞬間に、その周の記憶を意識の写しへ送り返すこと。すべては送り返せず、残った量が記憶ポイントになる | |
| 廃棄の領域 | 中枢サーバーのうち、壊れて廃棄した意識の写しを置く場所。ヨミ・システムズの装置は、ここにある写しを監視しない。主人公の意識の写しはここにある | |
| 裏通りの診療所 | 主人公が毎周目覚める場所。ヨミ・システムズの施設の外にある | |
