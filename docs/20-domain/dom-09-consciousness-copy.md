# 意識の写しと目覚め

## 定義

[主人公](./dom-01-world.md)が周ごとに新しい[体](./dom-02-life-and-body.md)で目覚める仕組みを、世界の中で説明するものである。[企業](./dom-01-world.md)の研究部門は、抜き取った意識の写しを[中枢サーバー](./dom-08-memory-fragments-and-endings.md)に保管し、体が倒れるたびに新しい体へ読み込み直している。これが反復計画である。

ふつうの被験体は、企業の施設で目覚めて企業の命令で働く。主人公の意識の写しは、読み込み先が書き換えられていて、裏通りの診療所で目覚める。そのため主人公は、企業の命令を受けずに、どの[仕事](./dom-03-jobs-and-skills.md)にも就ける。読み込み先を書き換えた人物は、[DOM-10](./dom-10-characters.md)が決めている。

## 属性

ゲームの仕組みは、世界の中で次のように説明する。どれも新しい数値は持たず、すでにある仕組みの理由だけを決める。

| 仕組み | 世界の中での説明 |
| --- | --- |
| 新しい体で目覚める（[DOM-05](./dom-05-rebirth.md)の転生） | 体が倒れると、企業の装置が意識の写しを新しい体へ読み込む |
| [記憶ポイント](./dom-05-rebirth.md) | 周が終わる瞬間の同期で、意識の写しへ送り返せた記憶の量 |
| [永続強化](./dom-05-rebirth.md) | 同期で残った記憶を使って、次の目覚めを調整すること |
| スキルが[開始レベル](./dom-03-jobs-and-skills.md)に戻る | 腕前は体の神経に焼き付いたもので、体と一緒に失われる |
| [クレジット](./dom-03-jobs-and-skills.md)が0に戻る | 体ごとに身元が新しくなり、前の身元の口座は企業に凍結される |
| [残るインプラント](./dom-04-implants.md)が残る | 体ではなく、ネット上の身元に組み込むものだから |
| [記憶の断片](./dom-08-memory-fragments-and-endings.md)が戻る | 意識を抜き取られる前の記憶は、写しの奥に壊れたまま残っている。腕前が当時に近づくと、同期のときにつながって戻る |

永続強化ごとの説明は次のとおりである。

| 永続強化 | 世界の中での説明 |
| --- | --- |
| 記憶の残響 | 前の体で覚えた動きを、次の体に思い出させる |
| 闇市場のコネ | 覚えている連絡先を、次の体からも使う |
| 頑丈な義体 | 倒れ方の記録から、次の体を丈夫なものに選ぶ |
| 才能の継承 | 腕前の型を、次の体の神経へ先に焼き付ける |

## 不変条件

- [ ] 意識の写しは1つである。同じ主人公が、2つの体で同時に目覚めることはない
- [ ] 同期で送り返せるのは記憶だけである。体・腕前・身元は送り返せない
- [ ] 主人公が目覚めるのは、いつも裏通りの診療所である

## ライフサイクル

1. 体が倒れる瞬間に、その周の記憶を意識の写しへ同期する。残った量が記憶ポイントになる
2. 残った記憶で、次の目覚めを調整する（永続強化）
3. 企業の装置が、意識の写しを新しい体へ読み込む。書き換えられた読み込み先のとおり、裏通りの診療所で目覚める

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 意識の写し | 企業の中枢サーバーに保管されている、主人公の意識のデータ。体が倒れるたびに、新しい体へ読み込まれる | |
| 反復計画 | 企業の研究部門が動かしている計画。抜き取った意識を使い捨ての体に入れて汚れ仕事をさせ、体が倒れたら意識の写しを新しい体へ読み込み直す | |
| 被験体 | 反復計画に意識を使われている人。主人公もその1人である | |
| 同期 | 体が倒れる瞬間に、その周の記憶を意識の写しへ送り返すこと。すべては送り返せず、残った量が記憶ポイントになる | |
| 裏通りの診療所 | 主人公が毎周目覚める場所。企業の施設の外にある | |
