# クロニクルの物語

## 定義

物語文は、[クロニクル](./dom-05-rebirth.md)の記録を「路地裏の運び屋として生き、怪しい荷物の中身を確かめて報酬をつり上げ、裏切った仲間に撃たれて倒れた。」のような1文にしたものである。その周の主な仕事・最後に選んだ選択肢・倒れた理由の3つから組み立てる。クロニクルに残った選択肢の種類が増えるほど、経験の効果が増える。

## 属性

記録は、[DOM-05](./dom-05-rebirth.md)の属性のほかに、次の属性を持つ。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| 最後に選んだ選択肢 | イベントのidと選択肢のidの組 | | その周で最後に選んだ選択肢。周を終わらせた選択肢は入れない。選ばなかった周は空 |
| 倒れた理由 | イベントのid | | 選択肢の結果で耐久が0になったときの、そのイベント。劣化で耐久が0になったときは空 |

周ごとの状態として、最後に選んだ選択肢を持つ。周の始まりは空である。

表示文は、仕事ごとの句と選択肢ごとの句を言語ファイルに持つ。記録はidだけを持ち、物語文は表示するたびに、いまの言語で組み立てる。

次の値は属性ではなく導出値である。

```
物語文 = 主な仕事の句 ＋ 最後に選んだ選択肢の句 ＋ 倒れた理由の句
倒れた理由の句 = 倒れた理由が空なら「体の限界で倒れた」、そうでなければ、そのイベントの倒れたときの句（「企業の私兵の待ち伏せに遭って倒れた」）
記録に残った選択肢 = クロニクルの記録にある、最後に選んだ選択肢の種類の数
記録に残った選択肢による経験の効果 = 0.02 × 記録に残った選択肢
```

主な仕事が空の周は、仕事の句を「仕事に就かずに生き」にする。最後に選んだ選択肢が空の周は、その句を省く。エンディングにたどり着いた周の句は、[DOM-08](./dom-08-memory-fragments-and-endings.md)が決めている。

## 不変条件

- [ ] 周が終わって増えた記録は、その周の物語文を持つ
- [ ] 物語文は、どの言語でも同じ記録から組み立てる。言語を切り替えると、過去の記録も切り替えた言語で読める
- [ ] 同じ選択肢が何度クロニクルに残っても、記録に残った選択肢には1つとして数える
- [ ] いまのデータに無いイベントや選択肢は、記録に残った選択肢に数えない

## ライフサイクル

1. 周の始まりに、最後に選んだ選択肢は空になる
2. 選択肢を選び、その結果で周が終わらなかったら、それが最後に選んだ選択肢になる
3. 周が終わると、最後に選んだ選択肢と倒れた理由が記録に入る
4. 記録が増えると、記録に残った選択肢による経験の効果が、次の周から働く

この2つの属性を持たない古い記録（この仕組みより前に終わった周）は、最後に選んだ選択肢も倒れた理由も空として読む。

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 物語文 | 記録を1文にしたもの。主な仕事・最後に選んだ選択肢・倒れた理由から組み立てる | |
| 最後に選んだ選択肢 | その周で最後に選んだ[選択肢](./dom-06-events.md)。周を終わらせた選択肢は入れない | |
| 倒れた理由 | 耐久が0になって周が終わった原因。選択肢の結果で0になったときはそのイベントで、劣化で0になったときは空 | |
| 記録に残った選択肢 | クロニクルの記録にある、最後に選んだ選択肢の種類の数。経験の効果を増やす | |
