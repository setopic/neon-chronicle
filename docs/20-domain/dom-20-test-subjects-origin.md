# 被験体の出どころ

## 定義

[反復計画](./dom-09-consciousness-copy.md)の[被験体](./dom-09-consciousness-copy.md)が、どこから、どうやって集められたかである。抜き取ったあとの本当の体と、意識を読み込む使い捨ての体の出どころも、ここに書く。どれも文だけで、ゲームの数値は持たない。

## 属性

被験体は、下層街で腕を持ち、借金を返せなくなった者から集める。

| 段階 | 誰が | 何をするか |
| --- | --- | --- |
| 選ぶ | ヨミ・システムズの研究部門 | 汚れ仕事に使える腕を持つ者を選ぶ。ハッカー・傭兵・運び屋が多い |
| 借金を買う | ヨミ・システムズの研究部門 | 身元を隠して[闇市場](./dom-15-city-places-and-powers.md)に出入りし、選んだ者の借金を[ザンダー・ファミリー](./dom-15-city-places-and-powers.md)から買い取る |
| 契約させる | ザンダー・ファミリー | 借金を消す代わりに、ヨミ・システムズの研究に体を差し出す契約書に、本人を署名させる |
| 抜き取る | ヨミ・システムズの研究部門 | 署名した者を自社の施設へ運び、意識を[抜き取る](./dom-09-consciousness-copy.md) |

[社の身元](./dom-18-resident-classes.md)を持つ者は、被験体にしない。社の身元を持つ者がいなくなれば、属する企業が探すからである。

[主人公](./dom-01-world.md)も[レイ](./dom-10-characters.md)も、借金を返せなくなった下層街のハッカーで、この契約書に署名して被験体になった。

意識を抜き取った被験体の体は、[中枢サーバー](./dom-08-memory-fragments-and-endings.md)の奥で、眠ったまま保存する。意識の写しが壊れたときに、その体から抜き取り直すためである。抜き取り直した写しは、最初に抜き取ったときの状態に戻り、それより後の記憶を持たない。主人公の[本当の体](./dom-08-memory-fragments-and-endings.md)も、その1つである。

ふつうの被験体は、ヨミ・システムズの施設で目覚めるたびに、前の周の記憶を封じられる。命令に逆らう理由を持たせないためである。レイは、ハッカーの腕で自分の封じを内側から外したので、前の周を覚えている。主人公は、[ミオ](./dom-10-characters.md)が書き換えた読み込み先で目覚めるので、記憶を封じられない。

意識を読み込む使い捨ての体は、闇市場で買った[体の部品](./dom-19-resident-life-course.md)を組み立てて作る。下層街の死者から取り出した部品の寄せ集めなので、体は早く劣化する。

| 目覚める者 | 体を組み立てる者 | 組み立てる場所 |
| --- | --- | --- |
| ふつうの被験体 | ヨミ・システムズの研究部門 | ヨミ・システムズの施設 |
| 主人公 | ミオ | 裏通りの診療所 |

ミオは、白い部屋の技師だったときに覚えた手順で、主人公の体を組み立てる。[体の種類](./dom-11-body-types.md)は、組み立てに使う部品で分かれる。作業用の体と戦闘用の体は、それぞれの仕事に向いた部品で組み立てる。試作の体は、ミオが新しい組み合わせを試したものである。部品の代金には、主人公の稼ぎから残した[手数料](./dom-11-body-types.md)を使う。闇医者は体の部品を買うのがふつうなので、ミオが部品を買っても、ヨミ・システムズは気づかない。研究部門が主人公に気づかないのは、主人公の意識の写しが廃棄の領域にあるからである（[DOM-09](./dom-09-consciousness-copy.md)）。

## 不変条件

- [ ] 被験体は、借金を消す契約書に署名した下層街の住人である
- [ ] 社の身元を持つ者は、被験体にならない
- [ ] 被験体の本当の体は、中枢サーバーの奥で眠ったまま保存されている
- [ ] 前の周を覚えている被験体は、主人公とレイだけである

## ライフサイクル

1. ヨミ・システムズの研究部門が、腕を持つ下層街の住人を選び、その借金をザンダー・ファミリーから買い取る
2. ザンダー・ファミリーが、借金を消す契約書に本人を署名させる
3. ヨミ・システムズの施設で意識を抜き取り、本当の体を中枢サーバーの奥に保存する
4. 意識の写しを、闇市場の部品で組み立てた使い捨ての体へ読み込む。ふつうの被験体は、前の周の記憶を封じられて施設で目覚める
5. 体が倒れると、新しく組み立てた体へ読み込み直す

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 被験体の契約書 | 借金を消す代わりに、ヨミ・システムズの研究に体を差し出すという契約書。ザンダー・ファミリーが本人に署名させる | |
| 記憶の封じ | ヨミ・システムズが、ふつうの被験体の目覚めのたびに、前の周の記憶を思い出せなくすること | |
| 使い捨ての体 | 被験体の意識の写しを読み込む体。闇市場の体の部品を組み立てて作るので、早く劣化する | |
