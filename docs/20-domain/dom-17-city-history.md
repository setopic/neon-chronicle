# 街の歴史

## 定義

[企業](./dom-01-world.md)が[ネオン・シティ](./dom-01-world.md)を分け合って支配するより前に、街が何で、どうして今の形になったかである。[橋](./dom-15-city-places-and-powers.md)の呼び名、橋がどの社の持ち物でもないこと、[下層街](./dom-15-city-places-and-powers.md)の住まいに家主がいないことの理由を、ここで決める。どれも文だけで、ゲームの数値は持たない。

## 属性

街の歴史は、次の2つの時代に分かれる。

| 時代 | 街を治めていたもの | どんな街だったか |
| --- | --- | --- |
| 市の時代 | 市議会と市役所 | 市は高台にあった。崖の下は、川沿いの湿った低い土地だった。発電所・浄水場・路面電車・橋は、市のものだった |
| 企業の時代 | 企業の各社 | いまの街である。[DOM-15](./dom-15-city-places-and-powers.md)が決めている |

市の時代に、市は川をまっすぐにして排水路にし、低い土地を乾かした。乾いた低い土地には、市が工場で働く人のための住宅を建てた。高台と低い土地を行き来するために、市は排水路をまたぐ橋を架けた。崖と川は、橋よりも前からあった。

3本の橋は、市の技師が架けた。架けた順と、架けた人は次のとおりである。

| 架けた順 | 橋 | 架けた人 |
| --- | --- | --- |
| 1 | オルセン橋 | オルセン。市の技師で、ヴィラールとハーゲンの師匠 |
| 2 | ヴィラール橋 | ヴィラール。オルセンの弟子で、師匠の図面を引き継いで架けた |
| 3 | ハーゲン橋 | ハーゲン。オルセンの弟子で、師匠の図面を引き継いで架けた |

市の人々は、架けた技師の名前で橋を呼んだ。橋のたもとには、架けた人の名前を刻んだ銘板が、いまも残っている。

市は、借金を返せなくなって財政破綻した。返すために、市は発電所をヨミ・システムズへ、浄水場をリンドホルム食品へ売り、高台の土地を企業の各社へ売り払った。これが企業の時代の始まりである。市役所は無くなり、市議会も開かれなくなった。売り払ったものと、残ったものは次のとおりである。

| 市のもの | 企業の時代にどうなったか |
| --- | --- |
| 発電所 | ヨミ・システムズが買った |
| 浄水場 | リンドホルム食品が買った |
| 高台の土地 | 企業の各社が買い、縄張りになった |
| 路面電車 | 買い手が付かず、止まった。街に公共の交通が無いのはこのためである |
| 橋 | 手入れに金がかかるので、どの社も買わなかった。持ち主がいないまま残り、各社が出し合った金で、モンフォール警備が見張っている |
| 低い土地の住宅 | 市が無くなって家主がいなくなり、手入れされずに崩れた。住人は、その跡に小屋やコンテナを積み上げて住んでいる |

低い土地に残った人々は、どの企業にも雇われず、下層街の住人になった。

## 不変条件

- [ ] 企業の時代より前の街を治めていたのは、市議会と市役所だけである。企業ではない
- [ ] 橋は、市が無くなってから、どの社にも売られていない
- [ ] オルセン・ヴィラール・ハーゲンは、企業の時代を見ていない昔の人である。いまの街には出てこない

## ライフサイクル

街の歴史は、周をまたいでも変わらない。
