# 体の種類

## 定義

体の種類は、[体](./dom-02-life-and-body.md)ごとの違いである。種類ごとに基本の劣化と[効果](./dom-03-jobs-and-skills.md)を持つ。[転生](./dom-05-rebirth.md)するときに、[ミオ](./dom-10-characters.md)が用意した体の種類から1つを選んで目覚める。選んだ体の種類は、その周の間だけ働く。

体には、体の種類とは別に体の質がある。主人公は稼ぎを[ミオ](./dom-10-characters.md)の診療所の口座を通して受け取っていて、ミオはその1割を手数料として残す。前の身元の口座は[凍結される](./dom-09-consciousness-copy.md)が、手数料はミオの口座にあるので凍結されない。画面の稼ぎは、手数料を引いたあとの額である。ミオは手数料で体の部品を買って、次の体を組み立てる。そのため、前の周で稼いだクレジットが多いほど、次の体の体の質が高くなる。

## 属性

値は`game/data/bodies.json`にあり、並んだ順に転生の画面に出る。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 体の種類を区別する名前 |
| 基本の劣化 | 小数 | | その体の、効果も危険度も掛ける前の劣化。省いたときは0.4 |
| 効果 | 効果の種類ごとの小数 | ○ | その体で目覚めた周の間に働く効果。無い種類もある |

種類は次の4つである。

| 体の種類 | 基本の劣化 | 効果 |
| --- | --- | --- |
| 汎用の体 | 0.4 | なし |
| 作業用の体 | 0.3 | 経験 -10% |
| 戦闘用の体 | 0.5 | 稼ぎ +80% |
| 試作の体 | 0.5 | 経験 +60% |

ほかのノードの概念に、次の属性を足す。

| 対象 | 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| [周](./dom-02-life-and-body.md) | 体の種類 | 体の種類のid | ○ | その周の体の種類 |
| [周](./dom-02-life-and-body.md) | 体の質 | 0〜5の整数 | ○ | その周の体の質。第1周は0 |
| [記録](./dom-05-rebirth.md) | 体の種類 | 体の種類のid | ○ | その周を生きた体の種類 |

次の値は属性ではなく導出値である。

```
記録から決まる体の質 = clamp(floor(log2(その記録の稼いだクレジット ÷ 1,000)), 0, 5)
体の質 = 前の周の記録から決まる体の質
汎用の体の体の質 = max(前の周の記録から決まる体の質, floor(すべての記録から決まる体の質の最高 ÷ 2))
劣化の式に入る基本の劣化 = 体の種類の基本の劣化 × (1 - 0.15 × 体の質)
```

第1周には前の周の記録が無いので、体の質は0である。

体の質を掛けた基本の劣化は、[DOM-03](./dom-03-jobs-and-skills.md)の劣化の式の「基本の劣化」に入る。効果の合計とは別に掛けるので、劣化の効果が下限の0.2に届いていても、体の種類と体の質の違いは劣化に残る。

## 不変条件

- [ ] 1つの周の体の種類は1つで、周の間は変わらない
- [ ] 第1周は、並んだ順で最初の体の種類（汎用の体）で目覚める
- [ ] 2周目から後は、転生するときに選んだ体の種類で目覚める。選ばずには転生しない
- [ ] 汎用の体はいつでも選べる。作業用の体・戦闘用の体・試作の体は、前の周の記録から決まる体の質が1以上のとき、つまり前の周に2,000クレジット以上稼いだときだけ選べる
- [ ] 1つの周の体の質は、周の間は変わらない
- [ ] 体の種類の効果は、その周の間だけ働き、次の周には持ち越さない

## ライフサイクル

1. 周が終わると、その周の体の種類が記録に残る
2. 転生の画面に、すべての体の種類と、それぞれで目覚めたときの体の質が出る。選べる体の種類から1つを選ぶ。選ぶことが、そのまま転生になる
3. 選んだ体の種類と、その体の質で目覚める。その周の間、基本の劣化と効果が働く

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 体の種類 | 体ごとの違い。基本の劣化と効果を持ち、転生するときに選ぶ | |
| 基本の劣化 | 効果も危険度も掛ける前の、体の種類ごとの劣化 | |
| 体の質 | 前の周で稼いだクレジットで決まる、体の出来の段階。0〜5で、1段階ごとに基本の劣化を15%下げる | |
| 手数料 | 主人公の稼ぎのうち、ミオが診療所の口座に残す1割。ミオはこれで次の体の部品を買う | |
| 汎用の体 | 基本の劣化が0.4で、効果を持たない体の種類。第1周はこの体で目覚める | |
| 作業用の体 | 劣化が小さく、長くもつ代わりに、経験が入りにくい体の種類 | |
| 戦闘用の体 | 劣化が大きい代わりに、稼ぎが大きい体の種類 | |
| 試作の体 | 劣化が大きい代わりに、経験が入りやすい体の種類 | |
