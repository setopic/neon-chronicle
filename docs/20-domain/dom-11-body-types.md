# 体の種類

## 定義

体の種類は、[体](./dom-02-life-and-body.md)ごとの違いである。種類ごとに基本の劣化と[効果](./dom-03-jobs-and-skills.md)を持つ。[転生](./dom-05-rebirth.md)するときに、[ミオ](./dom-10-characters.md)が用意した体の種類から1つを選んで目覚める。選んだ体の種類は、その周の間だけ働く。

## 属性

値は`game/data/bodies.json`にあり、並んだ順に転生の画面に出る。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 体の種類を区別する名前 |
| 基本の劣化 | 小数 | | その体の、効果も危険度も掛ける前の劣化。省いたときは0.4 |
| 効果 | 効果の種類ごとの小数 | ○ | その体で目覚めた周の間に働く効果。無い種類もある |

種類は次の4つである。

| 体の種類 | 基本の劣化 | 効果 |
| --- | --- | --- |
| 汎用の体 | 0.4 | なし |
| 作業用の体 | 0.3 | 経験 -10% |
| 戦闘用の体 | 0.5 | 稼ぎ +80% |
| 試作の体 | 0.5 | 経験 +60% |

ほかのノードの概念に、次の属性を足す。

| 対象 | 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| [周](./dom-02-life-and-body.md) | 体の種類 | 体の種類のid | ○ | その周の体の種類 |
| [記録](./dom-05-rebirth.md) | 体の種類 | 体の種類のid | ○ | その周を生きた体の種類 |

基本の劣化は、[DOM-03](./dom-03-jobs-and-skills.md)の劣化の式の「基本の劣化」に入る。効果の合計とは別に掛けるので、劣化の効果が下限の0.2に届いていても、体の種類の違いは劣化に残る。

## 不変条件

- [ ] 1つの周の体の種類は1つで、周の間は変わらない
- [ ] 第1周は、並んだ順で最初の体の種類（汎用の体）で目覚める
- [ ] 2周目から後は、転生するときに選んだ体の種類で目覚める。選ばずには転生しない
- [ ] 体の種類の効果は、その周の間だけ働き、次の周には持ち越さない

## ライフサイクル

1. 周が終わると、その周の体の種類が記録に残る
2. 転生の画面で、すべての体の種類から1つを選ぶ。選ぶことが、そのまま転生になる
3. 選んだ体の種類で目覚める。その周の間、基本の劣化と効果が働く

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 体の種類 | 体ごとの違い。基本の劣化と効果を持ち、転生するときに選ぶ | |
| 基本の劣化 | 効果も危険度も掛ける前の、体の種類ごとの劣化 | |
| 汎用の体 | 基本の劣化が0.4で、効果を持たない体の種類。第1周はこの体で目覚める | |
| 作業用の体 | 劣化が小さく、長くもつ代わりに、経験が入りにくい体の種類 | |
| 戦闘用の体 | 劣化が大きい代わりに、稼ぎが大きい体の種類 | |
| 試作の体 | 劣化が大きい代わりに、経験が入りやすい体の種類 | |
