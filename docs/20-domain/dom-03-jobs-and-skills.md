# 仕事とスキル

## 定義

仕事は、周の間に就いて、1回を終えるごとにクレジットと経験を得る活動である。スキルは、仕事で経験を積むと上がる腕前で、仕事の稼ぎを増やし、新しい仕事に就けるようにする。

効果は、稼ぎ・経験・劣化を割合で増減させる値と、開始レベルを足す値である。効果を持つものは、スキルのほかにもある（[DOM-04](./dom-04-implants.md)・[DOM-05](./dom-05-rebirth.md)・[DOM-07](./dom-07-chronicle-story.md)・[DOM-11](./dom-11-body-types.md)）。どれが持つ効果も、種類ごとに足し合わせて使う。

## 属性

仕事の属性は次のとおりである。値は`game/data/jobs.json`にある。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 仕事を区別する名前 |
| 基本の稼ぎ | 小数 | ○ | スキルも効果も無いときの、1秒あたりのクレジット |
| 1回の長さ | 小数 | ○ | 1回を終えるまでの秒数 |
| 対応スキル | スキルのid | ○ | レベルが上がると、この仕事の稼ぎが増えるスキル |
| スキルの上乗せ | 小数 | ○ | 対応スキルの1レベルあたりに、稼ぎを増やす割合。量ではなく割合で、[依頼の上乗せ](./dom-12-jin-requests.md)や[縛りの上乗せ](./dom-21-challenges.md)とは違う |
| 危険度 | 小数 | ○ | 劣化に掛ける倍率。1が基準 |
| 得る経験 | スキルごとの小数 | ○ | 1秒あたりに換算して、どのスキルにどれだけ経験が入るか |
| 就く条件 | スキルごとのレベル | ○ | 就くのに要るスキルのレベル。無い仕事もある |
| ミニゲームの種類 | 文字列 | | 1回をミニゲームで終えるときに遊ぶもの。無い仕事は、ミニゲームで終えられない |

スキルの属性は次のとおりである。値は`game/data/skills.json`にある。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | スキルを区別する名前 |
| 1レベルあたりの効果 | 効果の種類ごとの小数 | ○ | レベルを掛けて足す。無いスキルもある |
| 節目の間隔 | 整数 | | 何レベルごとに節目が来るか。無いスキルには節目が無い |
| 1節目あたりの効果 | 効果の種類ごとの小数 | | 越えた節目の数を掛けて足す。どの仕事に就いていても効く |

劣化の式の基本の劣化は、体の種類が持っている（[DOM-11](./dom-11-body-types.md)）。

記憶の断片がすべて戻るまで就けない仕事を表す属性は、[DOM-08](./dom-08-memory-fragments-and-endings.md)が足している。

周ごとの状態として、持っているクレジット、その周で稼いだクレジット、就いている仕事、仕事の進み具合、ミニゲームを遊んでいるか、スキルごとのレベルと経験、仕事ごとの就いた時間を持つ。進み具合は、就いている仕事のいまの1回で、何秒進んだかである。

次の値は属性ではなく導出値である。

```
稼ぎ（1秒あたり） = 基本の稼ぎ × (1 + スキルの上乗せ × 対応スキルのレベル) × (1 + 稼ぎの効果の合計)
経験（1秒あたり） = 得る経験 × (1 + 経験の効果の合計)
報酬（1回あたり） = 1回を終えた時点の稼ぎ × 1回の長さ
1回で入る経験 = 1回を終えた時点の経験（1秒あたり） × 1回の長さ
ミニゲームで終えた1回の報酬と経験 = 報酬と1回で入る経験 × (1 + 1 × 成功の度合い)
次のレベルまでの経験 = 10 × 1.25 ^ いまのレベル
劣化 = 基本の劣化 × 危険度 × max(0.2, 1 + 劣化の効果の合計)
越えた節目の数 = floor(スキルのレベル ÷ 節目の間隔)
スキルの効果 = 1レベルあたりの効果 × スキルのレベル + 1節目あたりの効果 × 越えた節目の数
```

主な仕事は、その周でいちばん長く就いた仕事である。仕事ごとの就いた時間から導く。

## 不変条件

- [ ] 就く条件を満たしていない仕事には就けない
- [ ] 就ける仕事は、一度に1つだけである
- [ ] 仕事に就いていない間は、クレジットも経験も増えず、危険度は1として扱う
- [ ] クレジットと経験は、1回を終えたときにだけ入る。終えていない1回の分は入らない
- [ ] ミニゲームを遊んでいる間は、周の時間が止まり、進み具合も報酬も進まない
- [ ] スキルのレベルは、周の間は下がらない
- [ ] 劣化の効果をどれだけ重ねても、劣化は基本の劣化×危険度×0.2より小さくならない

## ライフサイクル

周の始まりには、クレジットと稼いだクレジットと進み具合が0になり、仕事には就いていない。スキルのレベルは、どれも開始レベルになる。開始レベルは、開始レベルの効果の合計である。

周の間は、就いている仕事の進み具合が時間とともに進む。進み具合が1回の長さに届くと、その1回の報酬と経験が入り、同じ仕事の次の1回が始まる。届いた分を超えた時間は、次の1回へ持ち越す。別の仕事に替えると、終えていない1回の分は入らず、進み具合は0に戻る。周が終わったときも、終えていない1回の分は入らない。

就いている仕事にミニゲームの種類があれば、いまの1回をミニゲームで終えられる。遊んでいる間は周の時間が止まる。終えると、成功の度合い（0〜1）に応じて上乗せした報酬と経験が入り、進み具合は0に戻る。度合いが0でも、放置で終えた1回と同じだけ入る。途中でやめると何も入らず、進み具合はそのまま残る。どの仕事でも、その仕事の対応スキルのレベルがミニゲームの難しさを変える（[ADR-0054](../50-adr/adr-0054-minigame-frame.md)）。

経験が次のレベルまでの経験に届くと、そのスキルのレベルが1上がり、超えた分は次のレベルへ持ち越す。上がったレベルが節目に届くと、そのスキルの1節目あたりの効果が1つ分強まる。節目には上限が無い（[ADR-0072](../50-adr/adr-0072-skill-milestones.md)）。

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 仕事 | 周の間に就いて、クレジットと経験を得る活動。運び屋・ハッカー・傭兵など | |
| クレジット | ネオン・シティのお金。仕事で稼ぐ。周が変わると0に戻る | |
| 稼ぎ | 就いている仕事の、1秒あたりに換算したクレジット。1回の報酬は、これに1回の長さを掛けた額である | |
| 1回 | 仕事の区切り。終えると報酬と経験が入り、同じ仕事の次の1回が始まる | |
| 報酬 | 仕事の1回を終えたときに入るクレジット | |
| 進み具合 | 就いている仕事のいまの1回で、進んだ秒数。[依頼の進み具合](./dom-12-jin-requests.md)や[話の進み具合](./dom-13-character-events.md)とは別のもの | |
| ミニゲーム | 就いている仕事の1回を、遊んで終える短いゲーム。終えると上乗せした報酬が入る | |
| 成功の度合い | ミニゲームをどれだけうまく終えたかを表す、0から1の値 | |
| 危険度 | 仕事ごとの、劣化に掛ける倍率。1が基準で、大きいほど体が早く使えなくなる | |
| 就く条件 | その仕事に就くのに要る、スキルのレベル | |
| 主な仕事 | その周でいちばん長く就いた仕事 | |
| スキル | 仕事で上がる腕前。ハッキング・格闘・交渉など。周が変わると開始レベルに戻る | |
| 経験 | スキルのレベルを上げるためにたまる量 | |
| 対応スキル | 仕事ごとに決まっている、レベルが上がるとその仕事の稼ぎが増えるスキル | |
| 効果 | 稼ぎ・経験・劣化・開始レベルのどれかを増減させる値。持っているものの効果を、種類ごとに足し合わせて使う | |
| 開始レベル | 周の始まりに、すべてのスキルが持っているレベル | |
| 節目 | スキルのレベルが、節目の間隔の倍数に届いたところ。越えるたびに、スキルごとに決まった効果が強まる | |
