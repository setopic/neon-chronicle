# 仕事とスキル

## 定義

仕事は、周の間に就いて、時間とともにクレジットと経験を得る活動である。スキルは、仕事で経験を積むと上がる腕前で、仕事の稼ぎを増やし、新しい仕事に就けるようにする。

効果は、稼ぎ・経験・劣化を割合で増減させる値と、開始レベルを足す値である。効果を持つものは、スキルのほかにもある（[DOM-04](./dom-04-implants.md)・[DOM-05](./dom-05-rebirth.md)）。どれが持つ効果も、種類ごとに足し合わせて使う。

## 属性

仕事の属性は次のとおりである。値は`game/data/jobs.json`にある。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 仕事を区別する名前 |
| 基本の稼ぎ | 小数 | ○ | スキルも効果も無いときの、1秒あたりのクレジット |
| 対応スキル | スキルのid | ○ | レベルが上がると、この仕事の稼ぎが増えるスキル |
| スキルの上乗せ | 小数 | ○ | 対応スキルの1レベルあたりに、稼ぎを増やす割合 |
| 危険度 | 小数 | ○ | 劣化に掛ける倍率。1が基準 |
| 得る経験 | スキルごとの小数 | ○ | 1秒あたりに、どのスキルにどれだけ経験が入るか |
| 就く条件 | スキルごとのレベル | ○ | 就くのに要るスキルのレベル。無い仕事もある |

スキルの属性は次のとおりである。値は`game/data/skills.json`にある。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | スキルを区別する名前 |
| 1レベルあたりの効果 | 効果の種類ごとの小数 | ○ | レベルを掛けて足す。無いスキルもある |

周ごとの状態として、持っているクレジット、その周で稼いだクレジット、就いている仕事、スキルごとのレベルと経験、仕事ごとの就いた時間を持つ。

次の値は属性ではなく導出値である。

```
稼ぎ（1秒あたり） = 基本の稼ぎ × (1 + スキルの上乗せ × 対応スキルのレベル) × (1 + 稼ぎの効果の合計)
経験（1秒あたり） = 得る経験 × (1 + 経験の効果の合計)
次のレベルまでの経験 = 10 × 1.25 ^ いまのレベル
劣化 = 基本の劣化 × 危険度 × max(0.2, 1 + 劣化の効果の合計)
```

主な仕事は、その周でいちばん長く就いた仕事である。仕事ごとの就いた時間から導く。

## 不変条件

- [ ] 就く条件を満たしていない仕事には就けない
- [ ] 就ける仕事は、一度に1つだけである
- [ ] 仕事に就いていない間は、クレジットも経験も増えず、危険度は1として扱う
- [ ] スキルのレベルは、周の間は下がらない
- [ ] 劣化の効果をどれだけ重ねても、劣化は基本の劣化×危険度×0.2より小さくならない

## ライフサイクル

周の始まりには、クレジットと稼いだクレジットが0になり、仕事には就いていない。スキルのレベルは、どれも開始レベルになる。開始レベルは、開始レベルの効果の合計である。

周の間は、就いている仕事に応じて、毎秒クレジットと経験が増える。経験が次のレベルまでの経験に届くと、そのスキルのレベルが1上がり、超えた分は次のレベルへ持ち越す。

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 仕事 | 周の間に就いて、クレジットと経験を得る活動。運び屋・ハッカー・傭兵など | |
| クレジット | ネオン・シティのお金。仕事で稼ぐ。周が変わると0に戻る | |
| 稼ぎ | 就いている仕事で、1秒あたりに増えるクレジット | |
| 危険度 | 仕事ごとの、劣化に掛ける倍率。1が基準で、大きいほど体が早く使えなくなる | |
| 就く条件 | その仕事に就くのに要る、スキルのレベル | |
| 主な仕事 | その周でいちばん長く就いた仕事 | |
| スキル | 仕事で上がる腕前。ハッキング・格闘・交渉など。周が変わると開始レベルに戻る | |
| 経験 | スキルのレベルを上げるためにたまる量 | |
| 対応スキル | 仕事ごとに決まっている、レベルが上がるとその仕事の稼ぎが増えるスキル | |
| 効果 | 稼ぎ・経験・劣化・開始レベルのどれかを増減させる値。持っているものの効果を、種類ごとに足し合わせて使う | |
| 開始レベル | 周の始まりに、すべてのスキルが持っているレベル | |
