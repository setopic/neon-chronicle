# 住民の生まれから死まで

## 定義

[ネオン・シティ](./dom-01-world.md)の住人が、生まれてから死ぬまでにどう暮らすかである。子どもの育ち方、病気やけがの手当て、老い、死んだあとの体の扱いを、[住民の階級](./dom-18-resident-classes.md)ごとに書く。どれも文だけで、ゲームの数値は持たない。

## 属性

子どもは、親の暮らしの中で育つ。

| 階級 | 生まれるところ | 学ぶところ | 大人になると |
| --- | --- | --- | --- |
| 重役・社員・私兵の子 | 自社の縄張りの社の病院 | 社の学校。社の仕事に要ることを学ぶ | 社員か私兵になる |
| 下層街の子 | 住まい。近所の年寄りや闇医者が取り上げる | 学校は無い。親や、屋台・修理屋の親方に付いて、仕事を覚える | 親と同じ稼ぎに就く |

下層街で親のいない子は、屋台組合が屋台通りや下層街の奥の店に預けて、手伝わせる。預け先の無い子は、[拾い屋](./dom-18-resident-classes.md)になって食べていく。そのうちの一部が、路地のチンピラになる。

ザンダー一家の頭と幹部は、頭の家の血筋で固めている。一家は、外から入る者を下で働かせて、構成員を増やす。入る道は次の3つである。

| 入る者 | どう入るか |
| --- | --- |
| 裏通りで育った若者 | 拾い屋や路地のチンピラの中から、腕や度胸のある者を一家が拾い上げる |
| 一家に借金を返せない者 | 借金の代わりに、一家の下働きをする |
| 解雇された私兵 | 社の身元を失った腕の立つ者を、一家が用心棒として雇う |

病気やけがを診る者は、身元で分かれる。

| 診る者 | 診る相手 | 薬の手に入れ方 |
| --- | --- | --- |
| 社の病院 | 社の身元を持つ者だけ | 社の病院が出す |
| 下層街の闇医者 | 払える者なら誰でも。裏通りの診療所も、その1つである | 屋台や闇市場で買う。闇市場の薬の多くは、企業の倉庫から盗まれたものである |

ヴァルデック義体の[インプラント](./dom-04-implants.md)を組み込んだ者は、拒絶反応を抑える薬を飲み続ける。下層街では、この薬が高く売れる。

老いて働けなくなった人の暮らしは、次のとおりである。

| 階級 | 老いたあと |
| --- | --- |
| 重役・社員・私兵 | 社を退き、社員である子の社宅で暮らす。社員である子がいなければ、社の身元を消されて、下層街へ下りる |
| 下層街の住人 | 家族や弟子が養う。屋台組合の年寄りは、組合の台帳を付けたり、もめごとを仲裁したりする。養う者のいない年寄りには、屋台組合が合成食と水を分ける |

死んだ人の体は、次のように扱われる。

| 階級 | 遺体の行き先 |
| --- | --- |
| 重役・社員・私兵 | 社が引き取って焼く。組み込んでいたインプラントは社が貸していたものなので、焼く前に取り出して回収する |
| 下層街の住人 | 家族が闇医者へ運ぶ。闇医者はインプラントと使える臓器を取り出し、代金を家族に払う。残りは、下層街の奥にある屋台組合の焼き場で焼き、灰を排水路に流す |

闇医者が取り出したインプラントと臓器は、闇市場へ売られる。闇市場で売り買いされる体の部品は、ほとんどがこれである。借金を残して死んだ者の遺体は、ザンダー一家が取り立てとして引き取り、体の部品を売って借金に充てる。

下層街で起きるイベント「遺体の取り立て」は、傭兵の仕事の間に起きる。ザンダー一家に雇われて、借金を残して死んだ拾い屋の遺体を引き取りに行く。

## 不変条件

- [ ] 社の病院が診るのは、社の身元を持つ者だけである
- [ ] 下層街には学校が無い
- [ ] ザンダー一家の頭と幹部は、頭の家の血筋の者だけである
- [ ] 闇市場の体の部品のほとんどは、下層街の死者から闇医者が取り出したものである

## ライフサイクル

子どもの育ち方から死んだあとの扱いまでは、周をまたいでも変わらない。主人公の体の出どころは、この文書では扱わない。

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 社の病院 | 企業が自社の縄張りに置く病院。社の身元を持つ者だけを診る | |
| 社の学校 | 企業が自社の縄張りに置く学校。重役・社員・私兵の子が、社の仕事に要ることを学ぶ | |
| 闇医者 | 下層街で、払える者なら誰でも診る医者。死者からインプラントと臓器を取り出して、闇市場へ売る | |
| 親方 | 下層街で、屋台や修理屋を営み、子どもや弟子に仕事を教える人 | |
| 焼き場 | 下層街の奥にある、屋台組合が遺体を焼く場所 | |
| 体の部品 | 闇市場で売り買いされる、人の体から取り出したインプラントと臓器 | |
