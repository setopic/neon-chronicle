# ジンの依頼

## 定義

ジンの依頼は、[周](./dom-02-life-and-body.md)の始まりに[ジン](./dom-10-characters.md)が主人公に持ってくる、その周の間に果たす目標である。1つの周に1つだけ示される。果たした周は、周の終わりに得る[記憶ポイント](./dom-05-rebirth.md)が上乗せされる。果たさなくても、失うものは無い。

## 属性

値は`game/data/requests.json`にある。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 依頼を区別する名前 |
| 依頼の種類 | 「仕事」か「スキル」 | ○ | 何をすれば果たしたことになるか。仕事とスキルのどちらを持つかで表す |
| 仕事 | 仕事のid | | 依頼の種類が「仕事」のとき、その周に就く仕事 |
| 秒数 | 秒 | | 依頼の種類が「仕事」のとき、その仕事に就いている時間の合計 |
| スキル | スキルのid | | 依頼の種類が「スキル」のとき、上げるスキル |
| レベル | 整数 | | 依頼の種類が「スキル」のとき、そのスキルの目標のレベル |
| 示す条件 | スキルのidごとのレベル | | 前の周の終わりのスキルのレベルが、これを満たしているときだけ示す |

依頼の種類ごとに、果たしたことになる条件は次のとおりである。

| 依頼の種類 | 果たしたことになる条件 |
| --- | --- |
| 仕事 | その周で、依頼の仕事に就いている時間の合計が秒数に届く |
| スキル | その周で、依頼のスキルのレベルが目標のレベルに届く |

依頼は次の6つである。

| 依頼の種類 | 中身 | 示す条件 |
| --- | --- | --- |
| 仕事 | 運び屋として2分働く | なし |
| スキル | 交渉をLv 4まで上げる | なし |
| 仕事 | ハッカーとして2分働く | 交渉 Lv 3 |
| スキル | ハッキングをLv 8まで上げる | 交渉 Lv 3 |
| 仕事 | 傭兵として2分働く | 格闘 Lv 6 |
| スキル | 格闘をLv 10まで上げる | 格闘 Lv 6 |

ほかのノードの概念に、次の属性を足す。

| 対象 | 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| [周](./dom-02-life-and-body.md) | 依頼 | 依頼のid | | その周に示されたジンの依頼。示せる依頼が無いときは空 |
| 周 | 依頼を果たしたか | 真偽 | ○ | その周の依頼を果たしたか |

次の値は属性ではなく導出値である。

```
示す依頼 = 示せる依頼[(周の番号 - 1) mod 示せる依頼の数]
示せる依頼 = 示す条件を、前の周の終わりのスキルのレベルが満たしている依頼（並んだ順）
依頼の上乗せ = max(1, round(周の終わりに得る記憶ポイント × 0.5))
```

第1周には前の周が無いので、示す条件の無い依頼だけを示せる依頼とする。周の終わりに得る記憶ポイントの式は、[DOM-05](./dom-05-rebirth.md)にある。依頼を果たした周は、その値に依頼の上乗せを足したものを得る。

果たした依頼の分だけ記憶ポイントが増えるのは、目的を持って過ごした周の記憶が、[同期](./dom-09-consciousness-copy.md)で意識の写しへ送り返しやすいからである。

## 不変条件

- [ ] 1つの周に示す依頼は1つまでで、周の間は変わらない
- [ ] 示す依頼は、周の番号と前の周の終わりのスキルのレベルだけで決まり、乱数を使わない
- [ ] 依頼を果たしたかどうかは、周の間に一度真になったら偽に戻らない
- [ ] 依頼の上乗せは、依頼を果たした周の終わりにだけ足す

## ライフサイクル

1. 周の始まりに、示す依頼が決まる。ジンが依頼を持ってきたことがログに残る
2. 周の間、依頼の進み具合が体の状態の欄に出る
3. 果たしたことになる条件を満たすと、依頼を果たしたことがログに残る
4. 周が終わると、依頼を果たしていれば、記憶ポイントに依頼の上乗せが足される

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 依頼 | 周の始まりにジンが持ってくる、その周の間に果たす目標。果たすと記憶ポイントが上乗せされる。仕事に就くこと（「仕事を受ける」）とは別で、仕事は依頼が無くても選べる | |
| 依頼の上乗せ | 依頼を果たした周の終わりに、記憶ポイントに足す量 | |
