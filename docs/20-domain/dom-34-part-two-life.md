# 第二部の暮らし

## 定義

第二部は、[エンディング](./dom-08-memory-fragments-and-endings.md)「本当の体」のあとに、[主人公](./dom-01-world.md)が[本当の体](./dom-08-memory-fragments-and-endings.md)で暮らす続きである。第二部には[転生](./dom-05-rebirth.md)が無い。主人公は1つの体の体調を保ちながら[仕事](./dom-03-jobs-and-skills.md)をし、章の目標を満たして章を進める。転生を繰り返して最初のエンディングまでを遊ぶ部分を、第一部と呼ぶ。

## 属性

第二部の状態は次のとおりである。第一部の[周](./dom-02-life-and-body.md)の状態とは別に持ち、第一部へ戻っても残る。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| 体調 | 小数 | ○ | 0から体調の上限まで。仕事をすると減り、休むと戻る。時間がたつだけでは減らない |
| 怪我 | 小数 | ○ | 0〜90。体調の上限を下げる。第二部の始めは40 |
| 日 | 整数 | ○ | 1から始まり、決まった時間（60秒）がたつたびに1増える |
| 住まいを借りたか | 真偽 | ○ | 一度借りると、第二部のあいだ持ち続ける |
| 仲間 | 仲間のidから仕事のidへの対応 | ○ | 迎えた仲間と、任せた仕事。仕事を任せていない仲間もいる |
| 進めている章 | 章のid | | すべての章を終えていれば無い |
| 起きた章の出来事 | イベントのidの並び | ○ | 章の出来事のうち、すでに起きたもの |
| 払った目標 | 章の目標のidの並び | ○ | クレジットを払って満たした章の目標 |

[クレジット](./dom-03-jobs-and-skills.md)・[スキル](./dom-03-jobs-and-skills.md)のレベルと経験・[インプラント](./dom-04-implants.md)・[偽の身元](./dom-24-job-districts-and-identity.md)も、第二部の状態として第一部とは別に持つ。

章の属性は次のとおりである。値は`game/data/part_two.json`にあり、並んだ順が進む順である。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 章を区別する名前 |
| 章の目標 | 目標の並び | ○ | すべて満たすと、章の最後の出来事が起きる |
| 章の出来事 | 出来事の並び | ○ | 並んだ順に起きる。最後の1つを選び終えると、その章が終わる |

章の目標は、次のどれかで満たす。

| 種類 | 満たすとき |
| --- | --- |
| スキル | スキルのレベルが、すべて書いた値以上になったとき。[就く条件](./dom-03-jobs-and-skills.md)と同じ形で書く |
| 住まい | 住まいを借りたとき |
| 怪我を治す | 怪我が0になったとき |
| 支払い | 書いた額のクレジットを払ったとき |

章の出来事は、[イベント](./dom-06-events.md)を1つ指す。起きる条件として、日・章の目標の1つ・すべての章の目標のどれかを持てる。条件の無い出来事は、その前の出来事のすぐあとに起きる。

ほかのノードの概念に、次の属性を足す。

| 対象 | 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| [イベント](./dom-06-events.md) | 部 | 1か2 | | 書いた部でだけ起きる。書かなければ、下の「第二部で起きるイベント」に従う |
| [選択肢](./dom-06-events.md) | 迎える仲間 | 仲間のid | | 選ぶと、その仲間を迎える |

次の値は属性ではなく導出値である。

```
体調の上限 = 100 - 怪我
仕事中の疲れ（1秒あたり） = 0.5 × 仕事の危険度 × max(0.2, 1 + 劣化の効果の合計)
休んだときの戻り（1秒あたり） = 1、住まいを借りていれば 2
1日の暮らしの代金 = 住まいを借りていれば 60、借りていなければ 20（簡易宿）
仲間の稼ぎ（1秒あたり） = 仕事の基本の稼ぎ × (1 + スキルの上乗せ × 仲間のその仕事のスキルのレベル) × (1 - 0.4)
```

劣化の効果は、第一部では[劣化](./dom-02-life-and-body.md)を下げ、第二部では仕事中の疲れを下げる。格闘の節目やインプラントの効果が、そのまま第二部でも効く。

### 仲間

仲間は、第二部で迎え、[仕事](./dom-03-jobs-and-skills.md)を任せられる人である。仲間の属性は次のとおりで、値は`game/data/part_two.json`にある。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 仲間を区別する名前 |
| 得意な仕事 | 仕事のid | ○ | 迎えたときに任せる仕事 |
| スキルのレベル | スキルのidからレベルへの対応 | ○ | 仲間のスキルのレベル。上がらない |

仲間は、主人公が意識を抜き取られる前に組んでいた昔の一味の3人である。3人とも、どの企業にも属さない下層街の人物で、[人物](./dom-10-characters.md)の名前の決まりに従ってカタカナで書く。

| 仲間 | 得意な仕事 | 主人公との関係 |
| --- | --- | --- |
| サキ | 運び屋 | 昔の一味の運び屋。いまは屋台組合の荷を運んでいる |
| ゴウ | 傭兵 | 昔の一味の用心棒。借金のかたに、賭け試合に出され続けていた |
| トワ | ハッカー | 主人公が昔、手ほどきをした若いハッカー。主人公が消えてから、記録庫の防壁を1人で調べ続けていた |

仲間は、章の出来事の選択肢で迎える。迎えた仲間は、得意な仕事を任された状態から始める。任せる仕事は、仲間のスキルのレベルが就く条件を満たす仕事のどれかに替えられ、何も任せないこともできる。仲間は自分の身元を持っているので、偽の身元が要る仕事にも就ける。

仲間は疲れず、休まない。任せた仕事は、主人公が仕事をしていても休んでいても、時間がたつだけ稼ぐ。稼ぎの4割は分け前として仲間が取り、残りが主人公のクレジットに入る。主人公のスキルの経験は増えない。インプラントやスキルの節目のような主人公の効果は、仲間の稼ぎに効かない。

### 第一部から持ち込むもの

| 第一部のもの | 第二部での扱い |
| --- | --- |
| スキル | レベル1から始める。取り戻したばかりの体はまだうまく動かず、頭も回らないからである。節目は第一部と同じく効く |
| クレジット・インプラント・偽の身元 | 持ち込まない。第二部の始めは何も持っていない |
| [記憶ポイント](./dom-05-rebirth.md)と[永続強化](./dom-05-rebirth.md) | 使わない。永続強化は意識の写しの改良なので（[DOM-09](./dom-09-consciousness-copy.md)）、本当の体には効かない |
| 体の種類と体の質 | 使わない。本当の体に組み込めるインプラントの大きさの合計は3である |
| 評判・人物のイベントの進み具合・記憶の断片 | 第一部と同じものを使う |

### 第二部で起きるイベント

部を書いていないイベントのうち、第二部で起きるのは、ふつうの仕事のイベントだけである。人物のイベント、勢力の話のイベント、前の周の跡のイベント、元の持ち主の話のイベント、記憶の断片の要るイベントは、第二部では起きない。どれも周や体の乗り換えに結びついているからである。最後の仕事は、第二部には無い。

## 不変条件

- [ ] 第二部では、転生は起きない。体調が0になっても周は終わらない
- [ ] 第二部に入れるのは、エンディング「本当の体」にたどり着いたあと、転生の画面にいるときだけである
- [ ] 体調は、体調の上限を超えない
- [ ] 怪我は、裏通りの診療所でクレジットを払って治すまで減らない
- [ ] 章の出来事は、並んだ順にしか起きない
- [ ] 第一部へ戻っても、第二部の状態は失われない
- [ ] 仲間は、第二部のあいだ減らない

## ライフサイクル

1. エンディング「本当の体」にたどり着くと、転生の画面から第二部へ進めるようになる
2. 初めて第二部へ進むと、裏通りの診療所で目を覚ます。スキルはレベル1、怪我は40で、クレジットもインプラントも持っていない
3. 仕事をすると体調が減り、休むと戻る。日が替わるたびに、1日の暮らしの代金を払う。払えなければ路上で寝て、体調が10減る
4. 選択肢で体調が減ると、減った分の半分が怪我として残る。体調が0になると倒れて、裏通りの診療所に運ばれる。怪我が10増え、クレジットの2割を失い、日が1つ進む。体調は上限の半分になり、休んでいる状態から続ける
5. 怪我は、裏通りの診療所で、1回に10ずつ、怪我1あたり100クレジットで治す
6. 章の出来事で仲間を迎えると、仲間に任せた仕事の稼ぎが入り始める
7. 章の目標をすべて満たすと、章の最後の出来事が起きる。その選択肢を選ぶと章が終わり、次の章へ進む
8. 第二部の途中で、いつでも第一部の転生の画面へ戻れる。戻ってまた第二部へ進むと、続きから遊べる。最初からやり直すと、第二部の状態も無くなる

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 第一部 | 転生を繰り返して、最初のエンディングまでを遊ぶ部分 | |
| 第二部 | エンディング「本当の体」のあとに、本当の体で暮らす続き。転生が無い | |
| 体調 | 第二部で、本当の体がいまどれだけ動けるかを表す値。仕事で減り、休むと戻る。0になると倒れる。第一部の[耐久](./dom-02-life-and-body.md)と違い、時間がたつだけでは減らず、0になっても周は終わらない | |
| 怪我 | 体調の上限を下げる傷。休んでも治らず、裏通りの診療所で治す | |
| 日 | 第二部の時間の単位。日が替わるたびに、1日の暮らしの代金を払う | |
| 休む | 仕事に就かずに、体調を戻すこと | |
| 倒れる（第二部） | 体調が0になり、裏通りの診療所に運ばれること。周は終わらない | |
| 住まい | 第二部で借りる部屋。借りると、休んだときに体調が早く戻る | |
| 章 | 第二部を分けた区切り。章の目標と章の出来事を持つ | |
| 章の目標 | 章を終えるのに満たすこと。スキル・住まい・怪我を治す・支払いのどれか | |
| 章の出来事 | 章の中で決まった順に起きるイベント。最後の1つを選び終えると章が終わる | |
| 仲間 | 第二部で迎え、仕事を任せられる人。疲れず、時間がたつだけ稼ぐ。[イベント](./dom-06-events.md)の中で主人公と組む相手とは違い、第二部のあいだ残る | |
| 任せる | 仲間を仕事に就かせること。何も任せないこともできる | |
| 昔の一味 | 意識を抜き取られる前の主人公と組んでいた、サキ・ゴウ・トワの3人 | |
| 分け前 | 仲間に任せた仕事の稼ぎのうち、仲間が取る分。稼ぎの4割 | |
