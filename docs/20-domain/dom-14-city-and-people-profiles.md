# 街と人物の資料

## 定義

資料は、[ネオン・シティ](./dom-01-world.md)・[企業](./dom-01-world.md)・[街の場所](./dom-15-city-places-and-powers.md)・[主人公](./dom-01-world.md)・[登場人物](./dom-10-characters.md)の1つについて、プレイヤーがいつでも読める説明である。最初は、遊んでいればすでに分かることだけを載せる。[記憶の断片](./dom-08-memory-fragments-and-endings.md)が戻ったり、[人物のイベント](./dom-13-character-events.md)が起きたりすると、その資料に追記が加わる。

## 属性

資料の属性は次のとおりである。値は`game/data/profiles.json`にあり、並んだ順が画面に出る順である。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 資料を区別する名前 |
| 出るイベント | イベントのid | | 人物のイベントのid。そのイベントで選択肢を選ぶまで、資料そのものを出さない。無ければ最初から出る |
| 追記 | 追記の並び | | 並んだ順に、資料の説明の後ろへ加わる |

追記の属性は次のとおりである。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 同じ資料の中で、追記を区別する名前 |
| 要る断片 | 記憶の断片のid | | その断片が戻るまで、追記を出さない |
| 出るイベント | イベントのid | | 人物のイベントのid。そのイベントで選択肢を選ぶまで、追記を出さない |

追記は、要る断片と出るイベントのどちらか一方を持つ。表示名と文は言語ファイルにあり、データは持たない。

載せる資料は次のとおりである。九条は、まだ名前で画面に出ないので、資料を置かない。

| 資料 | 出るイベント | 追記の要る断片・出るイベント |
| --- | --- | --- |
| ネオン・シティ | | 「計画書」「中枢サーバー」 |
| 企業 | | |
| リンドホルム食品 | | |
| 企業区画 | | |
| 下層街 | | |
| 闇市場 | | |
| ザンダー一家 | | |
| 屋台組合 | | |
| 自分（主人公） | | 「契約書」「名前」「計画書」「中枢サーバー」 |
| ミオ | | 「白い部屋」「計画書」 |
| ジン | | 「名前」 |
| レイ | レイの1段目 | レイの2段目 |

## 不変条件

- [ ] 記憶の断片で明かすことは、その断片が戻るまで、どの資料にも出ない
- [ ] 人物のイベントで分かることは、そのイベントで選択肢を選ぶまで、どの資料にも出ない
- [ ] 資料は読むだけで、ゲームの状態を変えない

## ライフサイクル

1. 最初の周から、出るイベントを持たない資料が読める
2. 記憶の断片が戻ると、その断片を要る追記が加わる。転生しても消えない
3. 人物のイベントで選択肢を選ぶと、そのイベントを出るイベントに持つ資料と追記が出る
4. 最初からやり直すと、戻った記憶の断片と[話の進み具合](./dom-13-character-events.md)が無くなるので、資料も最初の状態に戻る

| 追記 | 記憶の断片が戻るか、人物のイベントが起きると、資料の後ろに加わる文 | |
