# 転生と永続強化

## 定義

転生は、周が終わったあとに、主人公が新しい体で目覚めることである。周が終わると記憶ポイントが手に入り、記憶ポイントで永続強化を買う。永続強化は、転生しても失われない効果である。終わった周は、クロニクルに1件ずつ記録として残る。

## 属性

永続強化の属性は次のとおりである。値は`game/data/upgrades.json`にある。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 永続強化を区別する名前 |
| 最初の値段 | 記憶ポイント | ○ | レベル0から1に上げる値段 |
| 値段の伸び | 小数 | ○ | レベルが1上がるたびに、値段に掛ける倍率 |
| 最大レベル | 整数 | ○ | これ以上は上げられないレベル |
| 1レベルあたりの効果 | 効果の種類ごとの小数 | ○ | レベルを掛けて足す |

転生しても残る状態として、記憶ポイント、永続強化ごとのレベル、クロニクルを持つ。

クロニクルの記録の属性は次のとおりである。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| 周の番号 | 整数 | ○ | どの周の記録か |
| 主な仕事 | 仕事のid | | その周で仕事に就かなかったときは空 |
| 経過時間 | 秒 | ○ | その周が終わるまでの時間 |
| 稼いだクレジット | 小数 | ○ | その周で稼いだクレジットの合計 |
| 得た記憶ポイント | 整数 | ○ | その周の終わりに手に入った記憶ポイント |

記録を物語文にするための属性は、[DOM-07](./dom-07-chronicle-story.md)が足している。たどり着いたエンディングの属性は、[DOM-08](./dom-08-memory-fragments-and-endings.md)が足している。

次の値は属性ではなく導出値である。

```
周の終わりに得る記憶ポイント = max(1, floor(√(その周で稼いだクレジット ÷ 50)) + floor(スキルのレベルの合計 ÷ 3))
永続強化の値段 = 最初の値段 × 値段の伸び ^ いまのレベル
```

## 不変条件

- [ ] 周が終わるたびに、記憶ポイントは1以上増える
- [ ] 記憶ポイントが値段に足りないときは、永続強化を買えない
- [ ] 永続強化のレベルは、最大レベルを超えない
- [ ] 転生するのは、体が生きていないときだけである
- [ ] クロニクルの記録は、周が終わるたびに1件増え、消えない

## ライフサイクル

1. 耐久が0になり、周が終わる
2. 記憶ポイントが手に入り、その周の記録がクロニクルに1件増える
3. 記憶ポイントで永続強化を買う。買うのは、周の間でも、周が終わったあとでもよい
4. 転生すると、周の番号が1増え、新しい体で目覚める。クレジット・仕事・スキルは周の始まりに戻り、残るインプラント以外のインプラントは失われる
5. 記憶ポイント・永続強化・クロニクルは、そのまま次の周へ持ち越す

最初からやり直すと、転生しても残る状態も含めて、すべてが第1周の始まりに戻る。

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 転生 | 周が終わったあとに、新しい体で目覚めること。次の周が始まる | |
| 記憶ポイント | 周の終わりに手に入り、永続強化を買うのに使う値。転生しても失われない | |
| 永続強化 | 記憶ポイントで買う効果。レベルを持ち、転生しても失われない | |
| クロニクル | 終わった周の記録を、古い順に並べたもの | |
| 記録 | クロニクルの1件。1つの周の主な仕事・経過時間・稼いだクレジット・得た記憶ポイントを持つ | |
