# イベントと選択肢

## 定義

イベントは、[仕事](./dom-03-jobs-and-skills.md)に就いている間に起きる出来事である。[企業](./dom-01-world.md)の追跡や仲間の裏切りのように、仕事ごとに起きるものが決まっている。イベントには選択肢があり、主人公がどれかを選ぶと、その結果がクレジット・耐久・経験に表れる。

## 属性

イベントの属性は次のとおりである。値は`game/data/events.json`にある。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | イベントを区別する名前 |
| 起きる仕事 | 仕事のidの一覧 | ○ | このイベントが起きる仕事 |
| 選択肢 | 選択肢の一覧 | ○ | 1つ以上 |

選択肢の属性は次のとおりである。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | そのイベントの中で、選択肢を区別する名前 |
| 選ぶ条件 | スキルごとのレベル | | 選ぶのに要るスキルのレベル。就く条件と同じ形で書く |
| クレジットの増減 | 秒 | | いまの稼ぎの何秒分のクレジットを増やすか。負なら減らす |
| 耐久の増減 | 小数 | | 負なら減らす |
| 得る経験 | スキルごとの小数 | | 0以上 |

エンディングにたどり着く選択肢の属性は、[DOM-08](./dom-08-memory-fragments-and-endings.md)が足している。人物との話が周をまたいで進むイベントの属性は、[DOM-13](./dom-13-character-events.md)が足している。

周ごとの状態として、選ぶのを待っているイベントを持つ。待っているイベントが無いこともある。

次の値は属性ではなく導出値である。

```
イベントが起きる確率（1秒あたり） = 危険度 ÷ 90
クレジットの増減 = いまの稼ぎ × 選択肢のクレジットの増減（秒）
```

危険度が1の仕事では、平均90秒に1回起きる。起きたイベントは、いまの仕事で起きるイベントの中から、同じ確率で1つ選ぶ。

## 不変条件

- [ ] イベントが起きるのは、生きている体で仕事に就いている間だけである
- [ ] 待っているイベントは、一度に1つだけである。待っている間は、次のイベントは起きない
- [ ] 待っている間は、仕事を変えられない
- [ ] どのイベントにも、選ぶ条件の無い選択肢が1つ以上ある
- [ ] 選ぶ条件を満たしていない選択肢は選べない
- [ ] 選んだ結果でクレジットが0より少なくなるときは、0にする
- [ ] 選んだ結果で増えたクレジットは、その周で稼いだクレジットにも足す
- [ ] 選んだ結果で耐久が0になったら、その周は終わる

## ライフサイクル

1. 仕事に就いている間、毎秒、イベントが起きる確率で判定する
2. イベントが起きると、それが待っているイベントになる
3. 主人公が選択肢を1つ選ぶ。その結果が表れ、待っているイベントは無くなる
4. 選ぶ前に周が終わったら、待っているイベントは結果を残さずに無くなる

待っている間も、時間はふつうに進む。プレイヤーが設定で「イベントで止める」を選んでいるときは、待っている間だけ時間が進まない。

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| イベント | 仕事に就いている間に起きる出来事。選択肢を持ち、起きる仕事が決まっている | |
| 選択肢 | イベントで選べる行動の1つ。選ぶと結果が表れる | |
| 結果 | 選択肢を選んだときの、クレジット・耐久・経験の増減 | |
| 選ぶ条件 | その選択肢を選ぶのに要る、スキルのレベル | |
| 待っているイベント | 起きたが、まだ選択肢が選ばれていないイベント | |
| イベントで止める | 待っているイベントがある間、時間を進めない設定。既定では選ばれていない | |
