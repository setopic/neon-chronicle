# インプラント

## 定義

インプラントは、クレジットで買って体に組み込む強化の部品である。組み込むと、その効果が働く。ふつうは体と一緒に失われるが、次の周にも残るものがある。

## 属性

値は`game/data/implants.json`にある。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | インプラントを区別する名前 |
| 値段 | クレジット | ○ | 組み込むのに払うクレジット |
| 効果 | 効果の種類ごとの小数 | ○ | 組み込んでいる間に働く効果 |
| 次の周にも残るか | 真偽 | | 省いたときは偽 |

周をまたいで持つ状態として、組み込んでいるインプラントの一覧がある。

## 不変条件

- [ ] 同じインプラントを2つ組み込むことはできない
- [ ] 持っているクレジットが値段に足りないときは、組み込めない
- [ ] 生きていない体には組み込めない
- [ ] 新しい体で目覚めたときに組み込んだままなのは、残るインプラントだけである

## ライフサイクル

1. クレジットを払って組み込む。その時点から効果が働く
2. 周が終わると、残るインプラント以外は体と一緒に失われる
3. 残るインプラントは、次の周の体にも組み込まれたまま始まる

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| インプラント | クレジットで買って体に組み込む強化の部品。組み込んでいる間、効果が働く | |
| 組み込む | クレジットを払って、インプラントを体に入れること。外すことはできない | |
| 残るインプラント | 周が終わっても失われず、次の周の体にも組み込まれたままのインプラント | |
