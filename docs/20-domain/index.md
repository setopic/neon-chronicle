# ドメイン（層 20）

概念・属性・不変条件・用語を書く。**この層の言葉が、上の層すべての共通語彙になる。**

画面、エンドポイント、フレームワークの都合は、この層には書かない。
ユースケースを参照したくなったら、概念の切り出しが足りていない。

### [DOM-03 仕事とスキル](./dom-03-jobs-and-skills.md)

| 用語 | 意味 | 旧称 |

### [DOM-06 イベントと選択肢](./dom-06-events.md)

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| イベント | 仕事に就いている間に起きる出来事。選択肢を持ち、起きる仕事が決まっている | |
| 選択肢 | イベントで選べる行動の1つ。選ぶと結果が表れる | |
| 結果 | 選択肢を選んだときの、クレジット・耐久・経験の増減 | |
| 選ぶ条件 | その選択肢を選ぶのに要る、スキルのレベル | |
| 待っているイベント | 起きたが、まだ選択肢が選ばれていないイベント | |
| イベントで止める | 待っているイベントがある間、時間を進めない設定。既定では選ばれていない | |
