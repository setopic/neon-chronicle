# 縛りの周

## 定義

縛りは、遊ぶ人が転生のときに自分に課す、その[周](./dom-02-life-and-body.md)の間に守る条件である。1つの周に1つまで選べる。守り通した周は、周の終わりに得る[記憶ポイント](./dom-05-rebirth.md)に縛りの上乗せが足される。守る条件に反する操作はできるが、した時点でその周の縛りを破ったことになる。

## 属性

値は`game/data/challenges.json`にある。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 縛りを区別する名前 |
| 守る条件 | 「インプラント」「仕事」「選択肢」のどれか | ○ | 何をすると破ったことになるか |
| 縛りの上乗せの割合 | 小数 | ○ | 守り通した周に、記憶ポイントへ上乗せする割合 |

守る条件ごとに、破ったことになる操作は次のとおりである。

| 守る条件 | 破ったことになる操作 |
| --- | --- |
| インプラント | その周に[インプラント](./dom-04-implants.md)を買う |
| 仕事 | その周に最初に就いた[仕事](./dom-03-jobs-and-skills.md)から、ほかの仕事に移る |
| 選択肢 | 選ぶ条件のある[選択肢](./dom-06-events.md)を選べるイベントで、選ぶ条件の無い選択肢を選ぶ |

縛りは次の3つである。

| 縛り | 守る条件 | 縛りの上乗せの割合 |
| --- | --- | --- |
| インプラントを買わない | インプラント | 0.3 |
| 仕事を変えない | 仕事 | 0.3 |
| 安全な選択肢を選ばない | 選択肢 | 0.5 |

ほかのノードの概念に、次の属性を足す。

| 対象 | 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| 周 | 縛り | 縛りのid | | その周に選んだ縛り。選ばなかったときは空 |
| 周 | 縛りを破ったか | 真偽 | ○ | その周の縛りを破ったか |
| [記録](./dom-05-rebirth.md) | 守った縛り | 縛りのid | | その周に守り通した縛り。無いときは空 |

次の値は属性ではなく導出値である。

```
縛りの上乗せ = max(1, round(周の終わりに得る記憶ポイント × 縛りの上乗せの割合))
```

周の終わりに得る記憶ポイントの式は、DOM-05にある。縛りを守り通した周は、その値に縛りの上乗せを足したものを得る。ジンの依頼の上乗せも、同じ値をもとにする。

守った縛りは、記録の[物語文](./dom-07-chronicle-story.md)の後ろに1句で足す。

## 不変条件

- [ ] 1つの周の縛りは1つまでで、周の間は変わらない
- [ ] 第1周には縛りが無い
- [ ] 縛りを破ったかどうかは、周の間に一度真になったら偽に戻らない
- [ ] 縛りの上乗せは、縛りを選んで破らなかった周の終わりにだけ足す

## ライフサイクル

1. 転生するときに、縛りを1つ選ぶか、選ばずに目覚める
2. 周の間、縛りの名前と、守っているか破ったかが体の状態の欄に出る
3. 守る条件に反する操作をすると、縛りを破ったことがログに残る
4. 周が終わると、縛りを守り通していれば、記憶ポイントに縛りの上乗せが足され、記録に守った縛りが残る

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 縛り | 転生のときに自分に課す、その周の間に守る条件 | |

| 縛りの上乗せ | 縛りを守り通した周の終わりに、記憶ポイントに足す量 | |
