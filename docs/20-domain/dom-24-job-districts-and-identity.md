# 仕事の区画と身元

## 定義

[仕事](./dom-03-jobs-and-skills.md)の区画は、その仕事を請け負う場所である[区画](./dom-15-city-places-and-powers.md)である。仕事ごとに1つ決まっていて、[街の地図](./dom-16-city-map.md)に、いまの仕事の区画が示される。仕事の間に起きる[イベント](./dom-06-events.md)の舞台は、仕事の区画とは別に、イベントごとに決まる。

仕事の区画が橋の向こうにあり、橋を渡って働く仕事には、橋を渡れる[身元](./dom-18-resident-classes.md)が要る。ネット越しにする仕事は、仕事の区画が橋の向こうにあっても橋を渡らないので、身元が要らない。主人公の口座だけの身元では橋の検問を通れないので、闇市場で偽の身元を買って橋を渡る。

## 属性

値は`game/data/jobs.json`にある。ほかのノードの概念に、次の属性を足す。

| 対象 | 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| 仕事 | 区画 | 区画のid | ○ | その仕事を請け負う区画 |
| 仕事 | 身元が要る | 真偽 | | 真なら、偽の身元を持っているときだけ就ける |
| 周 | 偽の身元を持っているか | 真偽 | ○ | その周に闇市場で偽の身元を買ったか |

仕事ごとの区画は次のとおりである。

| 仕事 | 区画 | 身元が要る | 身元が要るか要らないかの理由 |
| --- | --- | --- | --- |
| 運び屋 | 屋台通り | | 下層街で働く |
| ハッカー | 闇市場 | | 下層街の地下で働く。仕事はネット越しにする |
| 傭兵 | ヴァルデック義体の縄張り | ○ | 橋を渡って働く |
| 中枢サーバーへの侵入 | ヨミ・システムズの縄張り | | ネット越しにするので、橋を渡らない |

偽の身元の値段は300クレジットである。

## 不変条件

- [ ] 身元が要る仕事には、偽の身元を持っていない周には就けない
- [ ] 偽の身元は、周の終わりに失われ、次の周には持ち越さない
- [ ] 地図に示すいまの仕事の区画は、仕事に就いていないときは無い

## ライフサイクル

1. 周の始まりに、偽の身元は無い
2. 300クレジットを払うと、闇市場で偽の身元を買える。その周の間は持ち続ける
3. 偽の身元を持っていれば、身元が要る仕事に就ける
4. 周が終わると、偽の身元は失われる

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 仕事の区画 | 仕事を請け負う場所である区画。仕事ごとに1つ決まっている。仕事の間に起きるイベントの舞台とは別である | |
| 身元が要る仕事 | 仕事の区画が橋の向こうにあり、橋を渡って働くので、偽の身元を持っているときだけ就ける仕事。ネット越しにする仕事は橋を渡らないので、これにあたらない | |
