# 人物のイベント

## 定義

人物のイベントは、[登場人物](./dom-10-characters.md)の1人との話が進む[イベント](./dom-06-events.md)である。人物ごとに段が決まった順に並び、1つの周で進むのは、人物ごとに1段までである。そのため、人物との話は周をまたいで進む。前の段で選んだ[選択肢](./dom-06-events.md)によって、後の段の説明の文と、選べる選択肢が変わる。

## 属性

値は`game/data/events.json`にある。同じ人物のイベントは、並んだ順が段の順である。

ほかのノードの概念に、次の属性を足す。

| 対象 | 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| [イベント](./dom-06-events.md) | 人物 | 人物のid | | 持っていれば人物のイベントである |
| イベント | 要る断片 | 記憶の断片のid | | その[記憶の断片](./dom-08-memory-fragments-and-endings.md)が戻るまで、この段は起きない |
| イベント | 説明の書き分け | イベントのid | | 同じ人物の前の段のイベント。説明の文を、その段で選んだ選択肢ごとに書き分ける |
| [選択肢](./dom-06-events.md) | 前の選択の条件 | 「イベントのid.選択肢のid」 | | 同じ人物の前の段で、その選択肢を選んだときだけ出る |

転生しても残る状態として、人物のイベントで選んだ選択肢を、イベントごとに持つ。これが話の進み具合である。[最初からやり直す](./dom-05-rebirth.md)と、話の進み具合は無くなる。

周ごとの状態として、その周に人物のイベントが起きた人物を持つ。

人物のイベントは次の6つである。

| 人物 | 段 | 起きる仕事 | 中身 | 前の段で変わるもの |
| --- | --- | --- | --- | --- |
| レイ | 1 | ハッカー | レイが同じ被験体だと名乗る | なし |
| レイ | 2 | ハッカー | 被験体の名簿を一緒に抜き取るよう頼まれる | 説明の文 |
| レイ | 3 | ハッカー | 中枢へ一緒に行くかを尋ねられる | 説明の文と、「一緒に行くと約束する」（2段目で名簿を一緒に抜き取ったときだけ出る） |
| ジン | 1 | 運び屋 | ジンが私兵の張っている橋を避けるよう忠告する | なし |
| ジン | 2 | 傭兵 | 借金取りに囲まれたジンを助けるかを選ぶ | 説明の文 |
| ジン | 3 | 運び屋・傭兵 | ジンに昔の名前を告げるかを選ぶ。要る断片は「名前」 | 説明の文 |

次の値は属性ではなく導出値である。

```
人物の次の段 = 同じ人物のイベントのうち、並んだ順で、まだ選択肢を選んでいない最初のもの。すべて選んでいれば無い
```

## 不変条件

- [ ] 人物のイベントのうち起きうるのは、人物の次の段だけである
- [ ] 1つの周で起きる人物のイベントは、人物ごとに1つまでである
- [ ] 要る断片が戻っていない段は起きない
- [ ] 前の選択の条件を満たさない選択肢は、画面に出さない
- [ ] 前の選択の条件を持たず、選ぶ条件も持たない選択肢が、どの段にも1つ以上ある
- [ ] 話の進み具合は、転生しても失われない

## ライフサイクル

1. 仕事に就いている間にイベントが起きるとき、人物の次の段も、その仕事で起きるイベントの1つとして選ばれうる。その周にまだ話が進んでいない人物のものだけが選ばれうる
2. 人物のイベントが起きると、その人物は、その周に話が進んだ人物になる
3. 選択肢を選ぶと、その段で選んだ選択肢が話の進み具合に入る。選ぶ前に周が終わったら、その段は進まず、次の周にまた起きうる
4. 次の周から、その人物の次の段が起きうる

ジンは前の周の主人公を覚えていないので（[DOM-10](./dom-10-characters.md)）、ジンの段の書き分けは、主人公が前の体で覚えていることとして書く。レイは前の周を覚えているので、レイの台詞で前の段に触れる。

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 人物のイベント | 登場人物の1人との話が段の順に進むイベント。1つの周で進むのは、人物ごとに1段まで | |
| 段 | 人物のイベントの、話の中での順番 | |
| 人物の次の段 | その人物のイベントのうち、次に起きうる1つ | |
| 話の進み具合 | 人物のイベントで選んだ選択肢を、イベントごとに持ったもの。転生しても失われない | |
| 要る断片 | その段が起きるのに戻っている必要がある記憶の断片 | |
| 前の選択の条件 | その選択肢が出るのに要る、同じ人物の前の段で選んだ選択肢 | |
