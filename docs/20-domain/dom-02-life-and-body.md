# 周と体

## 定義

周は、[主人公](./dom-01-world.md)が1つの体で目覚めてから、その体の耐久が0になるまでの期間である。体は時間とともに劣化し、耐久が0になると周が終わる。

## 属性

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| 周の番号 | 整数 | ○ | 1から始まり、新しい体で目覚めるたびに1増える |
| 耐久 | 小数 | ○ | 0〜100。周の始まりは100 |
| 経過時間 | 秒 | ○ | 周の始まりから進んだ時間。周の始まりは0 |
| 生きているか | 真偽 | ○ | 耐久が0になったら偽になる |

劣化は属性ではなく導出値である。基本の劣化は毎秒0.4で、ほかに何も無ければ、体は250秒で使えなくなる。基本の劣化をどれだけ増減させるかは、[DOM-03](./dom-03-jobs-and-skills.md)が決めている。

## 不変条件

- [ ] 耐久は0以上、100以下である
- [ ] 生きている体の劣化は、0より大きい
- [ ] 生きていない体は、時間が進んでも何も変わらない
- [ ] 周の番号は減らない

## ライフサイクル

1. 新しい体で目覚める。耐久は100、経過時間は0になる
2. 時間が進むと、劣化の分だけ耐久が減る
3. 耐久が25以下になったとき、残りわずかだと知らせる
4. 耐久が0になると、周が終わる。その後の流れは[DOM-05](./dom-05-rebirth.md)が決めている

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 周 | 主人公が1つの体で目覚めてから、耐久が0になるまでの期間。番号で「第3周」のように呼ぶ | |
| 体 | 主人公の意識が入っているサイボーグの体。周ごとに新しくなる | |
| 耐久 | 体があとどれだけもつかを表す0〜100の値。0になると周が終わる | |
| 劣化 | 1秒あたりに耐久が減る量 | |
| 経過時間 | その周が始まってから進んだ時間 | |
