# 話の選び直し

## 定義

話の選び直しは、周をまたいで進む話の段のうち、すでに選択肢を選んだ段から、選択をやり直せるようにすることである。選び直した段と、それより後の段の選択は話の進み具合から消え、その段はまた起きうるようになる。どの選択をしても、選び直せば、同じデータのまま、どの段とどのエンディングにもたどり着ける。

## 属性

選び直しは、話の進み具合を変えるだけで、自分の値を持たない。

| 何が戻るか | 何が残るか |
| --- | --- |
| 選び直した段と、同じ話の後の段の選択 | 選んだときに得た評判・経験・クレジット |
| その選択で出ていた資料の追記と、分岐図の印 | 記録と物語文 |

選び直せるのは、どれか1つのエンディングに一度でもたどり着いてからである。たどり着いたかは、記録に残ったエンディングで決める。選び直しは、分岐図のタブで、選んだ段ごとに置いたボタンから行う。たどり着く前は、ボタンの代わりに、たどり着くと選び直せることを書いた1行を出す。代価は無い。

## 不変条件

- [ ] 選び直せるのは、すでに選択肢を選んだ段だけである
- [ ] どのエンディングにもたどり着いていないうちは、選び直せない
- [ ] 選び直すと、その段より前の段の選択は変わらない
- [ ] 選び直しても、評判・経験・クレジットと記録は変わらない

## ライフサイクル

1. 分岐図のタブで、選び直す段のボタンを押す
2. その段と、同じ話の後の段の選択が消え、分岐図と資料が選ぶ前の形に戻る
3. 次からの周で、その段がまた起きうる。1つの周に1段までという進み方は変わらない
