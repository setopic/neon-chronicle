# 勢力の評判

## 定義

評判は、[勢力](./dom-15-city-places-and-powers.md)の1つが主人公をどう見ているかを表す整数である。[イベント](./dom-06-events.md)で選んだ選択肢によって上下し、[転生](./dom-05-rebirth.md)しても残る。勢力は、体の替わる主人公を1人の人としては見分けない。評判は、勢力が[裏通りの診療所](./dom-09-consciousness-copy.md)から来る者をどう見ているかで、診療所から来る者が替わっても続く。評判が一定の値に届くと、その勢力に関わる選択肢を選べるようになる。

## 属性

評判を持つ勢力は、`game/data/factions.json`にある次の4つである。

| 勢力 | 企業か |
| --- | --- |
| ザンダー・ファミリー | 属さない |
| 屋台組合 | 属さない |
| ヨミ・システムズ | 企業 |
| ヴァルデック義体 | 企業 |

ほかのノードの概念に、次の属性を足す。

| 対象 | 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| 選択肢 | 評判の増減 | 勢力ごとの整数 | | 選んだときに、その勢力の評判に足す値。負なら減らす |
| 選択肢 | 評判の条件 | 勢力ごとの整数 | | 選ぶのに要る評判。その勢力の評判がこの値以上のときだけ選べる |

転生しても残る状態として、勢力ごとの評判を持つ。始めは0である。

評判の増減が付く選択肢は、主に下層街を舞台にしたイベントにある。屋台組合の人々を助けると屋台組合の評判が上がり、ザンダー・ファミリーの仕事を果たすとザンダー・ファミリーの評判が上がる。どちらかの側に付く選択肢では、片方が上がり、もう片方が下がる。

評判の条件が付く選択肢は、次の4つである。

| イベント | 選択肢 | 評判の条件 |
| --- | --- | --- |
| 路地の通行料 | ザンダー・ファミリーの名前を出す | ザンダー・ファミリー 3 |
| 遺体の取り立て | 屋台組合に話を通す | 屋台組合 3 |
| 闇市場の買い手 | 得意客として売る | ヴァルデック義体 3 |
| 盗電の線 | 監視係に話を付ける | ヨミ・システムズ 3 |

評判の条件は、[選ぶ条件](./dom-06-events.md)の1つとして扱う。選ぶ条件のある選択肢の数え方（[DOM-21](./dom-21-challenges.md)の縛りなど）では、評判の条件だけを持つ選択肢も、選ぶ条件のある選択肢に入る。

## 不変条件

- [ ] 評判は、-10以上10以下である
- [ ] 評判は、イベントで選択肢を選んだときにだけ変わる
- [ ] 評判は、転生しても失われない。最初からやり直すと、すべて0に戻る

## ライフサイクル

1. 最初の周の始まりに、どの勢力の評判も0である
2. 評判の増減が付く選択肢を選ぶと、その勢力の評判が変わる
3. 評判が評判の条件に届くと、その選択肢を選べるようになる。体の状態の欄に、0でない評判が出る
4. 転生しても、評判はそのまま次の周へ持ち越す

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
