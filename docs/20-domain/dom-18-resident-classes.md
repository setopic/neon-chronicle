# 住民の階級と暮らし

## 定義

[ネオン・シティ](./dom-01-world.md)に住む人々が、どの階級に属し、何で稼ぎ、どこから来て、どう行き来するかである。[企業区画](./dom-15-city-places-and-powers.md)と[下層街](./dom-15-city-places-and-powers.md)の暮らしを、身元と橋でつなぐ。どれも文だけで、ゲームの数値は持たない。

## 属性

企業区画に住む階級は、次の3つである。どれも、属する企業から身元を受け取る。

| 階級 | 住まい | 何をしているか | どこから来るか |
| --- | --- | --- | --- |
| 重役 | 自社の本社ビルの上の階 | 社を動かす | 社員から引き上げられる |
| 社員 | 自社の縄張りの[社宅](./dom-15-city-places-and-powers.md) | 研究・事務・工場の監督など、社の仕事をする | 多くは、社宅で生まれ育った社員の子である |
| [私兵](./dom-15-city-places-and-powers.md) | 自社の縄張りの社宅 | 自社の縄張りを守る。モンフォール警備の隊員は、モンフォール警備の私兵である | 社員の子と、下層街から雇われた者 |

下層街の住人の稼ぎは、次のとおりである。店を持つ者のほかは、決まった店を持たずに稼ぐ。

| 稼ぎ | 何をしているか |
| --- | --- |
| 屋台・修理屋 | 屋台通りと下層街の奥で店を営む。[組合の台帳](./dom-15-city-places-and-powers.md)に載っている |
| 日雇い | 朝に橋を渡って、企業の工場で下働きをし、夜には下層街へ戻る。社員にはならず、社宅にも住まない |
| 拾い屋 | 企業区画から流れてくる廃品や、壊れた機械の部品を拾い、修理屋や闇市場へ売る |
| 屋台組合の手伝い | 屋台組合に雇われて、盗電の線を引いたり、雨水のタンクを手入れしたりする |
| 運び屋・ハッカー・傭兵 | 企業や闇市場から、1つずつ仕事を請け負う。傭兵は企業に雇われても、その社の身元を受け取らない |

身元は、ヨミ・システムズのネットに登録された、人ごとの記録である。クレジットは身元に付いた口座でやり取りし、身元の無い者は口座を持てない。身元の種類は次のとおりである。

| 身元 | 持つ人 | どう手に入れるか |
| --- | --- | --- |
| 社の身元 | 重役・社員・私兵 | 属する企業が登録する |
| 偽の身元 | クレジットを受け取る下層街の住人の多く | ハッカーが作り、闇市場で売られる。ヨミ・システムズの監視に見つかると、口座ごと消される |
| 身元なし | 下層街の住人の残り | 店の手伝いの代わりに食べ物を受け取るなど、クレジットを使わずに暮らす |

橋を見張るモンフォール警備は、渡る者の身元を確かめる。身元の無い者は、橋を渡れない。下層街の日雇いが工場へ通えるのは、偽の身元を持っているからである。各社は、工場の働き手が要るので、日雇いの偽の身元を問いたださない。

階級の行き来は、次の2つだけである。

| 向き | どうなるか |
| --- | --- |
| 企業区画から下層街へ | 社員や私兵は、解雇されると社の身元を消され、社宅を出されて、下層街へ下りる |
| 下層街から企業区画へ | 私兵に雇われて、社の身元を受け取る。日雇いや傭兵を続けても、社員にはなれない |

街には、裁判所が無い。人を裁いていたのは市で、[市の時代](./dom-17-city-history.md)が終わったときに無くなった。いまは、場所ごとに次の者が罰を決める。

| 場所 | 罰を決める者 | どう罰するか |
| --- | --- | --- |
| 各社の縄張り | その社。私兵が罰を与える | 社員は解雇する。外の者は縄張りの外へ放り出すか、私兵が撃つ |
| 橋と下層街 | モンフォール警備 | 捕まえた者に罰金を払わせる。払えない者は、身元を確かめたうえで下層街へ追い返す。牢屋は持たない |
| 屋台通りと下層街の奥 | 屋台組合 | 住人どうしのもめごとを仲裁する |
| 裏通りと闇市場 | ザンダー・ファミリー | ファミリーの決まりに逆らった者を、ファミリーが痛めつける |

下層街で起きるイベント「偽の身元」は、ハッカーの仕事の間に起き、日雇いの偽の身元を作り直す頼みである。

## 不変条件

- [ ] 社の身元を持つのは、重役・社員・私兵だけである
- [ ] 身元の無い者は、橋を渡れない
- [ ] 下層街から企業区画へ上がる道は、私兵に雇われることだけである
- [ ] 街には裁判所が無い

## ライフサイクル

階級と暮らしは、周をまたいでも変わらない。主人公は、[DOM-09](./dom-09-consciousness-copy.md)のとおり体ごとに新しい身元になり、どの階級にも属さない。

| 用語 | 意味 | 旧称 |

| 社員 | 企業に雇われて、社宅に住み、社の身元を持つ人。多くは社員の子である | |
| 日雇い | 偽の身元で橋を渡り、企業の工場で下働きをして、夜には下層街へ戻る住人 | |

| 社の身元 | 企業が、重役・社員・私兵のために登録する身元 | |
| 偽の身元 | ハッカーが作り、闇市場で売られる身元。ヨミ・システムズの監視に見つかると、口座ごと消される | |
| 解雇 | 企業が社員や私兵を辞めさせること。社の身元が消され、社宅を出される | |
