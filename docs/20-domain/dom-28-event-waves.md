# イベントの波

## 定義

イベントの波は、1つの周の中で、[イベント](./dom-06-events.md)の起きやすさに付く強弱である。危ない目が続くと緊張が高まり、ひと息つける間になって、イベントが起きにくく、穏やかなイベントばかりになる。体の耐久が0に近づくほど、イベントは起きやすくなる。

## 属性

周ごとの状態として、緊張を持つ。緊張は0以上の小数で、周の始まりは0である。

| 何が起きたか | 緊張の変わり方 |
| --- | --- |
| 耐久を減らす選択肢を選んだ | 減った耐久の分だけ上がる |
| 仕事に就いて1秒たった | 0.1下がる。0より下にはならない |

次の値は属性ではなく導出値である。

```
ひと息つける間 = 緊張が15以上のとき
起きやすさの倍率 = (1 + 0.5 × (1 - 耐久 ÷ 100)) × (ひと息つける間なら0.5、そうでなければ1)
イベントが起きる確率（1秒あたり） = 基本の確率 × 起きやすさの倍率
穏やかなイベント = 耐久を減らす選択肢を1つも持たないイベント
```

基本の確率は、DOM-06にある。ひと息つける間にイベントが起きるときは、いまの仕事で起きるイベントのうち、穏やかなイベントの中から選ぶ。穏やかなイベントが無ければ、ふだんと同じく全体から選ぶ。

## 不変条件

- [ ] 緊張は、周の始まりに0に戻る
- [ ] ひと息つける間に選ばれるイベントは、穏やかなイベントがあるときは、穏やかなイベントである
- [ ] 閉じていた時間を進めるときも、開いているときと同じ式で起きやすさが決まる

## ライフサイクル

1. 周の始まりに、緊張は0である
2. 耐久を減らす選択肢を選ぶたびに、緊張が上がる。緊張が15に届くと、ひと息つける間になったことがログに残り、体の状態の欄に出る
3. 仕事に就いている間、緊張は少しずつ下がり、15を下回るとひと息つける間が終わる
4. 耐久が減るほど、イベントは起きやすくなる

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 緊張 | その周に危ない目が続いた度合い。耐久を減らす選択肢で上がり、時間とともに下がる | |
| ひと息つける間 | 緊張が高く、イベントが起きにくく、穏やかなイベントが選ばれる間 | |
| 穏やかなイベント | 耐久を減らす選択肢を1つも持たないイベント | |
| 起きやすさの倍率 | 基本の確率に掛ける、緊張と耐久で決まる倍率 | |
