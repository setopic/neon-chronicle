# 記憶の断片とエンディング

## 定義

記憶の断片は、[主人公](./dom-01-world.md)が失った過去の記憶の一部である。周が終わったとき、その周のスキルのレベルが次の断片の条件を満たしていれば、断片が1つ戻る。断片は決まった順に戻り、[ヨミ・システムズ](./dom-01-world.md)が主人公の意識をデータにした経緯と、本当の体の在りかが少しずつ分かる。

断片がすべて戻ると、最後の仕事に就けるようになる。最後の仕事の間に起きるイベントには、エンディングの選択肢がある。エンディングの選択肢を選ぶと、その周が終わり、物語が終わる。エンディングは3つあり、どれになるかは選んだ選択肢で決まる。3つ目のエンディングの選択肢は、条件を満たしたときだけ出る（[DOM-29](./dom-29-day-of-waking.md)）。

## 属性

記憶の断片の属性は次のとおりである。値は`game/data/story.json`にあり、並んだ順が戻る順である。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 断片を区別する名前 |
| 断片の条件 | スキルごとのレベル | ○ | 周が終わったときに要るスキルのレベル。[就く条件](./dom-03-jobs-and-skills.md)と同じ形で書く |

エンディングの属性は、idだけである。値は`game/data/story.json`にある。

ほかのノードの概念に、次の属性を足す。

| 対象 | 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| [仕事](./dom-03-jobs-and-skills.md) | 断片がすべて要るか | 真偽 | | 真なら、記憶の断片がすべて戻るまで就けない。最後の仕事だけが真である |
| [選択肢](./dom-06-events.md) | エンディング | エンディングのid | | 選ぶと、ほかの結果を表さずに、その周を終える |
| [記録](./dom-05-rebirth.md) | たどり着いたエンディング | エンディングのid | | エンディングの選択肢で終わった周だけが持つ |

転生しても残る状態として、戻った記憶の断片を持つ。最初からやり直すと、戻った記憶の断片は無くなる。

次の値は属性ではなく導出値である。

```
次の断片 = 並んだ順で、まだ戻っていない最初の断片。すべて戻っていれば無い
たどり着いたエンディング = クロニクルの記録にある、たどり着いたエンディングの種類
```

たどり着いたエンディングを持つ記録の[物語文](./dom-07-chronicle-story.md)では、倒れた理由の句の代わりに、エンディングの句を使う。

## 不変条件

- [ ] 記憶の断片は、並んだ順にしか戻らない
- [ ] 戻った記憶の断片は、転生しても失われない
- [ ] 断片がすべて要る仕事には、記憶の断片がすべて戻るまで就けない
- [ ] エンディングの選択肢を選ぶと、クレジット・耐久・経験は変わらず、その周が終わる
- [ ] エンディングの選択肢で終わった周も、ほかの周と同じく、記憶ポイントを得て記録を1件残す

## ライフサイクル

1. 周が終わると、次の断片の条件を、その周の終わりのスキルのレベルで確かめる。満たしていれば、その断片が戻る。続く断片の条件も満たしていれば、それも同じ周で戻る
2. 記憶の断片がすべて戻ると、最後の仕事に就けるようになる
3. 最後の仕事の間に起きるイベントで、エンディングの選択肢を選ぶ。その周が終わり、記録にたどり着いたエンディングが入る
4. エンディングを見たあとも、転生して次の周を遊べる。ほかのエンディングを選ぶこともできる
5. エンディング「本当の体」にたどり着いたあとは、転生の画面から[第二部](./dom-34-part-two-life.md)へ進める

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 記憶の断片 | 主人公が失った過去の記憶の一部。周の終わりに、断片の条件を満たしていれば決まった順に戻る。転生しても失われない | |
| 断片の条件 | その記憶の断片が戻るのに要る、周の終わりのスキルのレベル | |
| 次の断片 | まだ戻っていない記憶の断片のうち、次に戻る1つ | |
| 本当の体 | 主人公が生まれ持った体。ヨミ・システムズに意識を抜き取られたあとも、中枢サーバーの奥で眠ったまま保存されている | |
| 中枢サーバー | ヨミ・システムズのネットの中心にあるサーバー。本当の体がここに保存されている | |
| 最後の仕事 | 記憶の断片がすべて戻ると就ける仕事。中枢サーバーへ侵入する | |
| エンディング | 物語の終わり方。本当の体に戻るもの、データのまま中枢サーバーに残るもの、眠らされている被験体をすべて目覚めさせるものの3つがある | |
| エンディングの選択肢 | 選ぶとエンディングにたどり着く選択肢。最後の仕事の間に起きるイベントにだけある | |
