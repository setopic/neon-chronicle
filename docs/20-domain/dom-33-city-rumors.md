# 街の噂

## 定義

噂は、[仕事の区画](./dom-24-job-districts-and-identity.md)の住人が話している街の様子を、ログに1行で出す文である。主人公が就いている[仕事](./dom-03-jobs-and-skills.md)の、仕事の区画の噂だけが出る。同じ仕事を2分続けるごとに1つ出し、[閉じていた時間](./dom-02-life-and-body.md)を進めている間は出さない。

噂は、主人公が仕事の合間に耳にしたことを伝えるだけで、ゲームの状態を変えない。[評判](./dom-22-faction-reputation.md)と[資料](./dom-14-city-and-people-profiles.md)の追記の出方によって、出る噂が増える。

## 属性

値は`game/data/rumors.json`にあり、並んだ順に出す。文は`game/lang/*.json`の`rumor.<id>.text`にある。

| 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| id | 文字列 | ○ | 噂を区別する名前 |
| 出る区画 | 区画のidの並び | ○ | この噂が出る仕事の区画。仕事のデータの`district`と同じ値を使う |
| 噂の出る評判 | 勢力ごとの整数 | | 正の値なら、その勢力の評判がこの値以上のときだけ出る。負の値なら、この値以下のときだけ出る |
| 噂の出る追記 | 資料の追記 | | その追記が資料に出ているときだけ出る |

噂は、仕事の区画ごとに次の人が話す。2つの企業の縄張りでは、同じ噂を出す。

| 仕事の区画 | 仕事 | 話す人 |
| --- | --- | --- |
| 屋台通り | 運び屋 | 屋台の主人、修理屋の客、屋台組合の集会に出る住人 |
| 闇市場 | ハッカー | 闇市場の売り手と常連 |
| ヴァルデック義体の縄張り、ヨミ・システムズの縄張り | 傭兵、中枢サーバーへの侵入 | 企業の私兵、社員、見張り |

噂の出る評判を持つ噂は、勢力ごとに2つある。評判が3以上なら、その勢力が[裏通りの診療所](./dom-09-consciousness-copy.md)から来る者をかばう噂が出る。評判が-3以下なら、その勢力が診療所から来る者を警戒する噂が出る。勢力ごとに、その勢力が出入りする仕事の区画で出す。

噂の出る追記を持つ噂は、次の2つである。

| 噂 | 噂の出る追記 | 出る区画 |
| --- | --- | --- |
| 保護料の台帳 | 資料「屋台組合」の追記「屋台通りの対立」 | 屋台通り |
| 床下の管路の見張り | 資料「橋を架けた技師たち」の追記「変電所」 | 2つの企業の縄張り |

その周に聞いた噂は、周の状態として持つ。

## 不変条件

- [ ] 噂は、就いている仕事の区画の噂だけが出る
- [ ] 閉じていた時間を進めている間は、噂を出さない
- [ ] 噂は、ゲームの状態を変えない。資料にも追記を足さない
- [ ] 噂の出る追記を持つ噂は、その追記が資料に出るまで出ない

## ライフサイクル

1. 周の始まりには、その周に聞いた噂は無い
2. 仕事に就いて2分続けると、その仕事の区画でいま出せる噂のうち、その周にまだ聞いていないものを1つ出す。噂の出る評判か噂の出る追記を持つ噂を先に出し、その中ではデータに並んだ順に出す
3. 仕事を替えると、2分を数え直す
4. その仕事の区画の噂をすべて聞いたら、その区画の噂を聞いていないものとして、最初から聞き直す
5. 次の周に目覚めると、その周に聞いた噂は無くなる
