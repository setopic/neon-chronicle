# 街の地図

## 定義

街の地図は、[街の場所](./dom-15-city-places-and-powers.md)の区画と橋の配置を、プレイヤーがいつでも見られるように描いた図である。[資料](./dom-14-city-and-people-profiles.md)と同じ「街と人物」の画面にあり、資料とはタブで切り替える。読むだけで、ゲームの状態を変えない。

## 属性

地図は、街を上から見た地形として描く。配置はDOM-15の図と同じにする。上に高台の企業区画と4つの縄張り、その下に崖と排水路、下に低い土地の下層街の区画と闇市場を置く。3本の橋は、高台から排水路をまたいで下層街へ下りる。企業区画には「高台」、下層街には「低い土地」と添える。

高台と低い土地は色で分け、道路を縁取りした帯、排水路を青、崖を崖の記号（縁の線に低いほうへ向けた歯を並べたもの）、縄張りの境を点線で描く。表通りは太く、路地は細くする。橋は、道路が崖と排水路をまたぐところの両側に線を引き、両端を外へ開いて示す。施設は丸い印と名前で示す。区画の名前は、箱で囲まずに地図の上に置く。闇市場は地下にあるので、点線で囲む。地図の隅に凡例を置き、記号が何を表すかを示す。

描くものと、施設の印は次のとおりである。名前は言語ファイルにあり、データは持たない。

| 描くもの | 施設の印・添える文 | 出る条件 |
| --- | --- | --- |
| ヨミ・システムズの縄張り | 本社ビル、発電所、変電所（オルセン橋のたもと） | 最初から |
| ヨミ・システムズの縄張り | 中枢サーバー（本社の地下） | 記憶の断片「中枢サーバー」が戻ってから |
| ヴァルデック義体の縄張り | | 最初から |
| モンフォール警備の縄張り | 本社（橋を見張る） | 最初から |
| リンドホルム食品の縄張り | 合成食の工場、浄水場 | 最初から |
| 裏通り | 裏通りの診療所、闇市場の入口 | 最初から |
| 屋台通り | | 最初から |
| 下層街の奥 | 小屋とコンテナ（添える文） | 最初から |
| 闇市場 | 下層街の地下（添える文） | 最初から |
| オルセン橋・ヴィラール橋・ハーゲン橋 | | 最初から |
| 排水路 | | 最初から |

## 不変条件

- [ ] 地図の区画・橋・つながりは、DOM-15の図と食い違わない
- [ ] 中枢サーバーは、記憶の断片「中枢サーバー」が戻るまで、地図に出ない
- [ ] ヨミ・システムズが主人公の意識をデータにしたことは、地図に出さない
- [ ] 地図は読むだけで、ゲームの状態を変えない

## ライフサイクル

1. 最初の周から、中枢サーバーを除いた地図が見られる
2. 記憶の断片「中枢サーバー」が戻ると、ヨミ・システムズの縄張りに中枢サーバーが加わる。転生しても消えない
3. 最初からやり直すと、戻った記憶の断片が無くなるので、中枢サーバーも地図から消える
