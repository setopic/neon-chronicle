# 街の場所と勢力

## 定義

[ネオン・シティ](./dom-01-world.md)の中で、[仕事](./dom-03-jobs-and-skills.md)と[イベント](./dom-06-events.md)の舞台になる場所と、街を動かしている勢力である。勢力は、[企業](./dom-01-world.md)の各社と、企業に属さない人々の集まりからなる。どれも文だけで、ゲームの数値は持たない。

## 属性

場所は次の3つである。

| 場所 | どんなところか | 出る仕事とイベント |
| --- | --- | --- |
| 下層街 | 企業区画の高層ビルの下に広がる、日の当たらない街。[裏通りの診療所](./dom-09-consciousness-copy.md)も、運び屋の走る路地もここにある | 運び屋、「路地の通行料」「薬の配達」 |
| 闇市場 | 下層街の地下にある市場。盗んだデータ、体の部品、インプラントが売り買いされる。企業の買い手も、身元を隠して出入りする | ハッカー（盗んだデータを売る先）、「闇市場の買い手」 |
| 企業区画 | 企業の高層ビルが並ぶ区画。社ごとに縄張りが分かれ、私兵が守っている。下層街とは数本の橋でつながる | 傭兵、「待ち伏せ」「ジンの忠告」「変電所の奪い合い」 |

勢力は次の5つである。

| 勢力 | 企業か | 何をしているか |
| --- | --- | --- |
| [ヨミ・システムズ](./dom-01-world.md) | 企業 | 神経接続のチップと、街のネットの基幹を売っている |
| カナエ義体 | 企業 | 義体とインプラントを作って売っている。神経接続のチップでは、ヨミ・システムズと客を奪い合っている |
| シロガネ警備 | 企業 | 私兵を貸し出す警備会社。どの企業にも雇われ、企業区画の橋と縄張りを守る |
| 下層街の住人 | 属さない | 屋台や修理屋を営みながら、下層街で暮らしている。企業同士の争いのしわ寄せを受ける |
| 路地のチンピラ | 属さない | 下層街の路地にたむろして、通る者から金を取る。小さな集まりで、顔の利く名前には逆らわない |

企業は互いに製品と縄張りを奪い合っている。ハッカーが盗むデータは、たいてい別の企業へ売られる。傭兵の仕事の多くは、ある企業に雇われて別の企業の縄張りを荒らすものである。

## 不変条件

- [ ] 企業は互いに競い合っている。1社がほかの社を従えてはいない
- [ ] ヨミ・システムズが主人公の意識をデータにしたことは、[記憶の断片](./dom-08-memory-fragments-and-endings.md)「契約書」が戻るまで、画面に出さない
- [ ] 下層街の住人と路地のチンピラは、どの企業にも属さない

## ライフサイクル

場所と勢力は、周をまたいでも変わらない。
