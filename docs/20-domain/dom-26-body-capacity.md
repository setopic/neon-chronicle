# 体の容量とインプラントの取り外し

## 定義

体の容量は、1つの[体の種類](./dom-11-body-types.md)に組み込める[インプラント](./dom-04-implants.md)の量の上限である。インプラントはそれぞれ大きさを持ち、組み込んでいるインプラントの大きさの合計は、体の容量を超えられない。組み込んだインプラントは外せるが、払ったクレジットは戻らない。

## 属性

値は`game/data/bodies.json`と`game/data/implants.json`にある。ほかのノードの概念に、次の属性を足す。

| 対象 | 属性 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| 体の種類 | 容量 | 整数 | | 組み込めるインプラントの大きさの合計の上限。無いときは上限を設けない |
| インプラント | 大きさ | 整数 | | 体の容量のうち、そのインプラントが使う量。無いときは1 |

体の種類ごとの容量は次のとおりである。

| 体の種類 | 容量 |
| --- | --- |
| 汎用の体 | 3 |
| 作業用の体 | 4 |
| 戦闘用の体 | 5 |
| 試作の体 | 2 |

インプラントは次の7つである。

| インプラント | 値段 | 大きさ | 効果 |
| --- | --- | --- | --- |
| 神経加速チップ | 100 | 1 | 経験 +50% |
| 痛覚抑制 | 300 | 1 | 体の劣化 -15% |
| 強化骨格 | 500 | 2 | 体の劣化 -30% |
| 相場読みの義眼 | 600 | 1 | 稼ぎ +20% |
| 反射配線 | 800 | 2 | 稼ぎ +30%、体の劣化 +10% |
| 記憶補助野 | 1500 | 2 | 経験 +40% |
| 信用スコア偽装 | 2000 | 0 | 稼ぎ +50%。次の周にも残る |

信用スコア偽装は、体ではなく、稼ぎを受け取るミオの診療所の口座の取引記録に組み込むので、大きさは0である。

次の値は属性ではなく導出値である。

```
使っている容量 = 組み込んでいるインプラントの大きさの合計
```

## 不変条件

- [ ] 使っている容量に、組み込むインプラントの大きさを足した値が体の容量を超えるときは、組み込めない
- [ ] インプラントを外しても、払ったクレジットは戻らない
- [ ] 生きていない体からは、インプラントを外せない

## ライフサイクル

1. 周の始まりに、使っている容量は、残るインプラントの大きさの合計である
2. インプラントを組み込むと、使っている容量が増える。容量が足りなければ組み込めない
3. インプラントを外すと、使っている容量が減り、その効果も無くなる
4. 周が終わると、残るインプラント以外は体と一緒に失われる

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| 体の容量 | 体の種類ごとの、組み込めるインプラントの大きさの合計の上限 | |
| 大きさ | インプラントが体の容量のうちに使う量 | |
| 外す | 組み込んだインプラントを、体から取り除くこと。代金は戻らない | |
