# 登場人物

## 定義

[主人公](./dom-01-world.md)のほかに、物語に名前を持って出てくる人物である。4人いて、それぞれが[反復計画](./dom-09-consciousness-copy.md)と、[記憶の断片](./dom-08-memory-fragments-and-endings.md)・[エンディング](./dom-08-memory-fragments-and-endings.md)のどれかに関わる。

## 属性

| 人物 | 役 | 主人公との関係 | 明かされるところ |
| --- | --- | --- | --- |
| ミオ | 裏通りの闇医者 | 毎周、目覚めた主人公を迎える。主人公の意識の写しの読み込み先を書き換えた本人で、主人公を前の周から覚えている唯一の人物である | 記憶の断片「白い部屋」の技師の1人だったこと。償いとして主人公を逃がした |
| ジン | 仲介屋 | 主人公に仕事を回す。体が毎周違うので、毎周初めて会う相手として話す | 記憶の断片「名前」で主人公の名前を呼ぶ昔の仲間であること |
| レイ | ハッカー | イベント「同業者の挑戦」の相手。主人公と同じ被験体で、前の周を覚えている | エンディング「ネットの亡霊」で、主人公が解き放つ相手の1人であること |
| 九条 | 企業の研究部門の責任者 | 反復計画を動かしている | イベント「中枢の扉」で初めて姿を見せる |

人物が画面に出るところは次のとおりである。

| 人物 | 画面に出るところ |
| --- | --- |
| ミオ | 転生の画面のミオの一言と体の種類を選ぶ文、最初の周の目覚め、記憶の断片「白い部屋」「計画書」 |
| ジン | 周の始まりのジンの依頼（[DOM-12](./dom-12-jin-requests.md)）、仕事を始めたときのログ、最初の周の目覚め、記憶の断片「名前」、ジンの人物のイベント（[DOM-13](./dom-13-character-events.md)） |
| レイ | レイの人物のイベント（[DOM-13](./dom-13-character-events.md)） |
| 九条 | まだ名前では出ない |

ミオの一言は、倒れた理由（体の限界かイベントか）と周の番号（第1周・第9周まで・第10周から）で変わる。エンディングにたどり着いた周には出ない。

## 不変条件

- [ ] 主人公を前の周から覚えているのは、ミオと、被験体のレイだけである
- [ ] ジンが主人公に気づくのは、記憶の断片「名前」が戻ったあとである
- [ ] 九条が姿を見せるのは、最後の仕事の間だけである

## 用語

| 用語 | 意味 | 旧称 |
| --- | --- | --- |
| ミオ | 裏通りの診療所の闇医者。主人公の意識の写しの読み込み先を書き換え、毎周主人公を迎える | |
| ジン | 主人公に仕事を回す仲介屋。主人公の昔の仲間だが、体が変わった主人公に気づかない | |
| レイ | 主人公と同じ被験体のハッカー。前の周を覚えている | |
| 九条 | 企業の研究部門の責任者。反復計画を動かしている | |
| ミオの一言 | 転生の画面で、周を終えた主人公にミオがかける1文から2文の台詞 | |
