# 主人公は体ごとに口座だけの身元を持つことにする

- 日付: 2026-10-20
- 状態: stable

## 背景

設計文書の点検で、主人公の身元とお金の決まりが互いに食い違っていると分かった（issue #146）。

[DOM-09](../20-domain/dom-09-consciousness-copy.md)は、体ごとに身元が新しくなり、前の身元の口座は凍結されるとしていた。[DOM-18](../20-domain/dom-18-resident-classes.md)の身元は、社の身元・偽の身元・身元なしの3種類だけで、体ごとの身元はどれにも当たらなかった。[DOM-24](../20-domain/dom-24-job-districts-and-identity.md)は、主人公は身元を持たないので偽の身元を買うとしていた。信用スコア偽装は「ネット上の身元」に組み込むので次の周にも残るとしていたが、その身元は体ごとに替わる。

ほかに、闇医者は部品を売る側なのにミオが部品を買うこと、偽の身元の監視が主人公を見逃す理由、体1つが偽の身元より安いことも挙がっていた。

## 決定

[ADR-0010](./adr-0010-characters-in-screen-text.md)の8つのうち、7つはそのまま引き継ぐ。

1. ミオの台詞は、転生の画面にだけ出す（そのまま）
2. ミオの一言は、倒れた理由と周の番号で選ぶ（そのまま）
3. 最初の周の目覚めのログで、ミオに「仕事ならジンが回してくれる」と言わせる（そのまま）
4. ジンは、仕事を始めたときのログに出す（そのまま）
5. 記憶の断片「白い部屋」「名前」「計画書」の書き足し（そのまま）
6. 転生の画面の要約と、永続強化の見出しの横の文（そのまま）
7. 信用スコア偽装が残る理由（改める。下記の3）
8. レイと九条は、この決定では画面に出さない（そのまま）

この決定で、次のことを決める。

1. 主人公は、体ごとに口座だけの身元を持つ。口座だけの身元は、裏通りの診療所が目覚めた体ごとに作り、体に結びつけて登録する。体が倒れると口座ごと凍結される。橋の検問は通れないので、橋の向こうで働くには、これまでどおり闇市場で偽の身元を買う。DOM-18の身元の表に4つ目の行として足す。
2. 偽の身元のうち、ヨミ・システムズの監視が消すのは、橋を渡る回数や稼ぎが目立つものである。口座だけの身元は、体が倒れるとすぐに使えなくなるので、監視は追わない。
3. 信用スコア偽装が次の周に残るのは、稼ぎを受け取るミオの診療所の口座の取引記録に組み込むからとする。信用スコアは、口座の取引記録から付く点数として、DOM-18に書く。
4. 闇医者は、死者から取り出した部品を売るだけでなく、手術に使う部品を闇市場から買い戻すこともある。
5. 体1つの値段は、遊びの釣り合いのまま残す。ミオは自分で死者から取り出した部品も使うので、闇市場の値より安く組み立てられる。第1周の体は、ミオが自分の金で用意した。

## 理由

口座だけの身元にしたのは、すでにある決まりの多くをそのまま使えるからである。体ごとに口座が凍結されてクレジットが0に戻ること（DOM-09）、橋を渡る仕事に偽の身元が要ること（DOM-24）、稼ぎがミオの診療所の口座を通ること（[DOM-11](../20-domain/dom-11-body-types.md)）が、どれも数値を変えずに成り立つ。

信用スコア偽装をミオの口座に付けたのは、周をまたいで残る口座が、ほかに無いからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 体ごとの身元をやめ、主人公は身元なしとする | 身元の無い者は口座を持てない（DOM-18）ので、クレジットが0に戻る理由を新しく作り直す必要がある |
| ネット上の身元を、周をまたいで続く作業用の名前として別の語で定義する | 新しい語が1つ増え、口座の付く身元との違いを、遊ぶ人に説明する場面が無い |
| ミオは部品を買わず、遺体から自分で取るだけとする | ミオが部品を買うのでヨミ・システムズが気づかないという理由（[ADR-0030](./adr-0030-test-subjects-and-bodies.md)）が使えなくなる |

## 影響

DOM-18の身元の表と用語表に、口座だけの身元と信用スコアが加わる。偽の身元の監視の説明は、目立つものだけを消すと改める。DOM-24の主人公が偽の身元を買う理由、DOM-09とDOM-26の信用スコア偽装が残る理由、DOM-19の闇医者の用語、DOM-11の体の組み立て方を、この決定に合わせて書き直す。数値は変わらない。

画面の文言（信用スコア偽装の説明など）を直す必要があるかは、issue #136で確かめる。

## 見直しの条件

主人公の身元を、物語の中で奪われたり取り戻したりする場面を足すときに見直す。
