# 倒れた理由の句をイベントごとに書く

- 日付: 2026-10-18
- 状態: stable

## 背景

[ADR-0005](./adr-0005-chronicle-story.md)は、イベントで倒れた周の物語文を「（イベントの名前）で倒れた」で終えると決めた。イベントの名前は「待ち伏せ」「怪しい荷物」のような名詞なので、「待ち伏せで倒れた」「怪しい荷物で倒れた」のように、何に倒されたのかが分からない不自然な文になっていた。[ADR-0010](./adr-0010-characters-in-screen-text.md)でミオの一言にも倒れ方を入れたため、同じ不自然さが転生の画面に2回出るようになった（issue #35）。

## 決定

ADR-0005の4つの決定のうち、1つめの一部だけを改める。

1. 物語文を主な仕事の句・最後に選んだ選択肢の句・倒れた理由の句から組み立てる（そのまま）。倒れた理由の句は、イベントの名前を差し込むのをやめ、イベントごとに書いた句（言語ファイルの`event.<id>.fall`）を使う（改める）。劣化で倒れたときの「体の限界で倒れた」は、そのまま使う
2. 記録にはidを残し、文は表示するたびに組み立てる（そのまま）
3. クロニクルに残った選択肢の種類ごとに、経験の効果を0.02足す（そのまま）
4. 転生の画面での物語文とクロニクルの見せ方（そのまま）

倒れたときの句は、何に倒されたのかが分かるように書く（「企業の私兵の待ち伏せに遭って倒れた」）。句が要るのは、耐久を減らす選択肢を持つイベントだけである。ミオの一言のうち、倒れ方を言う台詞も同じ句を使う。

## 理由

イベントの名前は、イベントの画面の見出しとして付けたもので、文の中に差し込む前提で付けていない。名前に合わせて「〜に遭って倒れた」のようなつなぎを1つ決めても、「怪しい荷物」「路地の通行料」には合わない。句をイベントごとに書けば、どのイベントでも自然な文にできる。選択肢の句（`event.<id>.<選択肢>.chronicle`）をすでにイベントごとに書いているので、書く手間の増え方は小さい。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| つなぎ方を「（イベントの名前）に遭って倒れた」に変える | 「怪しい荷物に遭って倒れた」のように、合わないイベントが残る |
| イベントの名前を、文に差し込める形に改める | 名前はイベントの画面の見出しでもあり、見出しとして読みにくくなる |
| 倒れた理由をイベントの名前で言わず、「イベントで倒れた」とだけ書く | 周ごとの倒れ方の違いが物語文から消える |

## 影響

[DOM-07](../20-domain/dom-07-chronicle-story.md)の「倒れた理由の句」を、イベントごとの句に改める。言語ファイルから`chronicle.end_event`を外し、耐久を減らすイベント5つに`event.<id>.fall`を足す。`game/ci/check_data.py`は、耐久を減らす選択肢を持つイベントに、この句があるかを見る。

イベントを足すMODは、耐久を減らす選択肢があれば`event.<id>.fall`も置く。

## 見直しの条件

イベントの数が増えて、句を書く手間が問題になったら、句を省いたイベントの書き方（既定の句）を決める。
