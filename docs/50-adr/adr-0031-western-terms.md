# 日本のやくざや的屋に寄った語を、欧米の街でも通じる語に改める

- 日付: 2026-10-19
- 状態: stable

## 背景

ネオン・シティは、ヨミ・システムズのほかは、欧米の名前の企業と人物でできている。それなのに、下層街の用語には、日本のやくざや的屋の言葉と、日本の火葬の言い方が混ざっていた。そのため、街の世界観とずれて読める。ギャングの呼び名は、[ADR-0029](./adr-0029-zander-family-name.md)でザンダー・ファミリーに改めてある。残りの語を、issue #72で見直した。

## 決定

次の4つの語を改める。英語の文は、もとからずれが無いので変えない。

| 改める語 | 新しい語 | 英語（変えない） |
| --- | --- | --- |
| みかじめ | 保護料 | protection money |
| 場所代 | 出店料 | stall fee |
| 路地のチンピラ（チンピラ） | 路地のごろつき（ごろつき） | thugs |
| 焼き場 | 火葬場 | crematorium |

改めるのは語だけで、指す物事は変えない。[ADR-0026](./adr-0026-union-ledger-and-housing.md)・[ADR-0028](./adr-0028-life-course-and-body-parts.md)・ADR-0029の決定は、そのまま生きている。そのため、これらのADRは置き換えない。確定したADRの本文は、古い語のまま残す。

イベント「みかじめの運び」は、「保護料の運び」と呼ぶ。

屋台・屋台通り・屋台組合、社員・社宅、親方、闇医者、縄張り、日雇い、拾い屋は残す。九条は、ヨミ・システムズの人物なので、アジアの名前のままにする。

## 理由

新しい4つの語は、欧米の物事を訳すときにもふつうに使う語で、意味の幅も元の語と同じである。英語の文と並べても、同じ物事を指していると分かる。

残す語は、欧米の物事を訳すときにも使う語である。言い換えると、かえって意味がぼやける。

ADRを置き換えずに語だけを改めるのは、決定の中身が変わらないからである。古い語は、用語表の旧称に書く。そうすれば、依存している文書で古い語を使ったときに、`check`が`G013`で見つける。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 語をそのまま残す | 欧米の名前の街に、日本のやくざや的屋の言葉が混ざって読める |
| 改めた語ごとに、ADR-0026・ADR-0028・ADR-0029を置き換える | 決定の中身は変わらないので、置き換えると、生きている決定を指す参照の張り替えだけが増える |
| チンピラを「ギャング」と呼ぶ | 路地のごろつきは1つの組織ではなく、ギャングのザンダー・ファミリーと区別がつかなくなる |

## 影響

[DOM-15](../20-domain/dom-15-city-places-and-powers.md)の用語表の、みかじめ・場所代・路地のチンピラを、保護料・出店料・路地のごろつきにし、旧称に元の語を書く。[DOM-19](../20-domain/dom-19-resident-life-course.md)の焼き場も、同じように火葬場にする。両方の本文の語も直す。

`game/lang/ja.json`の資料（[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)）とイベントの文の語を直す。英語の文は変えない。

## 見直しの条件

下層街の住人が、自分たちの言葉で物事を呼ぶ場面を画面に出すときに、呼び名を見直す。
