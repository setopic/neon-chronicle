# 第二部の第3章で、隠れ家に設備を足し、逃げてきた被験体を匿う

- 日付: 2026-10-21
- 状態: stable

## 背景

[ADR-0075](./adr-0075-part-two-after-reclaim.md)は、第二部の第3章の題を「隠れ家」、新しい遊び方を拠点を育てることとした。筋は、屋台組合と組んで追っ手から身を隠す拠点を下層街に作り、反復計画から逃げてきた被験体を匿うものである（issue #183）。[ADR-0076](./adr-0076-part-two-chapter-name.md)は、見直しの条件で、第3章で仲間を拠点の仕事にも任せるかを決めるとした。

第3章を作るには、拠点で何が育ち何に効くか、匿う被験体がエンディング「目覚めの日」とどう違うか、第3章の長さと章の目標を決める必要があった。

## 決定

1. 拠点は、屋台組合の台帳に載せてもらった下層街の奥の古い貯水槽とし、隠れ家と呼ぶ。隠れ家は、章の出来事の選択肢で得る。得た隠れ家は、第二部のあいだ持ち続ける。
2. 隠れ家には、設備をクレジットで1段ずつ足す。設備は次の4つとする。

   | 設備 | 段 | 効き目 |
   | --- | --- | --- |
   | 寝床 | 3 | 匿える人数が、段ごとに2・4・6人になる。休んだときの体調の戻りが、住まいの2倍に代わって3倍になる |
   | 診療台 | 1 | 休んでいる間に、怪我が1秒ごとに0.1治る |
   | 作業場 | 1 | 仲間の分け前が、4割から2割になる |
   | 盗電の線 | 1 | 1日の暮らしの代金のうち、住まいの代金が無くなる |

3. 匿う被験体は、反復計画の施設から、使い捨ての体のまま自分で逃げてきた意識の写しとする。名前は付けず、人数で数える。隠れ家を得た日から2日ごとに、寝床に空きがあれば1人ずつ逃げてくる。匿った被験体は、1人ごとに屋台組合の屋台を手伝って1秒あたり3クレジット稼ぎ、1日に30クレジットの食べる分の代金がかかる。匿った被験体は減らない。
4. 匿う被験体は、エンディング「目覚めの日」で目覚めさせる人々とは別の人々とする。「目覚めの日」は、中枢サーバーの奥で眠らされている本当の体を全員目覚めさせる結末である。第3章の被験体は、体を取り戻せないまま逃げてきた数人で、隠れ家はかくまうだけである。体を取り戻す話は、第4章「写し」につなげる。
5. 仲間は、隠れ家の仕事には任せない。仲間に任せるのは、これまでどおり仕事だけとする。
6. 第3章の章の目標は、屋台組合に100000クレジットを払って台帳に場所を載せてもらう、格闘をLv24にする（追っ手から隠れ家を守る）、寝床を3段にする、被験体を6人匿う、の4つとする。章の目標の種類に、設備（設備の段が書いた値以上）と匿った人数（書いた人数以上）を足す。章の出来事は、屋台組合の世話役の頼み、隠れ家を得る出来事、追っ手の手配書、逃げてきた被験体が施設のことを話す出来事、章の終わりの5つで、この順に起きる。章の終わりで、研究部門が主人公の意識の写しを中枢サーバーから持ち出したことが分かり、第4章へつなぐ。
7. 設備の値段は、寝床が150000・400000・1000000、診療台が250000、作業場が600000、盗電の線が5000クレジットとする。
8. 第3章の長さは、人が遊んで約2時間とする。`game/ci/part_two.gd`は、第2章に続けて第3章を終えるまで遊び、第3章にかかったゲーム内の時間が55分より短いか90分より長いときに失敗とする。人の時間への換算は、ADR-0075の決定9と同じ比を使う。

ADR-0075とADR-0076は置き換えない。第二部の章の組み立て、第1章と第2章の長さ、仲間の決まりは、そのまま生きている。

## 理由

拠点を設備の組み合わせにしたのは、どの設備から足すかを選ぶ遊びにするためである。設備を1つにまとめてレベルだけを上げる形では、払うたびに同じものが育つだけで、選ぶことが無い。4つの設備は、それぞれ第1章と第2章で入れた体調・怪我・仲間・暮らしの代金に効くので、新しい値を増やさずに済む。

被験体を、使い捨ての体のまま逃げてきた写しにしたのは、「目覚めの日」と重ねないためである。「目覚めの日」を選ばなかった人にも筋が通り、第4章の写しの話へつながる。名前を付けないのは、[DOM-10](../20-domain/dom-10-characters.md)の名前を持つ人物を増やさないためである。人数で数えると、寝床の段と匿う人数の目標を同じ単位で書ける。

仲間を隠れ家の仕事に任せないのは、新しい仕組みを、章ごとに1つに保つためである。仲間に新しい任せ先を足すと、第3章で入る仕組みが拠点と仲間の2つになる。

第3章の目標と長さは、自動で遊ぶ検査で決めた。検査では、第3章は68分（69日）で終わり、人の時間で約113分にあたる。第3章では、設備の値段が長さを決める。設備を安くして格闘の目標をLv28にした試しでは、クレジットが380万余ったまま、レベル上げを待つだけの時間が延びて103分かかった。そのため格闘の目標を下げ、設備の値段で長さを出した。

盗電の線を5000クレジットにしたのは、第3章の稼ぎに比べて、住まいの代金（1日60クレジット）が小さいからである。値段を上げても、払った分を取り戻せない。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 設備を1つにまとめ、拠点のレベルだけを上げる | 作る量は少ないが、どの設備から足すかを選ぶ遊びにならない |
| 仲間を隠れ家の仕事にも任せる | 第3章で入る仕組みが、拠点と仲間の2つになる |
| 匿う被験体を、中枢サーバーで眠らされている本当の体の人々にする | エンディング「目覚めの日」と同じ筋になる |
| 匿う被験体に名前を付ける | 名前を持つ人物が増え、1人ずつ話を書くことになる |
| 格闘の目標をLv28にして長さを出す | クレジットが余り、レベル上げを待つだけの時間が延びる |

## 影響

[DOM-34](../20-domain/dom-34-part-two-life.md)に、第二部の状態の隠れ家・設備・匿った被験体、設備の属性、章の目標の2つの種類、隠れ家を得る選択肢の属性、休んだときの戻りと暮らしの代金と分け前の式の変更を足す。

第二部の画面では、体の状態の欄に、匿っている人数と、設備ごとに次の段を足すボタンが1行に並ぶ。`game/data/part_two.json`に、第3章と設備を置く。`game/ci/part_two.gd`は第3章まで遊び、`game/ci/layout.gd`は、仲間を3人迎えて隠れ家を得た第3章の画面が1280x720に収まるかを見る。

## 見直しの条件

自動で遊ぶ検査で、第3章が55〜90分の範囲を外れたら、設備の値段を見直す。実際に遊んだ人が、設備を足す順をどれも同じにするなら、設備ごとの効き目か値段を見直す。匿った被験体の稼ぎと食べる分の代金は、第3章の稼ぎに比べて小さい。被験体の人数が遊び方に効いていないと分かったら、稼ぎと代金を見直す。
