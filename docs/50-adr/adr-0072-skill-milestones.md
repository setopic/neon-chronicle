# スキルに節目を置き、下の仕事に戻る理由にする

- 日付: 2026-10-20
- 状態: stable

## 背景

Anthony Pecorellaは、25個や50個のような節目で倍率を与えると、買い方に波ができると述べている。Warren Spectorは、育成の選択が実際の遊びで分かる違いを生むようにすると述べている（issue #142）。

本作の仕事は4つ、スキルは3つである（[DOM-03](../20-domain/dom-03-jobs-and-skills.md)）。スキルのレベルには、決まった節目が無かった。上の仕事に就けるようになったあと、下の仕事に戻る理由も無かった。仕事の基本の稼ぎは、運び屋・ハッカー・傭兵・コアへの侵入で1・5・20・50と、隣どうしで2.5〜5倍離れている。

一方で、記憶ポイントは、その周で得た経験の合計とスキルのレベルの合計から出る（[DOM-05](../20-domain/dom-05-rebirth.md)）。危険度の低い運び屋は、1周で傭兵より多くの経験を得る（運び屋は約400、傭兵は約190）。下の仕事のほうが記憶ポイントでは得になる場合がすでにあったが、画面からは見えなかった。

## 決定

1. スキルのレベルが5の倍数（Lv 5・10・15・20、その先も5ごと）に届くたびに、節目を越えたものとする。節目に上限は置かない。
2. 節目ごとに強まる効果を、スキルごとに1つ決める。交渉は稼ぎ+20%、格闘は劣化-10%、ハッキングは経験+15%である。この効果は、就いている仕事に関係なく効く。
3. 節目の効果は、1レベルあたりの効果と同じく、効果の種類ごとに足し合わせる。越えた節目の数は、floor(スキルのレベル ÷ 5)で出す。間隔と効果は`game/data/skills.json`に持たせる。
4. 下の仕事に戻る理由は、節目そのものとする。交渉と格闘の経験は、運び屋の仕事がおもな入り手である。戻る理由のために、依頼・評判・イベントは足さない。
5. スキルの欄には、スキルごとに次の節目のレベルと、そこで強まる効果を1行で出す。節目に届いたときは、ログに残す。
6. 最初のエンディングまでの遊び時間は、人が遊んで約1時間のまま保つ（[ADR-0006](./adr-0006-fragments-and-endings.md)の決定4、[ADR-0046](./adr-0046-third-ending.md)の決定4）。自動で遊ぶ`game/ci/playthrough.gd`は、遊んだ時間が25分より短いか45分より長いときに失敗とする。

ADR-0006とADR-0046は置き換えない。約1時間という目安と、自動で遊ぶ検査をCIで回すことはそのまま生きている。このADRは、その検査に下限を足すだけである。

作り手は、最初のエンディングのあとも遊び続けて、合わせて20時間以上になる遊びを目指している。このADRでは向きとして記録するだけで、最初のエンディングまでは約1時間のままにする。20時間に届かせる仕組みは、エンディングのあとの遊びとして別のissueで決める。

## 理由

節目の効果を仕事ごとではなく、スキルごとの全体の効果にしたのは、上の仕事に就いたあとでも効くからである。運び屋で交渉を上げて越えた節目は、傭兵の稼ぎも増やす。そのため、上の仕事に就ける人でも、次の節目が近ければ運び屋に戻る理由ができる。

効果の大きさは、1レベルあたりの効果より目に見えて大きくした。交渉の1レベルあたりの稼ぎは+3%で、節目の+20%はその約7レベル分にあたる。

下限を置いたのは、節目で周が速く進みすぎたときに、検査で気づけるようにするためである。節目を入れたあとの自動で遊ぶ検査は36分（6周）で、入れる前の34分（6周）とほぼ同じだった。そのため、記憶の断片の条件は変えていない。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 節目で、その節目のスキルを対応スキルにする仕事の稼ぎだけを倍にする（Pecorellaの形） | 基本の稼ぎが隣どうしで2.5〜5倍離れているので、倍にしても上の仕事がいつも勝つ。下の仕事に戻る理由にならない |
| 下の仕事に戻る理由として、依頼・評判・イベントを足す | 1つの目的に2つの仕組みを持つことになる。節目だけで戻る理由になる |
| 節目に上限を置く（Lv 20まで） | 最初のエンディングのあとの遊びで、伸びる先が無くなる |

## 影響

[DOM-03](../20-domain/dom-03-jobs-and-skills.md)に、スキルの属性として節目の間隔と1節目あたりの効果を足し、越えた節目の数とスキルの効果を導出値に足す。用語表に節目を載せる。スキルの欄に次の節目の行が増え、ログに節目に届いた行が出る。`game/ci/playthrough.gd`は、遊んだ時間の範囲を確かめる。

## 見直しの条件

実際に遊んだ人が、上の仕事に就いたあとも下の仕事に戻らないなら、節目の効果の大きさを見直す。自動で遊ぶ検査が25〜45分の範囲を外れたら、記憶の断片の条件を見直す。エンディングのあとの遊びを作るときに、節目の間隔と効果を見直す。
