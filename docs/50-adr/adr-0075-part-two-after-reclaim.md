# 本当の体のあとに、転生の無い第二部を章で足す

- 日付: 2026-10-20
- 状態: stable

## 背景

最初のエンディングまでは、人が遊んで約1時間である（[ADR-0072](./adr-0072-skill-milestones.md)）。作り手は、最初のエンディングのあとも遊び続けて、合わせて20時間以上になる遊びを目指している（issue #174）。

これまで、エンディングのあとに新しく開くものは、残り2つのエンディングと話の選び直し（[DOM-31](../20-domain/dom-31-choosing-again.md)）だけだった。永続強化にはどれもレベルの上限があり、エンディングのあとに記憶ポイントを使う先も尽きる。

作り手は、遊ぶ時間を引き延ばすのではなく、遊ぶ中身を足して長く楽しませると決めた。そのうえで、エンディング「本当の体」のあとを第二部とし、そこからは転生をやめて新しい仕組みにすると決めた。エンディング「本当の体」の文は、体が長い眠りで重いこと、もう劣化に追われないこと、ヨミ・システムズの記録を街のネットに流したことを書いている。

## 決定

1. エンディング「本当の体」のあとに、第二部を足す。第二部へは、エンディング「本当の体」にたどり着いたあと、転生の画面から進む。ほかのエンディングを選んだ人は、話の選び直しで「本当の体」を選び直せば、第二部へ進める。
2. 第二部の筋は1本にする。選んだエンディングで筋を分けない。
3. 第二部には転生が無い。耐久の代わりに体調を置く。体調は仕事で減り、休むと戻り、時間がたつだけでは減らない。体調の上限は怪我で下がり、怪我は裏通りの診療所で治すまで残る。体調が0になっても周は終わらず、倒れて診療所に運ばれる。時間は日で数え、日ごとに暮らしの代金を払う。
4. 第二部のスキルは、レベル1から始める。取り戻したばかりの体はまだうまく動かず、頭も回らないからである。記憶ポイント・永続強化・体の種類は、第二部では使わない。クレジットとインプラントも持ち込まない。
5. 第二部は章に分ける。章は、章の目標と、決まった順に起きる章の出来事を持つ。章の目標をすべて満たすと、章の最後の出来事が起きて、次の章へ進む。章ごとに、新しい遊び方を1つ入れる。
6. 章は4つとし、題と新しい遊び方は次のとおりにする。このADRでは第1章までを作る。第2章から先は、1章ずつissueに分けて作る。

   | 章 | 題 | 新しい遊び方 |
   | --- | --- | --- |
   | 1 | 重い体 | 体調と怪我、日を単位にした暮らし |
   | 2 | 名前 | 仲間（仕事を任せられる人） |
   | 3 | 隠れ家 | 拠点を育てる |
   | 4 | 写し | 章の最後の大きな仕事 |

7. 第二部でも、企業は倒れずに残る（[ADR-0070](./adr-0070-theme-disposable.md)の決定3）。第4章では、ヨミ・システムズの研究部門の一部を崩すところまでを描く。
8. 第二部の途中でも、いつでも第一部の転生の画面へ戻れる。第二部の状態は第一部とは別に持ち、戻っても失われない。
9. 第1章の長さは、人が遊んで約50分とする。自動で遊ぶ`game/ci/part_two.gd`は、最初のエンディング「本当の体」まで第一部と同じ手順で遊び、そのまま第1章を終えるまで遊ぶ。第1章にかかったゲーム内の時間が20分より短いか40分より長いときに失敗とする。人の時間への換算は、第一部の検査と同じ比（ゲーム内の約36分で、人の約1時間）を使う。
10. 合わせて20時間以上という目標は、章ごとのissueで、その章の長さを測って確かめる。

[ADR-0072](./adr-0072-skill-milestones.md)は置き換えない。最初のエンディングまでを約1時間に保つことは、そのまま生きている。ADR-0072が別のissueで決めるとした「20時間に届かせる仕組み」を、このADRで決める。

## 理由

第二部を「本当の体」のあとに置いたのは、転生をやめる理由が物語の中にあるからである。取り戻した体は、もう使い捨てにできない。第一部で体を使い捨ててきた遊び方と比べることで、主題の「使い捨て」を裏から伝えられる。

筋を1本にしたのは、エンディングごとに筋を分けると、作る量が3倍になるからである。「ネットの亡霊」と「目覚めの日」は体に戻らない、または全員を目覚めさせる結末で、本当の体で暮らす続きとはつながりにくい。そのため、選び直しで「本当の体」へ進む道を残した。

体調を時間で減らさないことにしたのは、エンディングの文が「もう劣化に追われることはない」と書いているからである。疲れと怪我を分けたのは、休めば戻るものと、クレジットを払わないと戻らないものを分けて、稼ぐ・休む・治すの配分を考える遊びにするためである。

スキルをレベル1から始めることにしたのは、作り手の判断である。『キングダムカム・デリバランス2』のように、能力が戻る理由を物語で付けられる。スキルがまた伸びるので、第二部でも仕事を選ぶ意味が残る。

章で区切ったのは、作る量を章ごとのissueに分けられるからである。20時間分を1つのPRに入れると、見直しができない大きさになる。

第1章を約50分にしたのは、いまの中身（章の出来事5つ、第二部だけのイベント3つ、章の目標4つ）に見合う長さだからである。自動で遊ぶ検査では、第1章は27〜29分（28〜30日）で終わった。3時間にするには、目標の数字を上げて引き延ばすことになる。第1章は新しい仕組みに慣れる章とし、仲間と拠点の入る第2章から先を長くする。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| エンディングのあとに企業の警戒の段階を置き、段階を上げるほど耐久の減りを速く、記憶ポイントを多くする | 同じ周の繰り返しを引き延ばすだけで、遊ぶ中身が増えない |
| 第一部に新しい区画と記憶の断片を足して、最初のエンディングのあとも続ける | 転生を続けるので、取り戻した体の話にならない。作る量も大きい |
| エンディングごとに第二部の筋を分ける | 作る量が3倍になる |
| 第一部の最後の周のスキルのレベルを、第二部に持ち込む | 第二部の始めから強く、仕事を選ぶ意味が薄れる |
| 第二部でも体調を時間で減らす | エンディングの文と食い違う。第一部の劣化と同じ遊びになる |
| 第1章を、目標の数字を上げて約3時間にする | 中身が増えないまま、時間だけが延びる |
| 4つの章を1つのPRで作る | 見直しができない大きさになる |

## 影響

[DOM-34](../20-domain/dom-34-part-two-life.md)を新しく置き、第二部の状態・章・体調の式・第一部から持ち込むものを書く。[DOM-08](../20-domain/dom-08-memory-fragments-and-endings.md)のライフサイクルに、エンディング「本当の体」のあとに第二部へ進めることを足す。[ARCH-02](../10-architecture/arch-02-theme-and-mechanics.md)の主題と仕組みの対応に、第二部の暮らしを足す。

転生の画面に、第二部へ進むボタンが増える。第二部の画面では、体の状態の欄に、休む・住まいを借りる・第一部に戻る・怪我を治すのボタンと、章の目標が並ぶ。`game/data/part_two.json`に、章と第二部だけのイベントを置く。CIに`game/ci/part_two.gd`の検査が増え、`game/ci/layout.gd`は第二部の画面も1280x720に収まるかを見る。

## 見直しの条件

自動で遊ぶ検査で、第1章が20〜40分の範囲を外れたら、章の目標の値を見直す。実際に遊んだ人が、倒れてばかりで先へ進めないなら、仕事中の疲れと休んだときの戻りを見直す。第2章から先を作るときに、章の数と、合わせて20時間に届くかを見直す。企業を倒す結末を足すときは、ADR-0070と合わせて決め直す。
