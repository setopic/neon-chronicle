# 話の選び直しを、エンディングにたどり着いてから使えるようにする

- 日付: 2026-10-20
- 状態: stable

## 背景

[ADR-0048](./adr-0048-no-point-of-no-return.md)で、分岐図のタブに、選んだ段ごとの「ここから選び直す」ボタンを置いた。このボタンは最初の周から使えるので、まだどのエンディングにもたどり着いていないうちから、話の選択をやり直せる。作者は、エンディングに一度でもたどり着いてから、その特典として選び直せるようにしたいと考えている（issue #115）。

## 決定

ADR-0048の6つの決定のうち、1つめと5つめに条件を足し、ほかはそのまま引き継ぐ。

1. 話の段は、すでに選択肢を選んだ段から選び直せる（改める。下記の1）
2. 排他の組の永続強化は、記憶ポイントをすべて戻して選び直せる（そのまま）
3. どちらも代価は取らない（そのまま）
4. 選び直しても、評判・経験・クレジットと記録の物語文は戻さない（そのまま）
5. 話の選び直しは、分岐図のタブに、選んだ段ごとのボタンとして置く（改める。下記の2）
6. 話の選び直しは、DOM-31に書く（そのまま）

新しく決めることは次のとおりである。

1. 話の段を選び直せるのは、どれか1つのエンディングに一度でもたどり着いてからである。たどり着いたかは、記録に残ったエンディングで決める。
2. どのエンディングにもたどり着いていないうちは、分岐図のタブに選び直すボタンを出さない。ボタンの代わりに、エンディングにたどり着くと選び直せることを書いた1行を出す。

## 理由

選び直しを、エンディングにたどり着いた特典にするためである。作者は、たどり着いたあとに、それまでの選択で見られなかった段を後から追いかけられるようにしたいと考えている。たどり着いたあとは、ADR-0048のとおり取り返しの付かない要素を無くす。

条件をどのエンディングでもよいとしたのは、特定のエンディングを条件にすると、その結末に要る選択を誤ったデータが、また取り返せなくなるからである。

ボタンを隠すだけでなく案内の1行を出すのは、選び直しがあることを、最初のエンディングの前から知っておけるようにするためである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 特定のエンディングにたどり着いてから選び直せるようにする | その結末に要る選択を誤ると、またそのデータでは取り返せなくなる |
| 条件を満たすまで、ボタンを押せない形で出す | 押せないボタンが段の数だけ並び、分岐図の下が埋まる |
| 永続強化の組の選び直しにも、同じ条件を付ける | 作者が求めたのは話の選び直しだけである |

## 影響

DOM-31の属性と不変条件に、エンディングにたどり着いてからという条件を足す。DOM-05は変わらない。

`game_state.gd`の話を選び直す操作は、どのエンディングにもたどり着いていなければ何もしない。分岐図のタブは、そのあいだ選び直すボタンを出さず、案内の1行だけを出す。`ci/chart.gd`で、エンディングにたどり着く前は選び直せないことを確かめる。セーブの形は変えない。

## 見直しの条件

最初のエンディングまでの周が長すぎて、選択を誤ったまま遊び続けることが多くなったら、条件を緩めるかを決める。
