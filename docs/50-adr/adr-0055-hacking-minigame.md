# ハッカーの仕事のミニゲームを、符号の表を縦横にたどる遊びにする

- 日付: 2026-10-20
- 状態: stable

## 背景

仕事の1回をミニゲームで置き換える仕組みを、[ADR-0054](./adr-0054-minigame-frame.md)で作った。中身は仮のもので、どの仕事も動く印を止める遊びだった。issue #123では、ハッカーの仕事のミニゲームの遊び方と、難しさをスキルのレベルでどう変えるかを決めることにしていた。ADR-0054の決定5で、中枢サーバーへの侵入の仕事も、このミニゲームを使う。

## 決定

1. 遊び方は、防壁の符号の表から、決まった並びの符号を順に選ぶものにする。表は5行5列で、符号は5種類ある。並びの長さは4とする。
2. 最初は1行目から選ぶ。次は選んだ符号の列の中から、その次は選んだ符号の行の中から選び、縦と横を交互にたどる。一度選んだ升目は選べない。
3. 選んだ符号が並びの次の符号なら1つ進む。違えば最初からやり直しになる。ただし、違った符号が並びの1つ目と同じなら、1つ目として数える。
4. 選べる回数には枠がある。枠は、並びの長さに余りを足した数とする。余りは、ハッキングのレベル0で1つあり、5レベルごとに1つ増え、4つまで増える。枠を使い切る前に並びをそろえれば成功で、そろえられなければ失敗になる。
5. 成功の度合いは、そろえたときに余らせた枠で決める。ちょうど4回でそろえたら1、余りの枠を使い切ってそろえたら0.5とし、その間は余りを使った数に比例させる。失敗の度合いは0とする。
6. 表は、先にちょうど4回でそろえられる道を1つ作って、その升目に並びの符号を置き、残りの升目を無作為に埋める。そのため、どの表でも必ずそろえられる。
7. 升目はボタンにする。マウスで押せるほか、キーボードの矢印で選べる升目へ動き、決定のキーで選べる。いま選べる升目だけを押せるようにする。

## 理由

符号の表を縦横にたどる遊びは、Cyberpunk 2077のハッキングと同じ形で、作者が挙げたゲームの雰囲気に合う。issueの例の「コードの並びを当てる」にもあたる。縦と横を交互にたどるので、先を読んで選ぶ考えどころがある。

難しさをレベルで易しくする向きにしたのは、ハッキングを上げることが、ミニゲームでも手応えとして分かるようにするためである。表の大きさや並びの長さは変えず、枠だけを変えるので、遊び方を覚え直す必要がない。

必ずそろえられる表を作るのは、運が悪いと解けない表に当たって、遊んだ人が損をしないようにするためである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 回路をつなぐ遊びにする | 線を引く操作はキーボードだけでは遊びにくい |
| 時間の制限を付ける | 読むのが遅い人ほど損をし、英語と日本語で説明を読む長さも違う |
| レベルが上がるほど、並びを長くして難しくする | スキルを上げるほど遊びにくくなり、上げた手応えが逆になる |
| 表を無作為に埋めるだけにする | 解けない表に当たることがある |

## 影響

DOM-03のミニゲームの種類に、ハッキングのミニゲームが加わる。`game/data/jobs.json`のハッカーと中枢サーバーへの侵入の`minigame`を`hacking`にする。`game/scripts/minigame_hacking.gd`がこのミニゲームを持ち、`ci/minigame.gd`で、作った道をたどれば度合いが1でそろうことを確かめる。

## 見直しの条件

易しすぎて、いつも度合いが1になるなら、並びの長さか余りの数を見直す。並びをそろえる規則が分かりにくいという声が出たら、決定の3を見直す。
