# 体の質を前の周の稼ぎで決め、記憶ポイントを経験から出す

- 日付: 2026-10-19
- 状態: stable

## 背景

ミオは闇市場で体の部品を買って主人公の体を組み立てる（[DOM-20](../20-domain/dom-20-test-subjects-origin.md)）が、その代金を誰が払うかは決まっていなかった（issue #78）。転生の画面では4種類の体を自由に選べて、前の周の働きは体に表れなかった（[ADR-0012](./adr-0012-choose-body-on-rebirth.md)）。

記憶の側にも体の話が混ざっていた。永続強化「頑丈な義体」は記憶ポイントで買うが、中身は体の劣化を下げる効果だった。記憶ポイントは、稼いだクレジットからも増えていた。

作者の案は、体はその体で稼いだクレジットで次の体を用意させ、記憶はソフトウェアとしての性能の向上という位置づけにすることだった。スレッドで、記憶ポイントの式からクレジットを外し、クレジットは体の質に、スキルと経験は記憶ポイントに分けると決めた。稼ぎが体と記憶ポイントの両方に効くのを避けるためである。

issueでは、クレジットがミオに渡る形、体の質で良くなるものと式、体の種類との組み合わせ、「頑丈な義体」の扱い、記憶ポイントの新しい式、残りの永続強化の説明の6つを決めることにしていた。

## 決定

ADR-0012の7つの決定のうち、3つめだけを改める。

1. 体の種類は4つで、値は`game/data/bodies.json`に置く（そのまま）
2. 体の種類は基本の劣化と効果を持つ（そのまま）
3. 転生の画面に、毎回すべての体の種類を並んだ順に出す（そのまま）。どれも選べる（改める。下記の6）
4. 体の種類ごとのボタンで、選ぶことと転生を1回の操作にする（そのまま）
5. 第1周は汎用の体で目覚める（そのまま）
6. 記録と体の画面に体の種類を出す（そのまま）
7. 体の種類はDOM-11に書く（そのまま）

新しく決めることは次のとおりである。

1. 主人公は、稼ぎをミオの診療所の口座を通して受け取っている。ミオはその1割を手数料として残し、この手数料は前の身元の口座と違って凍結されない。画面の稼ぎは手数料を引いたあとの額とみなし、数値は変えない。
2. ミオは手数料で部品を買って次の体を組み立てる。体の質は、前の周で稼いだクレジットで決まる0〜5の段階である。式は`体の質 = clamp(floor(log2(前の周で稼いだクレジット ÷ 1,000)), 0, 5)`とする。2,000未満で0、2,000で1、4,000で2、8,000で3、1万6,000で4、3万2,000以上で5になる。
3. 体の質1段階ごとに、基本の劣化を15%下げる（体の質5で-75%）。劣化の効果の合計とは別に、基本の劣化に掛ける。
4. 汎用の体の体の質は、これまでの周の体の質のうち最高のものの半分（切り捨て）を下回らない。
5. 体の質は、どの体の種類にも同じように働く。転生の画面のボタンに、目覚めたときの体の質と、基本の劣化がどれだけ下がるかを出す。体の画面の体の種類の名前にも、いまの体の質を添える。
6. 作業用の体・戦闘用の体・試作の体は、前の周の体の質が1以上のときだけ選べる。選べない体の種類のボタンも出し、押せない状態にして、選べる条件を添える。汎用の体はいつでも選べる。
7. 永続強化「頑丈な義体」は無くす。体の丈夫さは、体の質が受け持つ。まだ公開していないので、すでにレベルを上げた古いセーブのための処理は置かない。
8. 記憶ポイントの式は`max(1, floor(√(その周で得た経験の合計 ÷ 2)) + floor(スキルのレベルの合計 ÷ 3))`とする。稼いだクレジットは式に入れない。
9. 残りの3つの永続強化は、意識の写しの改良として説明する。効果の数値は変えない。記憶の残響は、前の体で覚えた動きの型を学習の手本として意識の写しに残す。闇市場のコネは、連絡先と取引の手口を意識の写しの中に覚えておく。才能の継承は、腕前の型を次の体の神経へ読み込む手順として意識の写しに持たせる。

## 理由

手数料の形にしたのは、[DOM-09](../20-domain/dom-09-consciousness-copy.md)の「前の身元の口座は凍結される」と食い違わず、画面の数値も変えずに済むからである。送金の画面を足すと、手元のクレジットとの取り合いの釣り合いを決め直すことになる。

体の質を段階にしたのは、転生の画面で「質3」のように示せるからである。稼ぎは周ごとに大きく変わるので、額そのものではなく2倍ごとに段階を上げる。最初は1桁（10倍）ごとに上げ、基本の劣化を1段階10%下げる案で考えていた。しかし、自動で遊ぶ検査（`playthrough.gd`）では、1つの周の稼ぎは2,000〜6万ほどで、1桁ごとでは体の質が2までしか上がらなかった。2倍ごとに上げ、1段階10%にしたときは、エンディングまでの時間がいまの約1.7倍（7回で37〜91分、平均で約68分）になった。「頑丈な義体」を最大まで上げると、劣化の効果の合計が下限の0.2に届いていたが、体の質5で-50%では届かなかったからである。1段階15%にすると、5回とも40〜41分になり、いまのルールで5回回した37〜44分と同じ幅に入った。どちらも、2周目からは経験がいちばん増える試作の体を選ぶ検査の手順で測った。

基本の劣化に掛けるのは、[ADR-0012](./adr-0012-choose-body-on-rebirth.md)と同じ理由である。劣化の効果の合計には下限があるので、体の質を劣化の効果にすると、インプラントやスキルで下限に届いたあとは体の質の差が消える。

汎用の体に下限を置いたのは、運の悪い周のあとで抜け出せなくならないようにするためである。イベントで早く倒れた周は稼ぎが少なく、次の体の質が0になる。そのとき、ほかの体の種類は選べないが、汎用の体はそれまでの最高の半分の体の質で目覚められる。作業用・戦闘用・試作の体に条件を付けたのは、特別な部品を使う体は、稼いだ周のあとでしか用意できないとするためである。汎用の体にだけ下限があるので、稼げなかった周のあとに汎用の体を選ぶ理由もできる。

「頑丈な義体」を無くしたのは、中身が体の性能で、体と記憶を分ける作者の案に合わないからである。体の質が同じ役割を受け持つ。

記憶ポイントの式は、クレジットの項を、その周で得た経験の合計に置き換えた。経験は経験の効果（記憶の残響・試作の体）で増えるので、スキルと経験が記憶ポイントになるという線引きに合う。経験の合計を割る値は2にした。自動で遊ぶ検査で、1つの周に得る記憶ポイントが、いまの式とほぼ同じ20〜60になる。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 周の間に、送金の画面でミオへ送る額を決める | 画面と操作が1つ増え、手元のクレジットとの取り合いの釣り合いを決め直すことになる |
| 体が倒れたあと、ジンが前の身元の隠し口座から回収してミオに渡す | ジンの役割が広がり、キャラクターの設定にも手が入る |
| 体の質で、劣化に加えて稼ぎも上げる | 体が良いほど稼げて、次の体も良くなるので、差が開きやすい |
| 体の質を段階にせず、稼いだクレジットから連続の値で劣化を下げる | 画面で体の質を示しにくい |
| 体の質を1桁ごとに上げ、1段階10%にする | 自動で遊ぶ検査で、体の質が2までしか上がらなかった |
| 体の質を2倍ごとに上げ、1段階10%にする | 自動で遊ぶ検査で、エンディングまでの時間がいまの約1.7倍になった |
| 4種類とも、条件を付けずに選べるようにする | 前の周の働きが、選べる体に表れない |
| 体の質で、体の種類の効果も大きくする | 釣り合いの検証が、劣化と効果の2軸になる |
| 「頑丈な義体」のレベルを、体の質の下限として残す | 新しく始めた人との差が残る。まだ公開していないので、残す相手もいない |
| 「頑丈な義体」を永続強化のまま残し、説明だけ変える | 体と記憶を分ける作者の案に合わない |
| 記憶ポイントを、スキルのレベルの合計だけから出す | 終盤の記憶ポイントが大きく減り、値段の伸びとの釣り合いを決め直すことになる |
| 記憶ポイントを、主な仕事の時間から出す | 新しい導出値が増える |

## 影響

DOM-05の記憶ポイントの式から稼いだクレジットを外し、経験の合計に置き換える。DOM-11に体の質と、体の種類を選べる条件を足す。DOM-09の世界の中での説明に、ミオの手数料と体の質を足し、永続強化ごとの説明を意識の写しの改良に改める。

`game/data/upgrades.json`から`frame`を外し、言語ファイルの`upgrade.frame.*`も消す。`game_state.gd`は、その周で得た経験の合計と体の質を持ち、セーブにも書く。転生の画面のボタンは3行になり、体の質と選べる条件を出す。`playthrough.gd`は、選べる体の種類の中から、経験がいちばん増える体を選ぶ。

## 見直しの条件

1つの周の稼ぎが、遊び方によって3万2,000を大きく超えるのが当たり前になり、体の質が早くから5で止まるようになったら、式を決め直す。体の種類を足して、選べる条件を種類ごとに変えたくなったら、条件を`bodies.json`に持たせるかを決め直す。
