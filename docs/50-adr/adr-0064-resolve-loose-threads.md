# 置いたまま回収していない伏線の扱いを決める

- 日付: 2026-10-20
- 状態: stable

## 背景

設計文書の点検で、置いたまま回収されていない伏線が6つあると分かった（issue #153）。九条が名前でも姿でも画面に出ないこと、ジンに名乗ってもその後が何も変わらないこと、ミオの3段目の追跡がその後に何も起こさないこと、目覚めの日に目覚めた体に入る意識と下層街への道が決まっていないこと、レイと約束した周に本当の体を選んだときの扱いが無いこと、オルセンの管路の向きが逆に見えて本筋で使われないことである。

## 決定

[ADR-0009](./adr-0009-world-rationale-and-characters.md)の5つのうち、4つはそのまま引き継ぐ。

1. 生き直しを、企業の研究部門の反復計画として説明する（そのまま）
2. 主人公の意識の写しだけは、ミオが読み込み先を書き換えていて、裏通りの診療所で目覚める（そのまま）
3. 記憶ポイント・永続強化・スキル・クレジット・残るインプラントの理由（そのまま）
4. 名前のある人物を4人置き、それぞれを記憶の断片かエンディングに結びつける（改める。下記の1）
5. いまある記憶の断片とエンディングの文は、この設定と食い違わない（そのまま）

[ADR-0036](./adr-0036-bridge-engineers-records.md)の6つのうち、5つはそのまま引き継ぐ。

1. 資料「橋を架けた技師たち」を足し、イベント「古い銘板」で出す（そのまま）
2. 資料の追記を3つにし、順は決めない（そのまま）
3. ハッカーのイベント「市の図面」を足す（そのまま）
4. イベントに「選んだ選択肢を残す」の属性を足す（そのまま）
5. 本筋とは、断片「中枢サーバー」で出る追記で結ぶ。オルセンの管路が本社の地下へ電気を送っていて、中枢サーバーもその先にある（改める。下記の6）
6. 記録を集め終えても、記憶ポイントや永続強化は増えない（そのまま）

この決定で、次のことを決める。

1. 九条は、名前も姿も画面に出さない黒幕とする。名前のある人物は4人のままとし、記憶の断片かエンディングに関わるのは、ミオ・ジン・レイの3人とする。九条がイベント「中枢の扉」で姿を見せることはしない。資料も置かない。
2. ジンの3段目で名乗っても、ジンが気づくのはその周の主人公だけとする。次の周の体は、ミオがまた新しい運び屋として紹介するので、ジンは次の周の主人公に気づかない。ジンの依頼の台詞と資料「ジン」は変えない。
3. ミオの3段目の追跡は、どの選択肢を選んでも、3段目で片が付いたものとする。次の周も主人公は裏通りの診療所で目覚め、目覚めとエンディングは変わらない。
4. 目覚めの日では、[本当の体](../20-domain/dom-08-memory-fragments-and-endings.md)と同じく、各被験体の意識の写しを、それぞれの体へ読み込み直す。写しと体は、レイと抜き取った被験体の名簿で結ぶ。写しが離れた施設の使い捨ての体は止まる。目覚めた人々は、オルセンの管路を通って、橋の検問を通らずに本社の地下から裏通りへ出る。
5. レイと約束した周に本当の体かネットの亡霊を選んでも、エンディングの文は書き分けない。本当の体を選ぶと、レイとの約束は果たされないまま物語が終わる。
6. オルセンの管路は、本社の地下から、オルセン橋の床下を通って裏通りの側へ延びているものとする。市の時代に、高台の発電所から低い土地へ電気を送るために引いたもので、人が通れる太さがある。

## 理由

九条を姿を見せない黒幕にしたのは、画面の文も資料も足さずに済むからである。反復計画を動かす者の顔を最後まで見せないことは、ミオ・ジン・レイの3人との関係を物語の中心に置くことと食い違わない。

ジンの扱いを決まりだけにしたのは、[ADR-0063](./adr-0063-recognizing-across-lives.md)のジンが気づかない理由が、名乗ったあとの周にもそのまま当てはまるからである。名乗った周にだけ再会があることは、体が毎周新しくなることを人間関係として感じさせるという[ADR-0009](./adr-0009-world-rationale-and-characters.md)の理由とも合う。

ミオの追跡を3段目で片付けたのは、次の周の目覚めやエンディングを変える仕組みを足さずに済むからである。主人公の写しは記録の上で廃棄した写しで、ミオは死んだことになっているので（[ADR-0062](./adr-0062-discarded-copy-and-dead-engineer.md)）、追跡が退けば、研究部門には次に辿る線が無い。

目覚めの日で写しを体へ読み込み直すとしたのは、本当の体と同じ仕組みで説明でき、「意識の写しは1つ」とも食い違わないからである。眠っていた体の側の意識だけを目覚めさせると、抜き取ったときの状態の者と、施設で働く写しの2人が同時にいることになる。名簿で写しと体を結ぶのは、レイの2段目で名簿を一緒に抜き取ることが目覚めの日の条件になっている理由にもなる。

管路を目覚めの日の道にしたのは、身元の無い者は橋を渡れないという決まり（[DOM-18](../20-domain/dom-18-resident-classes.md)）を変えずに、目覚めた人々を下層街へ移せるからである。管路の向きを直すと、オルセン橋が本社のあるヨミ・システムズの縄張りと裏通りをつなぐ橋であることとも合う。

レイとの約束を書き分けないのは、エンディングの文を話の進み具合で変える仕組みを足さずに済むからである。約束を破る選び方ができることは、選んだ結果として残す。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 断片「計画書」か「中枢サーバー」で九条の名前を出し、「中枢の扉」に九条の一言と資料を置く | 画面の文と資料を足すことになる |
| 九条を名前のある人物から外し、3人にする | 反復計画を動かす者が設計の上で名前を持たなくなる |
| 名乗ったあとの周で、ジンの依頼の台詞を書き分ける | 依頼に、話の進み具合で文を変える属性を足すことになる |
| ミオの3段目の選択で、目覚めのログかミオの一言を変える | 目覚めやミオの一言を話の進み具合で変える仕組みが要る |
| 目覚めの日に、眠っていた体の側の意識だけを目覚めさせる | 同じ人が、目覚めた体と施設の写しの2人になる |
| 目覚めた人々に、レイが名簿から偽の身元を作って橋を渡らせる | 数十人の偽の身元を一度に作ることになり、橋を見張るモンフォール警備に見咎められない理由が要る |
| レイと約束した周の本当の体の文を書き分ける | エンディングの文を話の進み具合で変える仕組みが要る |
| 管路を読み物にとどめ、向きだけを直す | 目覚めの日の道を別に決めることになる |

## 影響

DOM-10の九条の行・定義・不変条件を直し、ジンに名乗ったあとの決まりを足す。DOM-13にミオの3段目の追跡の結末を足す。DOM-14の九条の資料を置かない理由を直す。DOM-17にオルセンの管路を足す。DOM-29に、目覚めた体に入る意識、下層街への道、レイとの約束を破るときの扱いを足す。数値と仕組みは変えない。

画面の文のうち、資料「橋を架けた技師たち」の断片「中枢サーバー」の追記（`profile.engineers.core`）と、資料「ミオ」の3段目の追記（`profile.mio.chase`）が新しい決まりに合うかは、#136で確かめる。

## 見直しの条件

九条を画面に出したくなったら、九条の資料と「中枢の扉」の文を足すかを決め直す。エンディングの文を話の進み具合で書き分ける仕組みを足すときは、ジン・ミオ・レイとの約束の扱いを見直す。
