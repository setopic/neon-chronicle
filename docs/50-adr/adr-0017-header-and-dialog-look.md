# 画面の右上のボタンとダイアログの見た目をそろえる

- 日付: 2026-10-18
- 状態: stable

## 背景

機能を足すたびに、画面の右上へボタンを足してきた。言語・イベントで止める・音楽・効果音・最初から・記憶・街と人物・ライセンスの8つが1段に並び、英語では1280×720の横幅に収まらず、右端の「License」が切れていた（issue #46）。「記憶」「街と人物」「ライセンス」「最初から」の画面は、Godotの標準の灰色のダイアログで、ほかの画面のネオンの色合いとそろっていなかった。

issueでは、どこを直すかと、このissueで直す範囲を決めることにしていた。

## 決定

1. 右上のボタンを2段に分ける。上の段には設定（言語・イベントで止める・音楽・効果音）を、下の段には読み物（記憶・街と人物・ライセンス）と「最初から」を、右に寄せて置く。
2. 「最初から」は押すとやり直しになるので、下の段の右端に置き、文字を赤くする。
3. ダイアログの枠・見出し・背景と、言語を選ぶ一覧の背景に、パネルと同じ色を当てる。キーボードで選んでいるボタンの枠は、標準の白ではなく水色にする。
4. 「最初から」の確かめる画面の見出しを、英語の固定の文（Please Confirm...）から「最初から」に変える。
5. 仕事の条件に「必要」が2回出ていた（「必要：記憶の断片 2 / 5 必要：ハッキング Lv 15」）ので、「必要」を1つにして、条件を「、」でつなぐ。言語ファイルの`ui.requires`は`{items}`を受け取る形にし、`ui.requires_fragments`からは「必要」を外す。

転生の画面は、1280×720の高さに収まっているので、このissueでは変えない。

## 理由

2段にしたのは、上の街の帯の高さ（140）に2段がそのまま収まり、ほかの欄の高さを変えずに済むからである。設定と読み物で分けたのは、押したときに起きることが、設定は切り替え、読み物は画面を開くことで異なるからである。

ダイアログは、テーマの`Window`と`AcceptDialog`の見た目を足して色を変えた。ダイアログはメインの画面の子なので、同じテーマが届く。部品を作り直さずに済む。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ボタンを1つのメニューにまとめる | 音楽と効果音の入り切りが、いまの状態を見られず、2回押す操作になる |
| ボタンの文字を小さくして1段に収める | 英語ではまだ収まらず、言語が増えるとまたはみ出す |
| ダイアログを自前のパネルで作り直す | テーマを足すだけで色がそろい、閉じる・動かすといった標準の動きをそのまま使える |

## 影響

ARCH-01の分担は変わらない。`main.gd`の画面の組み立てとテーマだけが変わる。

言語ファイルの`ui.requires`と`ui.requires_fragments`の文が変わる。MODの言語ファイルでこの2つを上書きしているなら、合わせて直す。

## 見直しの条件

右上のボタンがさらに増えて2段でも収まらなくなったら見直す。転生の画面に部品を足して、1280×720の高さに収まらなくなったときも見直す。
