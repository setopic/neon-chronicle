# 本作の主題を「使い捨て」とし、警告として描く

- 日付: 2026-10-20
- 状態: stable

## 背景

本作には、劣化・転生・体の種類・インプラントなどの仕組みが、それぞれ何を伝えるためにあるかを1か所で述べた文書が無かった（issue #137）。そのため、仕組みを足すたびに、主題に合うかを判断する基準が無かった。『Citizen Sleeper』の作り手は、先に主題の語を決め、そこから仕組みを作ったと述べている。Mike Pondsmithは、サイバーパンクを憧れではなく警告として描くと述べている。

## 決定

1. 本作の主題の語は「使い捨て」とする。
2. 主題は2つの側から伝える。1つは、企業が人を使い捨てにする街である。もう1つは、遊ぶ人も、死者の神経の型でできた体を使い捨てにして強くなることである。遊ぶ人に、企業と同じことをしていると気づかせる。
3. 警告として描く。どのエンディングでも、企業は倒れずに残る。
4. 主題と仕組みの対応は、ARCH-02に表として書く。仕組みを足すときは、その表と照らす。

## 理由

「使い捨て」にしたのは、被験体の契約、解雇、死後に回収するインプラント、廃棄した写しと、企業の側の仕組みのほとんどが1つの語で言えるからである。遊ぶ人の側の、耐久が尽きる体と転生も、同じ語で言える。

遊ぶ人も使い捨てにする側に置いたのは、体が倒れるたびに強くなる仕組みが、主題とぶつからずに主題を伝える側に入るからである。使い捨てにされる側だけに立たせると、この仕組みが主題とぶつかる。

警告として描くことにしたのは、いまの3つのエンディングが、どれも企業を倒していないからである。この方針なら、エンディングを直さずに済む。

対応表をADRとは別のノードに置いたのは、ADRは確定したら直せないのに、対応表は仕組みが増えるたびに足すからである。ARCH-01は技術の構成の文書なので、主題を入れると別の概念が混ざる。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 主題の語を「写し」にする | 意識の写しと神経の型には合うが、街の暮らしの側が外れる |
| 主題の語を「借り物の体」にする | 体の種類と元の持ち主には合うが、企業の側が外れる |
| 遊ぶ人は使い捨てにされる側だけに立つ | 体が倒れるほど強くなる仕組みが、主題とぶつかる |
| 描き方を決めない | 企業を倒す結末を足すときに、主題に合うかを判断できない |
| 主題と対応表をARCH-01に書く | ARCH-01は技術の構成の文書で、主題とは別の概念である |
| 主題と対応表を、すべてこのADRに書く | 仕組みが増えるたびに、確定したADRを直すことになる |

## 影響

ARCH-02を新しく置き、主題と、仕組みごとの対応を書く。主題とぶつかる仕組みは見つからなかったので、数値と仕組みと画面の文は変えない。

## 見直しの条件

企業を倒す結末を足すときは、警告として描く方針を決め直す。対応表の「主題と関わらない」に入らない仕組みで、主題とぶつかるものを足すときは、主題の語を決め直すか、その仕組みを直すかを決める。
