# 意識を抜き取るとは、写しを取って体を眠らせることにする

- 日付: 2026-10-20
- 状態: stable

## 背景

設計文書の点検で、意識を抜き取る仕組みと、意識の写しの仕組みが両立していないと分かった（issue #147）。

[DOM-20](../20-domain/dom-20-test-subjects-origin.md)は、意識を抜き取った体を、写しが壊れたときに抜き取り直すために保存するとしていた。意識を体から取り去ったのなら、同じ体から抜き取り直すことはできない。体に意識が残っているなら、本当の体の中にも主人公がいることになり、[DOM-09](../20-domain/dom-09-consciousness-copy.md)の「意識の写しは1つ」と食い違う。

ほかに、腕前が体の神経と一緒に失われるのに、研究部門が腕を目当てに被験体を選ぶこと、前の体の遺体の行方が書かれていないことも挙がっていた。

## 決定

1. 意識を抜き取るとは、人の意識の写しを取ったうえで、その人の体の側の意識を眠らせて止めることとする。体は眠ったまま残る。眠った体から写しを取り直すと、最初に抜き取ったときの状態の写しになる。
2. この語を「意識を抜き取る」として、[DOM-09](../20-domain/dom-09-consciousness-copy.md)の用語表で定義する。[DOM-08](../20-domain/dom-08-memory-fragments-and-endings.md)の本当の体と、[DOM-20](../20-domain/dom-20-test-subjects-origin.md)の被験体の集め方は、この意味で書く。
3. 腕前のうち、知っていることと手順は意識の写しに残る。手の速さは体の神経に焼き付いたもので、体と一緒に失われる。スキルのレベルは、この神経の慣れの度合いとする。
4. 倒れた体は、倒れた場所に残される。体とインプラントは拾った者が闇市場へ売り、裏通りの診療所には戻らない。
5. 体が何でできているかは、ここでは決めない。issue #148で決める。

## 理由

1つ目の案にしたのは、すでにある文書の多くをそのまま使えるからである。本当の体が眠ったまま保存されていること（DOM-08）、エンディング「目覚めの日」で眠らされた被験体を目覚めさせること（[DOM-29](../20-domain/dom-29-day-of-waking.md)）が、新しい説明を足さずに成り立つ。眠った体の意識は目覚めないので、「意識の写しは1つ」とも食い違わない。

腕前を分けたのは、研究部門が腕のある者を選ぶ理由を残すためである。DOM-09の永続強化の説明は、もともと腕前の型を写しに持たせるものとして書いてあり、この分け方と合う。

遺体の行方を、裏通りの診療所に戻らないことにしたのは、数値を変えずに済むからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 抜き取りは意識を体から取り去ることとし、本当の体を保存する理由を「写しを読み込み直す先として、元の体がいちばん合う」などに替える | 抜き取り直すという理由（DOM-20）を捨てることになり、エンディングで体に戻ることの意味も新しく説明し直す必要がある |
| ミオが遺体を回収し、部品を次の体の代金に充てる | 手数料と体の質の式（[DOM-11](../20-domain/dom-11-body-types.md)）の説明を書き直すことになり、インプラントが残らない理由も別に要る |

## 影響

DOM-09の用語表に「意識を抜き取る」が加わり、不変条件に「意識を抜き取った体は目覚めない」が加わる。仕組みの説明の表では、スキルが開始レベルに戻る理由を書き直し、前の体とインプラントが戻らない理由の行を足す。

DOM-08の本当の体と、DOM-20の被験体の集め方は、決定1の意味で書き直す。数値は変わらない。

画面の文言（断片「白い部屋」の「移す」など）を直す必要があるかは、issue #136で確かめる。

## 見直しの条件

眠った体の側の意識を、物語の中で動かしたくなったとき（たとえば、本当の体の夢を見るイベントを足すとき）に見直す。
