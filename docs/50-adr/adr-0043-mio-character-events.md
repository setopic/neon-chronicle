# ミオにも3段の人物のイベントを持たせる

- 日付: 2026-10-20
- 状態: stable

## 背景

ミオは毎周主人公を迎えるが、人物のイベントを持たなかった（issue #90）。[ADR-0014](./adr-0014-character-events-across-lives.md)は、ミオは診療所の人物で、仕事の間に起きるイベントには出せないとして、人物のイベントをレイとジンだけにしていた。そのため、なぜ毎周迎えに来られるのかや、手数料を何に使っているのかは、記憶の断片の文と資料でしか分からなかった。

issueでは、ミオの話で明かすことと、進み方の2つを決めることにしていた。作者からは、推奨の案で進めてよいと言われている。

## 決定

ADR-0014の7つの決定のうち、1つめだけを改める。

1. 人物のイベントは、レイとジンの2人に3段ずつ置く（改める。下記の1）
2. 人物のイベントは`game/data/events.json`に置き、並んだ順を段の順とする（そのまま）
3. 1つの周で進むのは、人物ごとに1段までにする（そのまま）
4. 話の進み具合は、選んだ選択肢をイベントのidごとに持つ（そのまま）
5. 前の選択は、説明の文の書き分けと前の選択の条件で後の段に反映する（そのまま）
6. ジンの3段目は、記憶の断片「名前」が戻るまで起きない（そのまま）
7. 人物のイベントはDOM-13に書く（そのまま）

新しく決めることは次のとおりである。

1. ミオにも3段の人物のイベントを置き、人物のイベントを9つにする。ミオの段は、仕事帰りや仕事の合間に診療所へ寄る場面にする。
2. 1段目は、ミオが下層街の患者を代金を取らずに診ている夜で、手伝うかを選ぶ。手数料を患者の薬にも使っていることが分かる。
3. 2段目は、記憶の断片「白い部屋」が戻ってから起きる。ミオに白い部屋のことを聞くかを選ぶ。聞くと、ミオが途中で降りる前に読み込み先を書き換えたことを、ミオの口から聞く。
4. 3段目は、記憶の断片「計画書」が戻ってから起きる。研究部門の追跡が診療所へ近づき、追跡をそらす（ハッキング Lv 10）、診療所を守る（格闘 Lv 10）、逃げるよう言う、のどれかを選ぶ。
5. 1段目と3段目で選択肢を選ぶと、資料「ミオ」に追記が加わる。

## 理由

診療所へ寄る場面にしたのは、ADR-0014が却下した理由を、イベントの舞台の側で解くためである。仕事帰りや合間に診療所へ寄るなら、仕事の間に起きるイベントとして出せる。

2段目と3段目に断片を要るとしたのは、ミオが技師の1人だったことと、読み込み先を書き換えたことを、断片が戻る前に画面に出さない決まり（[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)の不変条件）を守るためである。

3段目に、条件の無い「逃げるよう言う」を置いたのは、どのスキルを伸ばしてきた人でも話を終えられるようにするためである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ミオの話を、転生の画面のミオの一言だけで進める | 選択肢を選べず、話の進み具合が残らない |
| ミオの段を、仕事に関わらず診療所で起こす | 仕事の間に起きるイベントの仕組みとは別の起き方が要る |
| 九条にも人物のイベントを置く | 九条は最後の仕事の間まで名前で画面に出さない |
| ミオの話の結末で、エンディングを変える | エンディングを増やす話（issue #93）で決める |

## 影響

DOM-13の人物のイベントの一覧に、ミオの3段を足す。DOM-10の「画面に出るところ」に、ミオの人物のイベントを足す。DOM-14の資料の一覧に、ミオの追記を足す。

`game/data/events.json`にミオの3段を、`game/data/profiles.json`にミオの追記を足す。仕組みは変えない。

## 見直しの条件

ミオの話の結末を、エンディングや次の周の目覚めに効かせたくなったら、決め直す。
