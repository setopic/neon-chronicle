# 仕事の1回を、ミニゲームで置き換えて遊べるようにする

- 日付: 2026-10-20
- 状態: stable

## 背景

作者は、ハッキング・運び屋・傭兵の仕事を、ミニゲームとしても遊べるようにしたい。遊んで終えた仕事は、放置で終えた仕事より報酬を多くする（issue #122）。仕事は1回ずつ終わり、終わると報酬が入る（[ADR-0051](./adr-0051-job-pays-on-completion.md)）。

issueでは、どの仕事のミニゲームにも共通する仕組みとして、始め方と放置の仕事との関係、報酬の上乗せの決め方と失敗の扱い、中枢サーバーへの侵入にハッキングのミニゲームを使うかを決めることにしていた。各ミニゲームの中身は#123〜#125で作る。

## 決定

1. ミニゲームは、就いている仕事のいまの1回を置き換える。仕事の様子の欄（[ADR-0053](./adr-0053-job-scene.md)）に「遊んで1回を終える」のボタンを置き、押すとミニゲームの画面が開く。
2. 遊んでいる間は、周の時間を止める。放置の1回の進み具合も、劣化・イベントも進まない。そのため、遊んでいる間に放置の報酬が二重に入ることは無い。
3. ミニゲームは、終えたときに成功の度合いを0から1の値で返す。入る報酬と経験は、放置で終えた1回の分に「1 + 1 × 成功の度合い」を掛けたものとし、最大で2倍になる。終えると進み具合は0に戻り、ジンの依頼が数える就いた時間も1回の長さだけ進む。
4. 失敗しても罰は無い。成功の度合いが0でも、放置で終えた1回と同じだけ入る。途中でやめたときは何も入らず、進み具合はそのまま残る。
5. 中枢サーバーへの侵入の仕事には、ハッカーの仕事と同じハッキングのミニゲームを使う。
6. どのミニゲームを遊ぶかは、`game/data/jobs.json`の各仕事の`minigame`に書く。ミニゲームの部品は`game/scripts/minigame.gd`の`Minigame`を元にし、仕事の対応スキルのレベルを受け取って難しさを変える。
7. 遊んでいるかどうかはセーブに残さない。遊んでいる途中で閉じたら、開き直したときに放置の仕事に戻る。
8. 各仕事のミニゲームができるまでは、動く印を中央の枠で3回止める仮のミニゲームを、どの仕事にも当てる。

## 理由

いまの1回を置き換える形にしたのは、ミニゲームを放置の仕事と同じ区切りに乗せ、報酬の計算を1回の報酬の倍率だけで済ませるためである。別に遊ぶ形にすると、遊んだ分の報酬の基準を別に決める必要があり、放置の仕事と並べて比べにくい。

時間を止めるのは、遊んでいる間に体が劣化したりイベントが割り込んだりすると、遊ぶことが損になるからである。止めておけば、放置の報酬が二重に入る心配もない。

失敗しても1回分を入れるのは、遊ぶことを放置より損にしないためである。作者の望みは、遊べば放置より多く入ることで、失敗で減らすと遊ぶ気が起きにくくなる。途中でやめたときに何も入れないのは、すぐやめて1回分を早く取る遊び方を防ぐためである。

中枢サーバーへの侵入にハッキングのミニゲームを使うのは、対応スキルがハッキングで、仕事の中身もハッキングだからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ミニゲームを放置の仕事とは別に遊び、遊ぶたびに報酬を入れる | 遊んだ分の報酬の基準を別に決める必要があり、放置の仕事と二重に入らないようにする仕組みも要る |
| 遊んでいる間も周の時間を進める | 遊んでいる間に劣化やイベントが進み、遊ぶことが損になる |
| 失敗したら報酬を減らすか、入れない | 遊ぶことが放置より損になりうる |
| 途中でやめても1回分を入れる | すぐやめて1回を早く終える遊び方ができる |
| 中枢サーバーへの侵入に専用のミニゲームを作る | 中身がハッキングと同じで、作る量だけが増える |
| 遊んでいるかどうかをセーブに残す | 閉じている間の進みと組み合わせると、止めた時間の扱いが複雑になる |

## 影響

DOM-03の属性にミニゲームの種類を、周ごとの状態にミニゲームを遊んでいるかを足し、ミニゲームで終えた1回の報酬の式と、ライフサイクルの文を足す。

`game_state.gd`は、ミニゲームを始める・終える・やめる操作を持ち、遊んでいる間は時間を止める。`main.gd`は、仕事の様子の欄にボタンを置き、ミニゲームの画面を出す。`ci/minigame.gd`で、遊んでいる間に放置の報酬が入らないことと、上乗せの額を確かめる。ADR-0051は書き換えない。

## 見直しの条件

ミニゲームを遊ぶと放置よりずっと速く進み、通しで遊ぶ長さが大きく縮むなら、決定の3の上乗せを見直す。失敗しても損が無いので緊張感が無い、という声が出たら、決定の4を見直す。
