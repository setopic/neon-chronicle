# 1つの周は、世界の中では数日から数週とする

- 日付: 2026-10-20
- 状態: stable

## 背景

1つの周が世界の中でどれだけの時間かが、決まっていなかった（issue #152）。[DOM-02](../20-domain/dom-02-life-and-body.md)は、汎用の体は250秒で使えなくなるとしている。[ADR-0044](./adr-0044-traces-of-last-life.md)は、1周は数分で終わるので、2周前のことまで覚えている人は少ないとしていた。遊ぶ時間の長さが、世界の中の理由に使われていた。

画面の文では、ミオの1段目で主人公が「夜明けまで」手伝う。体が世界の中でも数分しかもたないなら、1つの周の中で夜は明けない。

## 決定

1. 1つの周は、世界の中では数日から数週にあたる。ゲームの秒は、世界の中の時間を縮めたものとする。秒と日の換算の比は決めない。
2. 画面に出す時間は、ゲームの秒で数える。ジンの依頼の「2分働く」は、そのまま残す。
3. 跡が1つ前の周にしか効かない理由を、世界の中の言葉で言い直す。裏通りの診療所からは毎周新しい運び屋が来るので、街の人々が比べるのは、すぐ前にいた運び屋だけである。2人前の運び屋までは、主人公と結びつけない。
4. 1は[DOM-02](../20-domain/dom-02-life-and-body.md)に、3は[DOM-27](../20-domain/dom-27-traces-of-last-life.md)に書く。

どのADRも置き換えない。跡を1つ前の周だけに効かせること（ADR-0044の決定の2、[ADR-0063](./adr-0063-recognizing-across-lives.md)が引き継いだ）と、人物のイベントを1つの周に1段までにすること（[ADR-0014](./adr-0014-character-events-across-lives.md)）は、決定そのものが変わらないからである。ADR-0044とADR-0014の理由にある「数分」は、遊ぶ時間の長さとして読めば今も正しい。

## 理由

換算の比を決めないのは、体の種類やインプラントで周の長さが変わるからである。比を決めると、周ごとの世界の中の日数が決まり、画面の文と食い違う箇所が増える。幅で書けば、ミオの「夜明けまで」も1つの周に収まる。

跡の理由を診療所の運び屋で言い直したのは、ADR-0063がジンの気づかない理由を、ミオが毎周新しい運び屋として紹介することにしているからである。同じ1つの筋で、跡が1つ前の周にしか効かないことも説明できる。

画面の時間をゲームの秒のままにしたのは、依頼の「2分働く」が、遊ぶ人が画面の時計で確かめる目標だからである。

目覚めの日の「何年ぶりかで」は直さない。被験体が主人公より前から眠らされていた年数で、周の長さとは食い違わない。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ゲームの1秒を世界の中の1時間のように、換算の比を決める | 体の種類やインプラントで周の長さが変わり、画面の文と食い違う箇所が増える |
| 数週たつと下層街の顔ぶれが入れ替わり、覚えている人がいなくなる、とする | 数週で顔ぶれが替わるほど人が動くという設定が、ほかの文書に無い |
| ADR-0063を置き換え、理由の言い直しを引き継ぎの一覧に書く | 決定が変わらないのに、確定したADRを取り下げることになる |
| 依頼の「2分働く」を、世界の中の時間（数日働くなど）に直す | 遊ぶ人が画面の時計で確かめられなくなる |

## 影響

DOM-02の定義に、1つの周の世界の中での長さと、画面に出す時間の数え方を足す。DOM-27に、跡が1つ前の周にしか効かない理由を足す。

画面の文と実装は変えない。

## 見直しの条件

周の世界の中の日数を、画面の文や記憶の断片に出すときは、換算の比を決め直す。跡を2つ前の周まで効かせたくなったら、3の理由を決め直す。
