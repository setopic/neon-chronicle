# ザンダー・ファミリーと屋台組合の対立を、3段の勢力の話にする

- 日付: 2026-10-20
- 状態: stable

## 背景

下層街のザンダー・ファミリーと屋台組合は、[ADR-0024](./adr-0024-lower-city-gang-and-union.md)と[ADR-0026](./adr-0026-union-ledger-and-housing.md)で決めたが、2つの勢力の対立はイベントの話になっていなかった（issue #85）。勢力の評判（[ADR-0037](./adr-0037-faction-reputation.md)）が入り、どちらに付いてきたかが周をまたいで残るようになった。

issueでは、どちらに付くかの決め方と、話の結末と下層街の仕事やイベントへの効き方の2つを決めることにしていた。作者からは、推奨の案で進めてよいと言われている。

## 決定

1. 屋台通りの保護料をめぐる対立を、3段の話にする。人物のイベントと同じく、1つの周に1段ずつ進み、前の段の選択で説明の文と選べる選択肢が変わる。
2. この話は登場人物の話ではないので、イベントに人物ではなく「話」のidを持たせる。話のidを持つイベントを、勢力の話のイベントと呼ぶ。進み方は人物のイベントと同じ仕組みを使う。
3. どちらに付くかは、2段目で決める。付く側の選択肢は、その勢力の評判3で選べる。どちらにも付かない選択肢も置く。
4. 1段目は評判の条件を持たず、選んだ側の評判が1上がり、もう片方が1下がる。1段目と、それまでのイベントで、2段目までに評判3へ届くかが決まる。
5. 結末は3段目の選択肢で4つに分かれる。組合の側で額を取り戻す、ファミリーの額をのませる、間に立って手打ちにする（交渉 Lv 6）、席に着かない、の4つである。前の2つは、2段目で付いた側でだけ選べる。
6. 結末は評判で効かせる。2段目と3段目の選択肢は評判を2ずつ動かし、遺体の取り立てや盗電の線などの、評判の条件を持つ選択肢が開く。下層街の仕事の稼ぎは変えない。
7. 3段目で選択肢を選ぶと、資料「ザンダー・ファミリー」と「屋台組合」に、対立の追記が加わる。
8. 勢力の話は、新しいドメインノード[DOM-23](../20-domain/dom-23-stall-street-feud.md)に書く。

## 理由

人物のイベントの仕組みを使ったのは、周をまたいで1段ずつ進む話の形が、すでに作ってあるからである。人物のイベントは登場人物との話に限る（[ADR-0014](./adr-0014-character-events-across-lives.md)）ので、人物のidではなく話のidを持たせて分けた。

付く側を評判で決めるのは、それまでの周でどちらの側に立ってきたかが話に表れるようにするためである。1段目には評判の条件を付けないので、評判が0から始めても話に入れる。

結末を評判で効かせるのは、ADR-0037の評判の条件を持つ選択肢がそのまま使えるからである。仕事の稼ぎを変えると、仕事ごとの釣り合いを決め直すことになる。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 屋台組合の年寄りを登場人物にして、人物のイベントにする | 登場人物を増やすと、DOM-10と資料の書き方を決め直すことになる |
| 勢力の話のイベントを、人物のイベントとは別の仕組みで進める | 同じ進み方の仕組みが2つになる |
| どちらに付くかを、1段目の選択だけで決める | それまでの周の評判が話に表れない |
| 結末で、下層街の仕事の稼ぎを変える | 仕事ごとの釣り合いを決め直すことになる |
| 結末で、遺体の取り立ての結末の文を書き分ける | 書き分けは人物のイベントの段どうしの仕組みで、ほかのイベントには使っていない |

## 影響

DOM-23を新しく起こし、勢力の話のイベントと、屋台通りの対立の3段を書く。DOM-14の資料の一覧に、対立の追記を足す。

`game/data/events.json`に3段のイベントを足す。`game_state.gd`は、人物と話のどちらかを持つイベントを、同じ進み方で扱う。`check_data.py`は、話のidを持つイベントの説明の書き分けと前の選択の条件も、同じ話の前の段を指すかで確かめる。セーブの形は変えない。

## 見直しの条件

勢力の話を2つ以上にしたくなったら、話ごとに起きやすさを分けるかを決め直す。
