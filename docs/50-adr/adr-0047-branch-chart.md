# 話とエンディングの分岐図を、街と人物の画面の3つ目のタブに出す

- 日付: 2026-10-20
- 状態: stable

## 背景

人物の話・勢力の話・元の持ち主の話・エンディングと、選択で分かれる道が増えた（[ADR-0038](./adr-0038-stall-street-feud.md)、[ADR-0041](./adr-0041-former-owner-memories.md)、[ADR-0043](./adr-0043-mio-character-events.md)、[ADR-0046](./adr-0046-third-ending.md)）。どの選択がどの段やエンディングにつながるかは、画面から分からなかった（issue #108）。作者は、Your ChronicleやDetroit: Become Humanのような分岐図を持ちたいと考えている。

issueでは、図に載せるものとまだ見ていないものの見せ方、図を置く画面の2つを決めることにしていた。作者からは、推奨の案で進めてよいと言われている。

## 決定

1. 分岐図に載せるのは、周をまたいで進む話（人物・勢力・元の持ち主）と、エンディングにする。ふつうのイベントは載せない。
2. 話ごとに1行にし、段を左から右へ箱で並べる。箱の中に選択肢を並べ、選んだ選択肢の印を塗る。
3. 前の選択の条件と話の条件は、条件の側の選択肢から開く側の選択肢へ線で結ぶ。レイの3段目の約束から、エンディング「目覚めの日」へも線が引かれる。
4. まだ選択肢を選んでいない段は、名前と選択肢を「？？？」で伏せる。線は伏せずに引く。
5. 分岐図は、街と人物の画面の3つ目のタブに置く。上のボタンは増やさない。
6. 図はデータから組み立て、Godotで箱と線を描く。画像は用意しない。
7. 分岐図は、新しいドメインノード[DOM-30](../20-domain/dom-30-branch-chart.md)に書く。

## 理由

ふつうのイベントを載せないのは、周をまたいで先へつながらず、選択肢の数だけ箱が増えるからである。

伏せた段にも線を引くのは、まだ見ていない先に分かれ道があることを、中身を明かさずに示すためである。Detroit: Become Humanの分岐図も、見ていない分岐を伏せたまま形だけを見せている。

街と人物の画面のタブにしたのは、上のボタンを増やすと英語で1280の幅に収まらない（[ADR-0022](./adr-0022-city-map-in-game.md)）からである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| すべてのイベントを図に載せる | 先へつながらないイベントの箱が大半になり、分かれ道が見えにくい |
| まだ見ていない段を図から消す | 見ていない先に分かれ道があることが分からない |
| まだ見ていない段の名前も出す | 話の中身を、選ぶ前に明かしてしまう |
| 上のボタンに分岐図を足す | 英語で1280の幅に収まらない |
| 図を画像で用意する | 話を足すたびに描き直すことになり、MODで足した話も載らない |

## 影響

DOM-30を新しく起こし、分岐図の並べ方と伏せ方を書く。

`game/scripts/branch_chart.gd`で分岐図を描き、街と人物の画面のタブに置く。`game/ci/chart.gd`で、分岐図が組み立てられるかをCIで確かめる。セーブの形は変えない。

## 見直しの条件

話が増えて図が読みにくくなったら、話ごとに畳めるようにするかを決める。選択肢を選び直す操作（issue #109）を分岐図に置くときは、その操作の置き場所をそちらで決める。
