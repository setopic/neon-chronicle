# 街を区画と3本の橋で分け、地図は設計文書の図に残す

- 日付: 2026-10-19
- 状態: deprecated（[ADR-0022](./adr-0022-city-map-in-game.md)が置き換えた）

## 背景

[DOM-15](../20-domain/dom-15-city-places-and-powers.md)は、街の場所を下層街・闇市場・企業区画の3つに決めていた。どこにあり、どうつながっているかは決めていなかった。企業区画の中の各社の縄張り、橋の数と位置、裏通りの診療所の場所も、配置としては書いていなかった（issue #52）。

イベントの文には、配置に触れるものがすでにあった。「合成食の荷運び」には「別の橋まで回って」とあり、橋は2本以上ある。「変電所の奪い合い」の変電所は企業区画の境にあり、止めると橋の向こうの下層街が暗くなる。「薬の配達」には、下層街のいちばん奥が出てくる。

issueでは、区画をどこまで細かく分けるか、地図をどの形で残すか、既にある場所を地図のどこに置くかの3つを決めることにしていた。

## 決定

1. 3つの場所の下に、区画を1段だけ足す。企業区画は、ヨミ・システムズ・ヴァルデック義体・モンフォール警備・リンドホルム食品の4つの縄張りに分ける。下層街は、屋台通り・裏通り・下層街の奥の3つに分ける。通りや建物の単位までは分けない。
2. 企業区画は高台にあり、下層街はその下の低い土地に広がる。2つをつなぐのは、北の橋・中の橋・南の橋の3本である。
3. 北の橋は、ヨミ・システムズの縄張りと裏通りをつなぐ。中の橋は、ヴァルデック義体とモンフォール警備の縄張りの間から、屋台通りへ下りる。南の橋は、リンドホルム食品の縄張りと屋台通りをつなぐ。下層街の奥は、どの橋からも遠い。
4. 闇市場の入口は、裏通りに1つだけある。裏通りの診療所は、その入口の近くにある。
5. 既にある場所は次のように置く。変電所は、ヨミ・システムズの縄張りの北の橋のたもとにある。ジンが忠告する橋は北の橋である。中枢サーバーは、ヨミ・システムズの本社ビルの地下にある。ジンには決まった居場所を置かず、通信で話すだけにする。
6. 地図は、DOM-15に図として載せる。ゲームの画面には出さない。ゲームの画面に地図を出すかは、別のissueで決める。

## 理由

区画を1段だけ足したのは、イベントの文がすでに触れている場所（橋、下層街の奥、変電所）を置ける細かさが、それで足りるからである。通りや建物の単位まで分けると、イベントの文に出てこない場所の名前が増える。

縄張りを4つにしたのは、DOM-15で各社が自分の縄張りを自前の私兵で守ると決めていて、企業が4社あるからである。モンフォール警備も企業なので、本社と社宅を置く縄張りを持つ。

橋を3本にしたのは、「合成食の荷運び」の「別の橋まで回って」が成り立つうえで、縄張りの数より少なくできるからである。橋はどの社の持ち物でもなく、モンフォール警備が見張るので、どの社の縄張りにも1本ずつある必要は無い。中の橋をヴァルデック義体とモンフォール警備の縄張りの間に置いたのは、橋を見張るモンフォール警備の本社が、橋の近くにあるようにするためである。

変電所と、ジンが忠告する橋を北の橋に寄せたのは、どちらもヨミ・システムズの縄張りの近くの出来事として書かれているからである。変電所を止めると、北の橋の向こうの裏通りが暗くなる。裏通りには主人公が毎周目覚める診療所がある。

地図を設計文書の図だけにしたのは、いまの目的が、イベントや資料の文を書くときに配置を揃えることだからである。ゲームの画面に出すと、描画と画面の配置の作業が要り、見積もりを超える。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 3つの場所のまま、つながりだけ書く | 橋の本数や、変電所・診療所の場所を決められない |
| 通りや建物の単位まで分ける | イベントの文に出てこない場所の名前が増え、決めることが増える |
| 橋を縄張りごとに1本ずつ、4本にする | 橋はどの社の持ち物でもないので、縄張りと1対1にする理由が無い |
| 「街と人物」の画面にも地図を出す | 描画と画面の配置の作業が要り、見積もりを超える。別のissueで決める |

## 影響

DOM-15に、区画とつながりの表、用語「縄張り」「屋台通り」「裏通り」「下層街の奥」、地図の図を足す。ゲームのデータと言語ファイルは変えない。

## 見直しの条件

ゲームの画面に地図を出すと決めたら、区画の細かさと橋の位置がそのまま使えるかを見直す。新しいイベントや資料で、ここに無い場所が要るようになったときも見直す。
