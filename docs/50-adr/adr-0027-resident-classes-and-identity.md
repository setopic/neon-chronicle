# 企業の階級と下層街の稼ぎを決め、身元で橋の行き来を分ける

- 日付: 2026-10-19
- 状態: stable

## 背景

階級ごとに住民の一生をたどると、企業区画と下層街の暮らしが階級の中で閉じていて、つながりが書けていなかった（issue #67）。社員と私兵は社宅に住むとしか書いておらず、工場で誰が働くかが無かった。下層街で店を持たない住人が何で食べているかも無かった。[DOM-09](../20-domain/dom-09-consciousness-copy.md)は、体ごとに身元が新しくなり、前の身元の口座はヨミ・システムズに凍結されると書いているが、下層街の住人が身元を持つかは無かった。モンフォール警備が捕まえた人をどうするかも決まっていなかった。

issueでは、企業の中の階級と働き手の出どころ、店を持たない住人の稼ぎ、身元とクレジット、階級の行き来、法と罰、画面のどこに出すかを決めることにしていた。

## 決定

1. 企業区画の階級を、重役・社員・私兵の3つとする。重役は社員から引き上げられ、本社ビルの上の階に住む。社員の多くは、社宅で生まれ育った社員の子である。私兵は、社員の子と下層街から雇われた者からなる。モンフォール警備の隊員は、モンフォール警備の私兵とする。
2. 企業の工場の下働きは、下層街から橋を渡って通う日雇いがする。日雇いは社員にならず、社宅に住まない。
3. 店を持たない下層街の住人は、日雇い・拾い屋・屋台組合の手伝い・運び屋やハッカーや傭兵の仕事で稼ぐ。
4. 身元は、ヨミ・システムズのネットに登録された人ごとの記録で、クレジットは身元に付いた口座でやり取りする。重役・社員・私兵は、属する企業が登録する社の身元を持つ。下層街でクレジットを受け取る住人の多くは、ハッカーが作って闇市場で売る偽の身元を使う。偽の身元は、ヨミ・システムズの監視に見つかると口座ごと消される。身元の無い住人は、クレジットを使わずに暮らす。
5. モンフォール警備は、橋を渡る者の身元を確かめ、身元の無い者を通さない。各社は、工場の働き手が要るので、日雇いの偽の身元を問いたださない。
6. 階級の行き来は2つだけにする。社員や私兵は、解雇されると社の身元を消され、社宅を出されて下層街へ下りる。下層街から企業区画へ上がる道は、私兵に雇われることだけである。
7. 街に裁判所は無い。人を裁いていた市が無くなったときに、裁く者もいなくなった。縄張りの中はその社が決め、私兵が罰を与える。橋と下層街では、モンフォール警備が罰金を払わせ、払えない者を下層街へ追い返す。牢屋は持たない。下層街の中のもめごとは、これまでどおり屋台組合とザンダー一家が片付ける。
8. 画面には、「街と人物」の資料「住民の暮らし」と、ハッカーのイベント「偽の身元」で出す。イベントと資料の仕組みは変えない。地図は変えない。

## 理由

社員の多くを社員の子にしたのは、社宅に住む社員がいる以上、社宅で育つ子がいるほうが自然で、社員を外から集める道を別に決めずに済むからである。工場の下働きを下層街の日雇いにしたのは、企業区画と下層街の暮らしが、橋を通ってつながるからである。モンフォール警備が橋を見張る意味も増える。

身元を偽の身元で分けたのは、作者がこの案を選んだからである（issue #67のスレッドの選択）。闇市場で偽の身元が売られるなら、インプラント「信用スコア偽装」がネット上の身元に組み込まれることや、企業の買い手が身元を隠して闇市場に出入りすることと話がつながる。モンフォール警備が橋で身元を確かめる理由にもなる。

上がる道を私兵だけにしたのは、下層街の者が企業区画で役に立つのは、まず腕っぷしだからである。上がる道が細いほど、下層街から抜け出せない暮らしが伝わる。傭兵が社の身元を受け取らないのは、1つずつ仕事を請け負う者で、社に雇われ続けるわけではないからである。

裁判所を置かなかったのは、市が財政破綻して市役所が無くなったという[ADR-0025](./adr-0025-city-history-before-corporations.md)の歴史と合うからである。モンフォール警備に牢屋を持たせなかったのは、各社が出し合った金で動く会社が、捕まえた者を養う理由が無いからである。

画面をハッカーのイベントにしたのは、偽の身元を作るのがハッカーの仕事だからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 下層街の住人も、ヨミ・システムズに登録された正規の身元と口座を持つ | 作者が偽の身元の案を選んだ。橋の見張りと身元の話がつながらない |
| 下層街には身元もクレジットの口座も無く、物と物で取引する | 作者が偽の身元の案を選んだ。主人公が下層街でクレジットを稼ぐ遊び方と食い違う |
| 社員を、社が下層街や外の街から集める | 社員の子が社員になるほうが、社宅の暮らしと合う。外の街は、まだ決めていない |
| 工場の働き手も社員にする | 下層街の住人が企業区画へ行く理由が無くなり、2つの暮らしがつながらない |
| 下層街から社員に上がる道を作る | 上がる道が太いと、下層街から抜け出せない暮らしが伝わらない |
| 市の時代の裁判所が残っていて、企業が雇った判事が裁く | 市役所が無くなったという歴史と合わない |
| モンフォール警備が牢屋を持つ | 各社の出資で動く会社に、捕まえた者を養う理由が無い |

## 影響

[DOM-18](../20-domain/dom-18-resident-classes.md)を新しく置き、階級・稼ぎ・身元・行き来・罰を書く。[DOM-15](../20-domain/dom-15-city-places-and-powers.md)の場所の表の下層街の行に、イベント「偽の身元」を足す。[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)の資料の一覧に「住民の暮らし」を足し、依存先にDOM-18を足す。

`game/data/events.json`にイベント「偽の身元」を、`game/data/profiles.json`に資料`residents`を足す。言語ファイルに、新しいイベントと資料のキーを足す。

## 見直しの条件

身元や罰金を、イベントの選択肢の条件や数値に結び付けるときは、身元の扱いを見直す。ネオン・シティの外の街を決めるときは、社員や私兵の出どころを見直す。
