# 話の段と永続強化の組を、いつでも選び直せるようにする

- 日付: 2026-10-20
- 状態: stable

## 背景

人物の話・勢力の話・元の持ち主の話で選んだ選択肢は、選び直せなかった。そのため、レイの2段目で断ると、そのデータではエンディング「目覚めの日」の選択肢が出なくなっていた（[ADR-0046](./adr-0046-third-ending.md)）。永続強化の排他の組も、取り直せなかった（[ADR-0033](./adr-0033-upgrade-groups.md)）。作者は、最終的に取り返しの付かない要素を無くしたいと考えている（issue #109）。

issueでは、取り返せるようにするものとその方法、取り返すときの代価の有無の2つを決めることにしていた。作者からは、推奨の案で進めてよいと言われている。

## 決定

ADR-0033の8つの決定のうち、4つめだけを改める。

1. 永続強化を6つ足し、9つにする（そのまま）
2. 同じ組の永続強化は、1つしかレベルを持てない（そのまま）
3. 組は「型」と「先と今」の2つにする（そのまま）
4. 一度選んだ組の永続強化は取り直せない（改める。下記の2）
5. 転生の画面のボタンに組の相手を添える（そのまま）
6. インプラントの値段は、もとの半分を下回らない（そのまま）
7. 記憶ポイントの上乗せは、依頼の上乗せの前に掛ける（そのまま）
8. 世界の中での説明は、どれも意識の写しの改良とする（そのまま）

新しく決めることは次のとおりである。

1. 話の段は、すでに選択肢を選んだ段から選び直せる。選び直すと、その段と同じ話の後の段の選択が話の進み具合から消え、その段はまた起きうる。
2. 排他の組の永続強化は、選び直せる。その永続強化に払った記憶ポイントをすべて戻し、レベルを0にする。
3. どちらも代価は取らない。
4. 選び直しても、選んだときに得た評判・経験・クレジットと、記録の物語文は戻さない。
5. 話の選び直しは、分岐図のタブに、選んだ段ごとのボタンとして置く。永続強化の選び直しは、転生の画面の永続強化の下に、レベルを持つ組の永続強化ごとのボタンとして置く。
6. 話の選び直しは、新しいドメインノード[DOM-31](../20-domain/dom-31-choosing-again.md)に書く。

## 理由

話の段を選び直せるようにしたのは、どの段も1つの周に1段までしか進まないので、選び直したあとにもう一度その段に出会うまで、何周か遊ぶことになるからである。代価を取らなくても、選び直しには時間の重みがある。

評判や経験を戻さないのは、戻すと、選んだときの周の状態まで決め直すことになるからである。記録は過ぎた周の出来事なので、消さない。

永続強化の記憶ポイントをすべて戻すのは、一部だけを戻すと、何度も選び直すほど記憶ポイントが減り、選び直すことそのものを避けるようになるからである。ADR-0033が取り直しを置かなかった理由の1つは、戻す量と手数料を決めることだった。すべて戻して手数料を取らないと決めれば、その問いは無くなる。

分岐図に話の選び直しを置くのは、どの段を選び直せばどこへ行けるかを、図を見て決められるからである（[ADR-0047](./adr-0047-branch-chart.md)）。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 話の選び直しに記憶ポイントを払う | 取り返すたびに記憶ポイントが減り、取り返しの付かなさが代価の形で残る |
| 選び直すと、その段で得た評判と経験も戻す | 選んだときの周の状態まで決め直すことになる |
| 話の段の選択を、いつでもその場で選び直せるようにする | 段がまた起きることを待たずに結末を見て回れ、話を進める理由が無くなる |
| 永続強化の選び直しで、記憶ポイントの半分だけを戻す | 選び直すほど記憶ポイントが減り、選び直すことそのものを避けるようになる |
| 最初からやり直すことを、取り返す手段のままにする | 取り返しの付かない要素を無くしたいという作者の考えに合わない |

## 影響

DOM-31を新しく起こし、話の選び直しを定義する。DOM-05の排他の組の不変条件を、選び直すときに記憶ポイントを戻す形に改める。

`game_state.gd`に、話の段を選び直す操作と、永続強化を選び直す操作を足す。分岐図のタブに選び直すボタンを、転生の画面に永続強化を選び直すボタンを置く。`ci/chart.gd`で、選び直したときに消える選択と戻る記憶ポイントを確かめる。セーブの形は変えない。

## 見直しの条件

選び直しを繰り返して、どの話も同じ周の間に何度も見て回る遊び方が広まったら、選び直しに間を置くかを決める。
