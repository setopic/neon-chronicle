# 画面の見た目の方向と、その土台を決める

- 日付: 2026-10-20
- 状態: stable

## 背景

画面の見た目が少し古めかしい。作者は、Cyberpunk 2077やDetroit: Become Humanのような、名の知られたゲームと比べても見劣りしない画面にしたい（issue #118）。画面はどれも`game/scripts/main.gd`がコードで組み立てていて、色や余白をその場で1つずつ当てていた。紫がかった地に桃色と水色を当て、枠の角は丸めていた。

issueでは、寄せる方向と、色・文字・枠・動きをまとめる場所と、新しいフォントや素材を使うかを決めることにしていた。各画面に当てるのは#119と#120に分ける。

## 決定

1. 2つを混ぜる。全体はDetroit: Become Humanに寄せ、暗い紺の地に細い線の枠と白い本文を置く。Cyberpunk 2077からは、角を斜めに切った枠と、走査線のような横線だけを取る。強調の色は、いまの水色（見出しと選んでいるもの）と桃色（題と入った額）の2つに絞り、黄色は足さない。
2. 色・文字の大きさ・枠・動きを、`game/scripts/ui_style.gd`（`UiStyle`）の定数と関数にまとめる。GodotのThemeもここのコードで作り、`main.gd`の根に当てる。画面を組み立てる側は、この定数を使い、その場で色や大きさを決めない。
3. 枠は、パネルの左上と右下の角を斜めに切る。ボタンも同じ形で小さく切り、選んでいるボタンは左の縁を太くする。
4. 動きは2つにする。画面を出すときに0.18秒で浮かび上がらせる動きと、ボタンに乗ったときやキーボードで選んだときに0.08秒で明るくする動きである。
5. 新しいフォントや素材は使わない。文字はいまのNoto Sans JPのままにし、題だけ字の間を少し空ける。
6. 試しに、メインの画面の上の帯に当てる。題と状態の行を、街の上に重ねた半透明の板に載せ、帯に走査線と下の縁の線を引き、右上のボタンに乗ったときの動きを付ける。テーマを差し替えたので、ほかの画面のボタンと枠の形も変わる。

## 理由

Cyberpunk 2077の黄と赤の強い色とノイズの演出を全面に当てると、文字の多いこのゲームでは本文が読みにくくなる。仕事・スキル・インプラントの欄は数字と説明の文が並ぶので、落ち着いた地に白い本文を置くDetroitの画面のほうが読みやすい。それだけではネオンの街の雰囲気が薄れるので、枠の形と走査線で街の世界観を残した。

強調の色を2つに絞ったのは、色ごとに意味を持たせるためである。水色は見出しと選んでいるもの、桃色は題と入った額にあて、赤は危ないものにだけ使う。

まとめる場所をGodotのThemeのファイル（`.tres`）にしなかったのは、ラベルの色や動きの長さのように、Themeに入らない値があるからである。Themeのファイルとスクリプトの定数に分けると、値が2か所に散らばる。

新しいフォントを足さなかったのは、日本語の字の範囲を持つ見出し用のフォントが少なく、足すとサブセットとライセンスの管理が増えるからである。字の間を空けるだけで、題はほかの文と区別できる。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| Cyberpunk 2077に寄せ、黄と赤の強い色とノイズの演出にする | 文字の多い欄が読みにくくなる |
| Detroit: Become Humanに寄せ、白と青だけの端正な画面にする | ネオンの街の雰囲気が薄れる |
| GodotのThemeのファイル（`.tres`）にまとめる | ラベルの色や動きの長さはThemeに入らず、値が2か所に散らばる |
| これまでどおり`main.gd`の定数に置く | 仕事の様子やミニゲームの画面を別のスクリプトに分けたとき、同じ値を使えない |
| 見出し用のフォントを足す | 日本語の字の範囲を持つものが少なく、サブセットとライセンスの管理が増える |
| ボタンに乗ったときに大きくする | 並んだボタンの位置がずれ、1280x720に詰めた配置が崩れる |

## 影響

ARCH-01の部品の表に`ui_style.gd`を足す。`main.gd`は、色の定数とThemeを`UiStyle`から取る。上の帯は、題と状態を板に載せ、走査線と下の縁の線を引き、右上のボタンに動きを付ける。メインの画面の欄と、転生の画面・ダイアログの中身は、#119と#120で`UiStyle`の値に移す。ADR-0017とADR-0049は書き換えない。右上のボタンを2段に置くことと、画面を1280x720に収めることは、そのまま生きている。

## 見直しの条件

走査線や斜めの角で、文字が読みにくいという声が出たら、決定の1と3を見直す。見出し用に日本語の字の範囲を持つフォントが見つかったら、決定の5を見直す。
