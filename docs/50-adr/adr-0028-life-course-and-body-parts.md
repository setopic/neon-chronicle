# 子どもは親の暮らしの中で育ち、下層街の死者の部品は闇医者が闇市場へ流す

- 日付: 2026-10-19
- 状態: stable

## 背景

街には子どもが1人も出てこず、病気・老い・死も書いていなかった（issue #68）。医者は、主人公が目覚める裏通りの診療所しか無かった。屋台組合の年寄りはいるが、老いて働けなくなった人の暮らしは無かった。[闇市場](../20-domain/dom-15-city-places-and-powers.md)で売り買いされる体の部品の出どころも、決まっていなかった。

issueでは、子どもの育ち方と仕事の覚え方、病気やけがを誰が診るか、老いたあとの暮らし、死んだ人をどうするか、画面のどこに出すかを決めることにしていた。

## 決定

1. 重役・社員・私兵の子は、自社の縄張りの社の病院で生まれ、社の学校で学び、社員か私兵になる。
2. 下層街の子は住まいで生まれ、近所の年寄りや闇医者が取り上げる。下層街に学校は無く、子どもは親や親方に付いて仕事を覚える。親のいない子は、屋台組合が店に預けて手伝わせる。預け先の無い子は拾い屋になり、その一部が路地のチンピラになる。
3. 社の身元を持つ者は、社の病院が診る。下層街では、払える者なら誰でも闇医者が診る。裏通りの診療所も、下層街の闇医者の1つとする。闇市場の薬の多くは、企業の倉庫から盗まれたものとする。
4. 社を退いた者は、社員である子の社宅で暮らす。社員である子がいなければ、社の身元を消されて下層街へ下りる。下層街の年寄りは、家族や弟子が養う。養う者のいない年寄りには、屋台組合が合成食と水を分ける。
5. 社の身元を持つ者が死ぬと、社が遺体を引き取って焼く。インプラントは社が貸していたものとし、焼く前に回収する。
6. 下層街の住人が死ぬと、家族が遺体を闇医者へ運ぶ。闇医者はインプラントと使える臓器を取り出して家族に代金を払い、闇市場へ売る。闇市場の体の部品は、ほとんどがこれである。残りは、下層街の奥にある屋台組合の焼き場で焼き、灰を排水路に流す。
7. 借金を残して死んだ者の遺体は、ザンダー一家が取り立てとして引き取り、体の部品を売って借金に充てる。
8. 画面には、「街と人物」の資料「生まれから死まで」と、傭兵のイベント「遺体の取り立て」で出す。イベントと資料の仕組みは変えない。地図は変えない。

## 理由

子どもを親の暮らしの中で育てたのは、[ADR-0027](./adr-0027-resident-classes-and-identity.md)で社員の多くを社員の子とし、下層街から上がる道を細くしたことと合うからである。社の学校で社の仕事を覚える子と、親方に付いて仕事を覚える子に分かれれば、生まれた階級から抜け出しにくい理由になる。

医者を身元で分けたのは、社の身元を持つかどうかで、受けられるものが変わるという[DOM-18](../20-domain/dom-18-resident-classes.md)の分け方に合うからである。裏通りの診療所を闇医者の1つにしたのは、裏通りの診療所だけでは、下層街の住人を診きれないからである。

体の部品を下層街の死者から取るとしたのは、作者に選んでもらう前に、推奨の案で書き進めたからである（issue #68のスレッドの選択）。闇市場の部品の出どころと、下層街の貧しさが1つにつながる。インプラントの多い街では、死者の体にも値が付くほうが自然である。社がインプラントを回収するとしたのは、社が貸したものなら、社員の遺体の部品が闇市場へ流れない理由になるからである。

焼き場を屋台組合のものにしたのは、組合が盗電の線と水を分けているので、焼くための電気も組合が引けるからである。灰を排水路に流すのは、低い土地に墓を作る場所が無いからである。

画面を傭兵のイベントにしたのは、傭兵の仕事のイベントがほかの仕事より少ないからである。ザンダー一家に雇われる仕事は、一家が企業の汚れ仕事を請け負うという[ADR-0024](./adr-0024-lower-city-gang-and-union.md)の決定とも合う。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 闇市場に流れるのはインプラントだけにする | 体の部品の出どころが半分しか決まらない |
| 体の部品は企業の倉庫から盗まれたものだけにし、死者はそのまま焼く | 下層街の暮らしとつながらない |
| 下層街にも屋台組合の学校を置く | 組合は住人の自治組織で、子どもを教える人手が無い。親方に付く暮らしのほうが、抜け出しにくさが伝わる |
| 社を退いた者も、社宅に住み続ける | 社員である子がいなければ下りるほうが、社の身元に頼る暮らしの細さが伝わる |
| 下層街に墓地を置く | 低い土地は住まいで埋まっていて、墓を作る場所が無い |

## 影響

[DOM-19](../20-domain/dom-19-resident-life-course.md)を新しく置き、子ども・病気やけが・老い・死を書く。[DOM-15](../20-domain/dom-15-city-places-and-powers.md)の場所の表の下層街の行に、イベント「遺体の取り立て」を足す。[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)の資料の一覧に「生まれから死まで」を足し、依存先にDOM-19を足す。

`game/data/events.json`にイベント「遺体の取り立て」を、`game/data/profiles.json`に資料`life_course`を足す。言語ファイルに、新しいイベントと資料のキーを足す。

主人公の体と、被験体の出どころは、ここでは決めない。issue #69で決める。

## 見直しの条件

主人公の体や被験体の出どころを決めるときに、体の部品の出どころと食い違えば見直す。下層街の子どもや年寄りを人物として画面に出すときは、育ち方と老い方を見直す。
