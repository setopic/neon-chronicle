# メインの画面の欄を、2つずつ組にして入れ替えられるようにする

- 日付: 2026-10-20
- 状態: stable

## 背景

#119でメインの画面に新しい見た目（[ADR-0052](./adr-0052-ui-style-foundation.md)）を当て、欄の並びはそのままにした。そのあと、欄の並びを利用者が自分で変えたいという要望が出た（issue #135）。既定の並びは、いまのままでよい。

メインの画面は、上の帯の下に5つの欄を置いている。左の列の上の段に仕事と体の状態、下の段に仕事の様子（幅300px、[ADR-0053](./adr-0053-job-scene.md)）とログ（高さ180px）を並べ、右の列にインプラントを置く。どの欄も1280x720に収まるよう大きさを決めてある。

issueでは、動かせる欄と、並びの変え方と、並びを残す場所と既定へ戻す手段と、1280x720に収まらない並びの防ぎ方を決めることにしていた。

## 決定

1. 上の帯は動かさない。動かせるのは、帯より下の5つの欄である。
2. 欄は、次の4つの組ごとに、組の2つを入れ替えられるようにする。自由な位置へは動かせない。4つの組は互いに関わらないので、並びは16通りになる。
   - 仕事と体の状態
   - 仕事の様子とログ
   - 仕事・体の状態の段と、仕事の様子・ログの段
   - インプラントの列と、ほかの欄
3. 上の帯の読み物のボタンの段に「並べ替え」のボタンを置く。押すと出る画面に、組ごとの入れ替えのボタンと、既定の並びに戻すボタンを並べる。押すと、その場で画面の並びが変わる。
4. 入れ替えた組は、言語や音の設定と同じ`user://settings.json`の`panel_layout`に残す。セーブには入れないので、最初からやり直しても並びは変わらない。何も入れ替えていなければ、いまの並びで出る。
5. 1280x720に収まるかは、CIで確かめる。日本語と英語で16通りの並びをすべて組み立て、欄が画面の中にあることと、上の帯の題とボタンが帯の幅に収まることを見る（`game/ci/layout.gd`）。

## 理由

組の中で入れ替えるだけにしたのは、欄の大きさを変えずに済むからである。入れ替えた2つは、同じ箱の中で順が変わるだけなので、どの並びでも既定の並びと同じ大きさの枠に収まる。仕事の様子の欄を幅300pxの枠から外したり、ログを高さの足りない枠に入れたりする並びが、そもそも作れない。

上の帯を動かさないのは、帯に3Dの街と状態とボタンを重ねていて、高さ140pxに合わせて作ってあるからである。帯を下の段に置くと、ボタンが画面の下の端に来る。

ボタンを読み物の段に置いたのは、英語でも幅に余りがあるからである。測ると、英語の帯の題とボタンの行は、ボタンを足しても1,228pxのうち1,004pxに収まる。

並びを設定に残すのは、言語や音と同じく画面の好みであって、周や進行とは関わらないからである。セーブに入れると、最初からやり直すたびに並びが既定に戻る。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 欄の見出しをドラッグして、好きな位置へ動かす | 欄ごとに大きさが違い、幅300pxの仕事の様子や高さ180pxのログが、収まらない枠に入る並びを防ぐ仕組みが要る |
| 決まった並びをいくつか用意して、その中から選ぶ | 利用者が変えたい組だけを変えられない。4つの組を入れ替えれば、同じ並びを作れる |
| 上の帯も入れ替えられるようにする | 帯は高さ140pxに合わせて作ってあり、下の段に置くとボタンが画面の下の端に来る |
| 並びをセーブに入れる | 最初からやり直すたびに既定に戻る。並びは周や進行と関わらない |

## 影響

ARCH-01の部品の表で、`Loc`が保存する設定に欄の並びを足し、`main.gd`が欄の並びを入れ替えられることを書く。言語ファイルに、並べ替えのボタンと画面の文を足す。CIに`game/ci/layout.gd`を足す。ADR-0052とADR-0053は書き換えない。欄の大きさと、既定の並びで仕事の様子をログの左に置くことは、そのまま生きている。

## 見直しの条件

4つの組では作れない並びを求める声が出たら、決定の2を見直す。上の帯にボタンを足して、英語で帯の幅に収まらなくなったら、決定の3のボタンの置き場を見直す。
