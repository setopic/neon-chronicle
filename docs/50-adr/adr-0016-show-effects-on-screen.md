# インプラントと体の種類の効果を画面の文に出す

- 日付: 2026-10-18
- 状態: stable

## 背景

インプラントの効果は、ボタンのツールチップにしか出なかった。マウスを重ねないと分からず、ブラウザを指で触る場合は見られない。体の種類の効果は転生の画面のボタンに出るが、目覚めたあとの周の間はどこにも出なかった。体の種類・インプラント・永続強化の効果を合わせて、いま稼ぎや経験や劣化がどれだけ増減しているかも分からなかった（issue #45）。

issueでは、効果をどこに出すかと、効果を合計して見せるか出どころごとに見せるかの2つを決めることにしていた。

## 決定

1. インプラントのボタンの文に、名前と値段の間に効果を出す。効果の文は`game/data/implants.json`の効果から作るので、MODで足したインプラントにも出る。ツールチップの説明はそのまま残す。
2. 体の欄に、いまの体の種類とその効果を「作業用の体：体の劣化速度 -25%、経験 -10%」の形で1行出す。文は転生の画面のボタンと同じ`body.<id>.desc`を使う。
3. 体の欄に「効果の合計」を1行出し、稼ぎ・経験・体の劣化速度の効果を、出どころを分けずに合計した割合で出す。経験にはクロニクルの経験の上乗せ（[DOM-07](../20-domain/dom-07-chronicle-story.md)）も含める。体の劣化速度は、[DOM-03](../20-domain/dom-03-jobs-and-skills.md)の下限を当てたあとの、実際に掛かっている割合を出す。
4. 体の欄が画面の高さに収まるよう、記憶ポイントを体の欄から上の周の状態の行へ移す。転生の画面の記憶ポイントはそのまま残す。

## 理由

インプラントの効果をボタンの文に出したのは、組み込む前に、ツールチップを見ずに効果が分かるようにするためである。説明の文をそのまま出さなかったのは、信用スコア偽装の説明のように、効果のほかに理由を書いた長い文があるからである。

効果の合計を出どころごとに分けなかったのは、出どころは体の種類・インプラント・永続強化・スキル・クロニクルの5つあり、分けると体の欄が画面に収まらないからである。それぞれの効果は、体の種類なら体の欄、インプラントならボタン、永続強化なら転生の画面で読める。合計は、それらを足した結果だけを見せればよい。

記憶ポイントを上へ移したのは、体の欄に2行足すと、1280×720で欄の中がスクロールになり、記憶ポイントが見えなくなったからである。記憶ポイントは周の間は増えないので、周の状態と並べても意味が変わらない。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| インプラントの説明の文をボタンに出す | 信用スコア偽装の説明は理由まで含めて長く、ボタンが2行になる |
| 効果を出どころごとに分けて出す | 出どころが5つあり、体の欄が画面に収まらない |
| 効果の合計を出さない | issueの背景にある「いまどれだけ増減しているか」が分からないままになる |
| ログの欄を低くして体の欄に高さを回す | ログの高さは、中段をスクロールにしてまで守っているので、削らない |

## 影響

DOM-04とDOM-11の定義は変わらない。画面の文が増えるだけである。

言語ファイルに、効果の文のキー（`ui.fx_income`・`ui.fx_xp`・`ui.fx_decay`・`ui.fx_start_level`・`ui.fx_none`・`ui.list_sep`）と、`ui.body_effects`・`ui.effect_total`を足す。

## 見直しの条件

効果の出どころや種類が増えて、合計の1行が画面に収まらなくなったら見直す。出どころごとに知りたいという声が出たときも見直す。
