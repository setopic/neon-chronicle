# ザンダー一家をザンダー・ファミリーと呼ぶ

- 日付: 2026-10-19
- 状態: stable

## 背景

[ADR-0024](./adr-0024-lower-city-gang-and-union.md)は、下層街のギャングをザンダー一家（英語ではZander Family）と呼ぶことにした。作者から、マフィアやギャングの呼び名としては「ザンダー・ファミリー」のほうがよい、という要望が出た（issue #68のスレッド）。

## 決定

ADR-0024の決定のうち、ギャングの日本語の呼び名だけを改める。ほかはそのまま引き継ぐ。

1. 下層街のギャングを1つ置き、頭の家の名前で呼ぶこと、裏通りと闇市場を仕切って場所代とみかじめを取ること（改める。日本語の呼び名を「ザンダー・ファミリー」にする。英語はZander Familyのまま）
2. 企業が表に出せない仕事を回し、モンフォール警備が金を受け取って見逃すこと（そのまま）
3. 屋台組合を置くこと（そのまま）
4. 路地のチンピラを別の小さな集まりのままにすること（そのまま）
5. 住人が路地のチンピラをダニやハイエナと蔑むこと（そのまま）
6. 画面に資料とイベント「みかじめの運び」で出すこと（そのまま）

日本語の文では、ザンダー・ファミリーを略すときも「ファミリー」と書き、「一家」とは書かない。

## 理由

作者がこの呼び名を選んだからである。「ファミリー」は、マフィアやギャングの組織の呼び名として通じる。英語のZander Familyとも、同じ語になる。

略すときに「一家」を使わないのは、2つの呼び名が混ざると、同じ組織かどうかが読み手に分かりにくくなるからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ザンダー一家のままにする | 作者の要望に合わない |
| ザンダーファミリーと中黒を入れずに書く | ネオン・シティやヨミ・システムズなど、ほかのカタカナの固有名は語の間に中黒を入れている |

## 影響

[DOM-15](../20-domain/dom-15-city-places-and-powers.md)の勢力の表と用語表の名前を「ザンダー・ファミリー」にし、旧称に「ザンダー一家」を書く。[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)・[DOM-18](../20-domain/dom-18-resident-classes.md)・[DOM-19](../20-domain/dom-19-resident-life-course.md)の文も直す。

`game/lang/ja.json`の文で、ザンダー一家と一家を、ザンダー・ファミリーとファミリーに直す。英語の文は変えない。

## 見直しの条件

ザンダー・ファミリーの人物を、名前のある登場人物として出すときに、呼び名を見直す。
