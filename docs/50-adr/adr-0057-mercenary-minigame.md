# 傭兵の仕事のミニゲームを、窓に出る敵を撃つ遊びにする

- 日付: 2026-10-20
- 状態: stable

## 背景

仕事の1回をミニゲームで置き換える仕組みを、[ADR-0054](./adr-0054-minigame-frame.md)で作った。issue #125では、傭兵の仕事のミニゲームの遊び方と、難しさをスキルのレベルでどう変えるかを決めることにしていた。issueの例には、狙って撃つことと、遮蔽物を移ることが挙がっていた。ハッカー（[ADR-0055](./adr-0055-hacking-minigame.md)）と運び屋（[ADR-0056](./adr-0056-courier-minigame.md)）のミニゲームはできている。

## 決定

1. 遊び方は、横に並んだ4つの窓に、敵が1人ずつ顔を出すので、撃ち返される前にその窓を撃つものにする。敵は8人で、どの窓に出るかは無作為に決める。
2. 敵が顔を出している時間は、レベル0で1.2秒とし、傭兵の対応スキルである格闘のレベル1ごとに0.05秒延ばし、2.2秒まで延ばす。時間が切れると撃たれて、その敵は引っ込む。敵が引っ込んでから次の敵が出るまでは0.5秒空ける。
3. 成功の度合いは、倒した敵の数を8で割った値から、誰もいない窓を撃った回数1回につき0.05を引いたものとする。0より小さくはしない。撃たれても罰は無く、その敵を倒せなかった分だけ度合いが下がる。
4. 窓はボタンにする。マウスで押せるほか、キーボードでは番号のキー（1〜4）で撃てる。矢印で窓を選んで決定のキーで撃つこともできる。

## 理由

窓に出る敵を撃つ形にしたのは、issueの例の「狙って撃つ」を、マウスでもキーボードでも同じ手間で遊べる形にするためである。マウスで照準を動かす形は、キーボードだけでは遊べない。

ハッカーと運び屋のミニゲームは、先を読んで選ぶ遊びである。傭兵は戦闘の仕事なので、素早く反応する遊びにして、3つの手触りを分けた。ただし、敵が出る窓は4つに絞り、番号のキーで1回押せば撃てるので、手の速さの差が出すぎないようにした。

レベルが上がるほど易しくする向きは、ほかの2つのミニゲームとそろえた。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| マウスで照準を動かして撃つ | キーボードだけでは遊べない |
| 遮蔽物の間を移りながら撃ち合う | 移る操作と撃つ操作が重なり、キーボードとマウスの両方で遊べる形にしにくい |
| 撃たれたら体の耐久を減らす | ミニゲームで失敗したときに罰を付けないとした、ADR-0054の決定4と食い違う |
| レベルが上がるほど、敵を速くして難しくする | スキルを上げるほど遊びにくくなり、上げた手応えが逆になる |

## 影響

DOM-03のミニゲームの種類に、傭兵のミニゲームが加わる。`game/data/jobs.json`の傭兵の`minigame`を`mercenary`にする。`game/scripts/minigame_mercenary.gd`がこのミニゲームを持ち、`ci/minigame.gd`で、すぐに撃てば度合いが1、撃たなければ0になることを確かめる。

これで、ミニゲームを持つ仕事のすべてに遊び方ができた。ADR-0054の決定8の仮のミニゲームは使う仕事が無くなったので、`minigame.gd`から外す。仕事を足して遊び方を作るまでは、`jobs.json`に`minigame`を書かなければ、その仕事はミニゲームで終えられない。

## 見直しの条件

手の速さで度合いが大きく分かれ、遊ぶ気が起きないという声が出たら、決定の2の時間を見直す。
