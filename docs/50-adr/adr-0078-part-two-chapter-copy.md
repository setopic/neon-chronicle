# 第二部の第4章で、持ち出された写しを止める作戦を遂げ、第二部を終える

- 日付: 2026-10-21
- 状態: stable

## 背景

[ADR-0075](./adr-0075-part-two-after-reclaim.md)は、第二部の第4章の題を「写し」、新しい遊び方を章の最後の大きな仕事とした。筋は、中枢サーバーに残った主人公の意識の写しを、九条が別の体に読み込んで使い始めるものである（issue #184）。[ADR-0077](./adr-0077-part-two-chapter-hideout.md)は、第3章の終わりで、研究部門が主人公の意識の写しを中枢サーバーから持ち出したことが分かるとした。

この筋は、[DOM-09](../20-domain/dom-09-consciousness-copy.md)の不変条件「同じ主人公が、2つの体で同時に目覚めることはない」とぶつかる。ADR-0075の決定7は、第4章でヨミ・システムズの研究部門の一部を崩すところまでを描くとした。ADR-0075の決定10は、章ごとに長さを測って、合わせて20時間に届くかを確かめるとした。

第4章を作るには、写しが2つの体で目覚めることを認めるか、写しを最後にどうするか、研究部門のどこを崩すか、大きな仕事の遊び方、第4章の長さを決める必要があった。

## 決定

1. 本当の体に戻ったあとは、主人公と、中枢サーバーに残った意識の写しを読み込んだ体が、同時に目覚めていることがある。第一部では、これまでどおり、同じ主人公が2つの体で同時に目覚めることはない。DOM-09の不変条件を、この範囲に決め直す。
2. 第4章では、研究部門が、持ち出した写しを、下層街に近い施設で使い捨ての体に読み込み、汚れ仕事に使う。九条は、これまでどおり画面に出さない。
3. 主人公は、その施設を崩し、写しを体に読み込む装置を壊す。崩すのは施設1つで、中枢サーバーと九条には届かない。ヨミ・システムズは倒れずに残る。第一部の転生はこれまでどおり起き、その理由は、遊ぶ人の側の仕組みとして世界の中では決めない。
4. 装置が壊れると、写しはもう次の体へ読み込み直されない。写しの使い捨ての体は劣化で倒れ、写しはそこで終わる。主人公は写しを救えない。写しの最期は、選択肢で変わらない。
5. 章の最後の大きな仕事を、作戦と呼ぶ。作戦は、潜入・防壁・決着の3つの段階を、この順に挑む。段階ごとに、要るスキルとそのレベル、挑むと減る体調、合う仲間が決まっている。

   | 段階 | スキル | 要るレベル | 合う仲間 | 減る体調 |
   | --- | --- | --- | --- | --- |
   | 潜入 | 交渉 | 26 | サキ | 50 |
   | 防壁 | ハッキング | 28 | トワ | 55 |
   | 決着 | 格闘 | 33 | ゴウ | 60 |

6. 仲間に任せる先に、作戦を足す。仲間を作戦に付けると、その仲間が合う段階で、要るレベルが4下がる。作戦に付けている間、その仲間は稼がない。作戦をすべて越えると、作戦に付けた仲間は、得意な仕事を任された状態に戻る。
7. 段階に挑めるのは、要るレベルに届いていて、その章のクレジットを払う目標をすべて払い終えたときである。挑むと、その段階の体調が減る。体調が0以下になったら、しくじって倒れる。倒れ方は、体調が0になったときと同じである。しくじった段階はやり直しになり、越えた段階は残る。うまくいくかは乱数を使わず、条件だけで決まる。
8. 第4章の章の目標は、作戦の手はずを整える（1000000クレジットを払う）と、施設の読み込みの装置を壊す（作戦をすべて越える）の2つとする。章の目標の種類に、作戦（作戦の段階をすべて越えた）を足す。章の出来事は、写しが目覚めたことが分かる出来事、写しの手口を見る出来事、潜入のあとの出来事、防壁のあとの出来事、章の終わりの5つで、この順に起きる。章の出来事の起きる条件に、越えた段階の数を足す。
9. 第4章の長さは、人が遊んで約2.5時間とする。`game/ci/part_two.gd`は、第3章に続けて第4章を終えるまで遊び、第4章にかかったゲーム内の時間が70分より短いか110分より長いときに失敗とする。人の時間への換算は、ADR-0075の決定9と同じ比を使う。
10. 第二部は第4章で終える。第4章を終えたあとも、第二部の暮らしはそのまま続けられ、終えたことを示す文を出す。
11. 第二部の4章を合わせても、20時間には届かない。ADR-0075の決定10のとおり、第三部を足す。第三部の中身は、別のissueで決める。

ADR-0075・ADR-0076・ADR-0077は置き換えない。第二部の章の組み立て、第1章から第3章の長さ、仲間と隠れ家の決まりは、そのまま生きている。

## 理由

写しが2つの体で目覚めることを認めたのは、章の題が「写し」で、主題が「使い捨て」だからである。自分の意識の写しが、使い捨ての体で汚れ仕事をさせられる場面で、主題をいちばん近くから描ける。決め直す範囲を本当の体に戻ったあとに限ったので、第一部の転生の説明（DOM-09の属性の表）は変えずに済む。

写しを救えないことにしたのは、主題の「使い捨て」を、写しの最期で描くためである。写しを匿って残すと、もう1人の主人公が第二部のあいだ残り、第三部の筋まで縛る。主人公が写しを倒す筋は、自分の写しを手にかけることになり、重くなりすぎる。写しの最期を選択肢で変えないのは、ADR-0075の決定2で、第二部の筋を1本にしたからである。

崩すものを、読み込みの装置のある施設1つにしたのは、ADR-0075の決定7（研究部門の一部を崩すところまで）に合うからである。研究部門の記録を盗み出して流す筋は、エンディング「本当の体」で記録をもう流しているので、同じことの繰り返しになる。九条の研究室に入る筋は、[DOM-10](../20-domain/dom-10-characters.md)の「九条は、名前も姿も画面に出ない」と食い違う。

作戦を段階に分け、仲間を付けると要るレベルが下がるようにしたのは、第1章から第3章で入れた体調・怪我・仲間を1か所で使う遊びにするためである。稼ぎを止めてでも仲間を付けるか、自分のレベルを上げるかを選ぶことになる。値はすでにあるスキル・体調・仲間の稼ぎだけで足り、新しい値は越えた段階の数だけである。乱数を使わないのは、自動で遊ぶ検査の長さがぶれないようにするためである。段階に挑む前に手はずを払うことにしたのは、筋の順に合わせるためでもあり、払うボタンと挑むボタンが同時に出て、体の状態の欄が1280x720からはみ出すのを防ぐためでもある。

第4章の目標と長さは、自動で遊ぶ検査で決めた。検査では、第4章は97分（97日）で終わり、人の時間で約2.7時間にあたる。手はずを200万クレジットにした試しでは、払いを貯めるだけで約148分かかった。要るレベルを上げて長さを出した試しでは、レベル上げを待つ時間が延びた。そのため、手はずの払いと要るレベルの両方で長さを出した。

人の時間で、第一部が約1時間、第二部の4章が合わせて約6.8時間で、合わせて約7.8時間である。第4章をさらに延ばしても、中身が増えないまま時間だけが延びる（ADR-0075の却下した案と同じ）。そのため、第二部を第4章で終え、ADR-0075の決定10のとおり第三部を足す。第三部の中身は大きく、このPRに入れると見直しができない大きさになる。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 写しを目覚めさせず、ほかの被験体に腕前を読み込む型として使う | 不変条件は保てるが、章の題の「写し」と主題の「使い捨て」を描けない |
| 目覚めた写しを、説得して味方にできる人物にする | もう1人の主人公が第二部のあいだ残り、第三部の筋まで縛る |
| 写しを隠れ家に匿う | 同じ理由で、第三部の筋まで縛る |
| 主人公が写しを倒す | 主人公が自分の写しを手にかけることになり、重くなりすぎる |
| 研究部門の記録を盗み出して流す | エンディング「本当の体」と同じことの繰り返しになる |
| 九条の研究室に入る | DOM-10の「九条は、名前も姿も画面に出ない」と食い違う |
| 第一部の最後の仕事と同じように、就く仕事を1つ足し、その間にイベントを順に起こす | 第1章から第3章の仕組みを使わず、選ぶことが増えない |
| 新しい仕組みを足さず、章の目標を大きくするだけにする | ADR-0075の決定5（章ごとに新しい遊び方を1つ入れる）を満たせない |
| 段階がうまくいくかを、乱数で決める | 自動で遊ぶ検査の長さがぶれる |
| 第4章を延ばして、第二部だけで20時間に届かせる | 中身が増えないまま、時間だけが延びる |
| 第4章を終えたら、転生の画面に戻す | 仲間と隠れ家の稼ぎが続かず、第三部へ状態をつなげにくい |

## 影響

[DOM-34](../20-domain/dom-34-part-two-life.md)に、第二部の状態の越えた段階の数、作戦と段階の属性、章の目標の種類の作戦、章の出来事の条件の越えた段階の数、仲間を作戦に付けることを足す。[DOM-09](../20-domain/dom-09-consciousness-copy.md)の不変条件を、決定1の範囲に決め直す。

第二部の画面では、手はずを払い終えると、払うボタンの代わりに、いまの段階に挑むボタンが出る。仲間のボタンは、押すたびに任せる先が替わり、その並びに作戦が入る。`game/data/part_two.json`に、第4章と作戦の段階を置く。`game/ci/part_two.gd`は第4章まで遊び、体調が足りないまま段階に挑むとしくじることも確かめる。`game/ci/layout.gd`は、仲間を3人迎えて隠れ家を得た、第4章の画面が1280x720に収まるかを見る。

## 見直しの条件

自動で遊ぶ検査で、第4章が70〜110分の範囲を外れたら、手はずの値段と段階に要るレベルを見直す。検査では、第4章を終えたときにクレジットが150万余っている。実際に遊んだ人が、仲間を作戦に付けずに済ませるなら、要るレベルの下がり幅か、仲間の稼ぎが止まる重さを見直す。第三部を作るときに、第二部の状態をどこまで持ち込むかを決める。企業を倒す結末を足すときは、ADR-0070と合わせて決め直す。
