# ミオの一言を転生の画面に出し、人物を目覚めと断片の文に入れる

- 日付: 2026-10-18
- 状態: stable

## 背景

[ADR-0009](./adr-0009-world-rationale-and-characters.md)で、生き直しの理由づけ（[DOM-09](../20-domain/dom-09-consciousness-copy.md)）と4人の人物（[DOM-10](../20-domain/dom-10-characters.md)）を決めた。画面の文にはまだ企業と主人公しか出てこず、新しい体で目覚める理由も、記憶ポイントと永続強化の意味も、遊んでいる人には伝わっていなかった（issue #35）。

ゲームは周の流れを止めずに遊ぶものなので、台詞を足すと、周を重ねるたびに読む量が増える。転生の画面は、すでに1280×720の画面の高さいっぱいに使っていた。

## 決定

1. ミオの台詞は、転生の画面にだけ出す。1回に出すのは1文から2文の一言で、周の物語文のすぐ下に置く。エンディングにたどり着いた周には出さない。
2. ミオの一言は、倒れた理由と周の番号で選ぶ。倒れた理由は、体の限界かイベントかの2つに分ける。イベントで倒れたときは、そのイベントの名前を一言に入れる。周の番号は、第1周・第2周から第9周・第10周から後の3段に分ける。一言は2×3の6通りで、言語ファイルの`mio.<倒れた理由>.<段>`に置く。
3. 最初の周の目覚めのログで、ミオに「仕事ならジンが回してくれる」と言わせる。2周目からの目覚めのログは、裏通りの診療所で目覚めたことだけを書く。
4. ジンは、仕事を始めたときのログに出す（「仲介屋のジンから、運び屋の仕事を受けた」）。ジンの台詞は書かない。
5. 記憶の断片「白い部屋」では、技師の1人の「ごめんね」という声がミオの声だったと書く。主人公を逃がしたことまでは書かない。記憶の断片「名前」では、名前を呼ぶ昔の仲間がジンで、ジンは体が変わった主人公に気づいていないと書く。記憶の断片「計画書」には、反復計画という名前と、主人公だけがミオの診療所で目覚めていることを足す。
6. 転生の画面の要約で、記憶ポイントを「倒れる瞬間の同期で、意識の写しへ送り返された記憶」として書く。永続強化の見出しの横に「同期で残った記憶を使って、次の目覚めを調整する」と書く。永続強化ごとのボタンは、効果だけを書いたままにする。
7. 残るインプラント「信用スコア偽装」の説明を、体ではなくネット上の身元に組み込むから残る、と書き直す。
8. レイと九条は、この決定では画面に出さない。

## 理由

台詞を転生の画面に限ったのは、そこが周の切れ目で、遊ぶ人がもともと手を止めて読む画面だからである。周の途中に台詞を出すと、イベントと同じように流れを止める。

倒れた理由を2つに分けたのは、どの周も必ずどちらかで終わり、一言が出ない周が無いからである。イベントの名前を差し込むので、イベントごとに台詞を書かなくても、倒れ方の違いが一言に出る。周の番号で段を分けたのは、ミオが主人公を前の周から覚えている唯一の人物（DOM-10）であることを、周を重ねるほど親しくなる言い方で伝えるためである。

「白い部屋」でミオが主人公を逃がしたことまで書かないのは、この断片が5つの中で最初に戻るからである。声だけを明かし、迎えてくれていた人物への見え方を変えるところで止める。

永続強化ごとの理由づけをボタンに書かなかったのは、ボタンが横に長くなってパネルが広がり、「新しい体で目覚める」が画面の下にはみ出したからである。見出しの横の1行で、4つに共通する理由を伝える。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 周の途中にもミオやジンの台詞を出す | 周の流れを止める。人物ごとのイベントは別のissue（#38）で扱う |
| ミオの一言をイベントごとに書く | イベントを足すたびに台詞を書く必要がある。名前を差し込めば倒れ方の違いは伝わる |
| 永続強化ごとの理由づけをボタンの説明に足す | パネルが広がり、1280×720の画面で「新しい体で目覚める」が見えなくなった |
| 永続強化ごとの理由づけをツールチップにだけ出す | ブラウザ版では触らないと見えず、キーの種類も増える。共通の1行で足りる |
| 「白い部屋」で、ミオが主人公を逃がしたことまで書く | 最初に戻る断片で、ミオの役が明かされ切ってしまう |

## 影響

[DOM-10](../20-domain/dom-10-characters.md)に、ミオの一言と、人物が画面に出るところを書く。DOM-10の`implemented_by`に、一言を選ぶ`game/scripts/game_state.gd`を挙げる。

言語ファイルに`mio.*`の6つのキーと`log.awaken_first`・`ui.upgrades_note`を足し、要約・目覚め・仕事のログ・記憶の断片3つ・信用スコア偽装の文を書き直す。`game/ci/check_data.py`は、`mio.*`の6つがそろっているかを見る。転生の画面は、画面が低いときにパネルごと縦にスクロールできるようにする。

## 見直しの条件

ミオの一言が、周を重ねるうちに同じ文の繰り返しに感じられたら、段を増やすか、記憶の断片の数で選ぶかを見直す。人物ごとのイベント（#38）で台詞が周の途中にも出るようになったら、転生の画面の一言と重ならないかを見直す。
