# 橋を架けた技師たちの記録を、イベントと資料の追記で集める

- 日付: 2026-10-20
- 状態: stable

## 背景

市の時代に3本の橋を架けた技師オルセン・ヴィラール・ハーゲン（[DOM-17](../20-domain/dom-17-city-history.md)）は、資料「街の歴史」で読むだけで、話は進まなかった（issue #83）。運び屋のイベント「古い銘板」と、傭兵のイベント「変電所」は、橋とその周りを舞台にしているが、資料とはつながっていなかった。

issueでは、記録を集める手段と、本筋（中枢サーバー）との結び方の2つを決めることにしていた。作者からは、推奨の案で進めてよいと言われている。

## 決定

1. 資料「橋を架けた技師たち」を足す。資料はイベント「古い銘板」で選択肢を選ぶと出る。
2. 資料の追記は3つで、出る順に「市の図面」のイベント、「変電所」のイベント、断片「中枢サーバー」で出る。どれもいつ起きてもよく、順は決めない。
3. ハッカーのイベント「市の図面」を足す。市役所が無くなったときに捨てられた記録庫の写しに、ヴィラールの書き込みが残っている。選択肢は、そのまま売る・書き込みを読む（ハッキング Lv 3）・消してしまうの3つとする。
4. 人物のイベントでないイベントも、資料と追記の出るイベントにできるようにする。イベントに「選んだ選択肢を残す」の属性を足し、真なら、選んだ選択肢を話の進み具合に残す。古い銘板・変電所・市の図面の3つを真にする。
5. 本筋とは、断片「中枢サーバー」で出る追記で結ぶ。オルセンが橋の床下に引いた管路が、いまはヨミ・システムズの本社の地下へ電気を送っていて、中枢サーバーもその先にある。
6. 記録を集め終えても、記憶ポイントや永続強化は増えない。読み物として集める。

## 理由

集める手段をイベントにしたのは、仕事の合間に出会う形にでき、すでに橋を舞台にしたイベントが2つあるからである。新しい仕組みを足さず、資料の追記の出るイベントを人物のイベントの外へ広げるだけで済む。

選んだ選択肢を話の進み具合に残すのは、資料の出るイベントの判定（[ADR-0015](./adr-0015-profiles-revealed-by-fragments.md)）を変えずに使えるからである。別の値を持つと、セーブの形とやり直しの扱いを決め直すことになる。

中枢サーバーへの結びを断片の追記にしたのは、断片が戻るまで中枢サーバーのことを画面に出さない決まり（[ADR-0022](./adr-0022-city-map-in-game.md)）を守るためである。追記の順を決めないのは、イベントが仕事ごとに起きるので、就く仕事によって出会う順が変わるからである。

集め終えても報酬を付けないのは、資料は読むだけで、ゲームの状態を変えないという決まり（DOM-14）を守るためである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 記録を記憶の断片にする | 断片はエンディングまでの道のりを決めていて、数を増やすとADR-0006の釣り合いを決め直すことになる |
| 3人の技師の記録を、それぞれ別の資料にする | 1人ずつの資料は短く、読む画面の項目だけが増える |
| 記録を集め終えると、記憶ポイントを足す | 資料は読むだけで、ゲームの状態を変えないという決まりから外れる |
| イベントが起きたかどうかを、選んだ選択肢とは別に持つ | セーブの形と、やり直しの扱いを決め直すことになる |
| 中枢サーバーとの結びを、市の図面の追記に書く | 断片が戻る前に、中枢サーバーのことが画面に出る |

## 影響

DOM-14の出るイベントを、人物のイベントと選んだ選択肢を残すイベントの両方に広げ、イベントに「選んだ選択肢を残す」の属性を足す。資料の一覧に「橋を架けた技師たち」を足す。

`game/data/events.json`に市の図面を足し、古い銘板と変電所に`record`を付ける。`game/data/profiles.json`に資料を足す。`game_state.gd`は、`record`の付いたイベントの選択も話の進み具合に残す。セーブの形は変えない。

## 見直しの条件

選んだ選択肢を残すイベントが増え、話の進み具合を人物のイベントと分けて見たくなったら、別の値に分けるかを決め直す。
