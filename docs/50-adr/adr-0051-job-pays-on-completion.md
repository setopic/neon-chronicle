# 仕事を、終わったら報酬が入る形にする

- 日付: 2026-10-20
- 状態: stable

## 背景

これまでの仕事は、就いている間、毎秒クレジットと経験が少しずつ増えた（[DOM-03](../20-domain/dom-03-jobs-and-skills.md)）。見ているあいだに区切りが無く、放置しているのと変わらない。作者は、いま行っている仕事が終わったところで報酬が入る形にしたいと考えている（issue #117）。

## 決定

1. 仕事ごとに1回の長さを持つ。運び屋は5秒、ハッカーは10秒、傭兵は15秒、中枢サーバーへの侵入は20秒とする。1回が終わると、終わった時点の1秒あたりの稼ぎに長さを掛けたクレジットが入る。1秒あたりの稼ぎの式は変えない。
2. 1回が終わると、同じ仕事の次の1回が自動で始まる。
3. 途中で別の仕事に替えたときと、周が終わったときは、終わっていない1回の分は何も入らず、進み具合は0に戻る。
4. 経験も、1回が終わったときにクレジットと一緒にまとめて入る。レベルが上がるのもそのときである。劣化・イベント・仕事ごとの就いた時間は、これまでどおり刻みごとに進む。
5. 離れている間の進みは、[ADR-0007](./adr-0007-away-progress.md)の決定の4のとおり、開いているときと同じ0.25秒の刻みで進める。離れている間に終わった回の報酬は入り、途中の回は開いたあとに続く。そのため、進み具合をセーブに残す。進み具合を持たない古いセーブは、0から始める。
6. 画面では、仕事の列の、就いている仕事のボタンの下に進み具合のバーを出す。1回が終わったら、上の状態の行のクレジットの横に「+入った額」を短く出して消す。1回ごとのログは残さない。仕事のボタンと上の行の1秒あたりの稼ぎは、そのまま出す。

## 理由

区切りを作るのが目的なので、終わるたびにまとまった報酬が入り、それが画面で分かる形にした。1秒あたりの稼ぎの式を変えず、長さを掛けた額を払うので、通しで遊ぶ長さはほぼ変わらない。

仕事ごとに長さを変えたのは、稼ぎの多い仕事ほど1回が長く、手応えが大きくなるようにするためである。

途中の回を捨てるのは、仕事を替えることに小さな代価を持たせ、1回を終えるまで待つ理由を作るためである。

経験もまとめて入れるのは、クレジットと経験の入り方をそろえ、レベルが上がる区切りも仕事の区切りに合わせるためである。劣化とイベントは周の時間の流れなので、仕事の区切りとは別に進める。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| すべての仕事で1回の長さを同じにする | 稼ぎの多い仕事でも手応えが変わらない |
| 1回が終わったら止まり、もう一度選ばせる | 目を離すと稼ぎが止まり、離れている間の進みとも合わない |
| 仕事ごとの進み具合を残し、戻ったときに続きから再開する | 仕事を替える代価が無くなり、持つ状態が仕事の数だけ増える |
| 経験はこれまでどおり刻みごとに入れる | クレジットと経験で入り方が分かれ、区切りがぼやける |
| 1回が終わるたびにログに1行残す | 運び屋では5秒ごとに1行増え、ほかのログが流れてしまう |

## 影響

DOM-03の属性に1回の長さを足し、周ごとの状態に進み具合を足す。稼ぎと経験の入り方の文を、1回が終わったときにまとめて入る形に直す。

`game/data/jobs.json`の各仕事に長さを足す。`game_state.gd`は、進み具合を刻みごとに進め、1回が終わったときにクレジットと経験を入れる。仕事を替えたときと周を始めたときに、進み具合を0に戻す。進み具合はセーブに書く。`main.gd`は、就いている仕事のボタンの下のバーと、クレジットの横の「+入った額」を出す。`ci/away.gd`で、離れている間に終わった回の報酬が入り、途中の回が残ることを確かめる。ADR-0007は書き換えない。

## 見直しの条件

5秒の運び屋でも区切りが待ち遠しく感じられるなら、長さを見直す。仕事を替えるたびに途中の回を失うのが不満として多く挙がったら、決定の3を見直す。
