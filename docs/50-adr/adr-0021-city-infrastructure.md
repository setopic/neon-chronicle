# 電気はヨミ・システムズ、水はリンドホルム食品が握り、街に公共の交通は置かない

- 日付: 2026-10-19
- 状態: stable

## 背景

街のインフラは、ほとんど決めていなかった。決まっていたのは、ヨミ・システムズが街のネットの基幹を売っていることと、北の橋のたもとにヨミ・システムズの変電所があること、モンフォール警備が橋を見張っていることだけだった（issue #54）。イベント「変電所の奪い合い」では、変電所の送電を止めると下層街も暗くなると書いていたが、誰が発電しているかは書いていなかった。

issueでは、電気・水・交通を誰が作り誰が握るか、企業を新しく足すか、画面のどこに出すかの3つを決めることにしていた。停電や運賃のような新しい仕組みは足さないことも、issueの時点で決めていた。

## 決定

1. 電気は、ヨミ・システムズが握る。自社の縄張りにある発電所で発電し、送電網で企業区画の各社の縄張りと下層街へ送る。下層街へは、北の橋のたもとの変電所を通して送る。下層街の住人の多くは、送電網から勝手に線を引いて電気を使う（盗電）。
2. 水は、リンドホルム食品が握る。自社の縄張りにある浄水場で水を浄め、培養槽に使うほか、企業区画へ水道で送る。下層街に水道は無い。住人は雨水をためて濾すか、屋台で浄水を買う。
3. 街に公共の交通は置かない。企業区画では、各社が自社の車で社員を運ぶ。下層街の住人は歩くかバイクで移動し、荷物は運び屋が運ぶ。
4. インフラのために企業を新しく足さない。
5. 画面には、「街と人物」の資料と、新しいイベントで出す。資料「企業」「企業区画」「下層街」にインフラの文を足す。ハッカーのイベント「盗電の線」を足す。イベントの仕組みは変えない。

## 理由

電気をヨミ・システムズに持たせたのは、街のネットの基幹を売る会社として筋が通り、イベント「変電所の奪い合い」の変電所がヨミ・システムズのものである理由にもなるからである。ヴァルデック義体が送電を止めさせるのも、競う相手の握るものを止めたいからだと読める。

水をリンドホルム食品に持たせたのは、合成食の培養槽に大量の水が要るからである。

公共の交通を置かないのは、[ADR-0018](./adr-0018-companies-places-and-residents.md)の、各社が私兵も兵器も自前で持つという決まりと揃うからである。下層街で運び屋が仕事になる理由にもなる。

企業を足さなかったのは、[ADR-0019](./adr-0019-food-clothing-housing.md)で衣服と住居に企業を足さなかったのと同じく、社名と縄張りを新しく決めると設定が増えるからである。

新しいイベントをハッカーの仕事にしたのは、盗電の線を送電網の監視から隠すのはハッカーの仕事だからである。下層街の住人と、電気を握るヨミ・システムズとの間で選ばせることで、仕事中にインフラの設定が目に入る。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 各社が自社の縄張りで発電する | 「変電所の奪い合い」で、ヨミ・システムズの変電所を止めるとほかの区画まで暗くなる理由が無くなる |
| 水の企業をヨーロッパ系の社名で足す | 社名と縄張りを新しく決めることになり、設定が増える |
| モンフォール警備が、橋を渡るモノレールを走らせる | モンフォール警備は橋と下層街の治安を請け負う会社で、運ぶ仕事は役割が違う。下層街で運び屋が仕事になる理由も弱まる |
| 資料だけで出す | 仕事中には目に入らない |
| 停電や運賃の仕組みを足す | 新しい数値と画面が要り、遊び通しての確認が増える |

## 影響

[DOM-15](../20-domain/dom-15-city-places-and-powers.md)に、インフラの表と、用語「送電網」「盗電」「浄水場」を足す。区画の表と図に、ヨミ・システムズの発電所とリンドホルム食品の浄水場を足す。[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)の資料の一覧は変わらない。

`game/data/events.json`にイベント「盗電の線」を足す。言語ファイルでは、新しいイベントのキーを足し、資料「企業」「企業区画」「下層街」の説明に文を足す。

## 見直しの条件

電気や水を、数値として扱いたくなったら見直す。
