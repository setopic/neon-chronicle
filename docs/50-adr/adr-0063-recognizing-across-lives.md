# 周をまたいで主人公を見分ける決まりを1つにする

- 日付: 2026-10-20
- 状態: stable

## 背景

設計文書の点検で、周をまたいで主人公を見分けられる人の決まりがそろっていないと分かった（issue #150）。

[DOM-10](../20-domain/dom-10-characters.md)は、ミオを主人公を前の周から覚えている唯一の人物としながら、不変条件では、覚えているのはミオとレイだとしていた。ジンは体が変わった主人公に気づかないのに、跡のイベントでは街の人々が歩き方や作業用の名前で主人公だと気づき（[ADR-0044](./adr-0044-traces-of-last-life.md)）、勢力も評判として主人公を覚え続けていた（[DOM-22](../20-domain/dom-22-faction-reputation.md)）。体が替わることを人間関係として感じさせるジンの役（[ADR-0009](./adr-0009-world-rationale-and-characters.md)）が弱まっていた。

ジンの居場所も揺れていた。[ADR-0020](./adr-0020-city-districts-and-map.md)はジンには居場所を置かず、通信で話すだけとし、[ADR-0022](./adr-0022-city-map-in-game.md)と[ADR-0023](./adr-0023-bridge-names-and-terrain-map.md)が引き継いでいた。一方で、ジンの人物のイベントの2段目と3段目では、会って話している（[DOM-13](../20-domain/dom-13-character-events.md)）。

DOM-10はレイをイベント「同業者の挑戦」の相手としていたが、レイが画面に出るのはレイの人物のイベントだけで、画面の「同業者の挑戦」の相手は見知らぬハッカーである。

[ADR-0025](./adr-0025-city-history-before-corporations.md)の決定は、この食い違いに関わらない。

## 決定

ADR-0023の決定は、ジンに居場所を置かないことのうち、通信で話すだけとした部分を改める。ほかはそのまま引き継ぐ。

1. 区画と、高台と低い土地を3本の橋でつなぐこと、橋・闇市場の入口・裏通りの診療所・変電所・中枢サーバーの位置（そのまま）
2. 地図を「街と人物」の画面に置き、資料とタブで切り替える（そのまま）
3. 区画と橋は最初から見せ、中枢サーバーは記憶の断片「中枢サーバー」が戻るまで描かない（そのまま）
4. 名前と添える文を言語ファイルに書き、画像を用意しない（そのまま）
5. 3本の橋の人名、高台の縁の崖と排水路、企業の力関係、地図の描き方（そのまま）
6. ジンには決まった居場所を置かず、通信で話すだけにする（改める。下記の4）

ADR-0044の7つのうち、6つはそのまま引き継ぐ。

1. 周ごとに選んだ選択肢を残し、1つ前の周の選択として持つ（そのまま）
2. 効くのは1つ前の周だけにする（そのまま）
3. 出し方は、新しい跡のイベントにする（そのまま）
4. 跡のイベントを4つ置く（そのまま）
5. 街の人々が、顔は違っても歩き方や作業用の名前で主人公だと気づく（改める。下記の2）
6. 前の版のセーブからは、読み込んだ周が終わったあとの周から跡のイベントが起きうる（そのまま）
7. 前の周の跡は、DOM-27に書く（そのまま）

この決定で、次のことを決める。

1. 見分けの決まりを[DOM-09](../20-domain/dom-09-consciousness-copy.md)に1つだけ書く。主人公の顔と体は周ごとに替わるので、顔を見て主人公だと分かる者はいない。前の周に主人公と関わった者が、話し方や仕事の手口から、同じ人ではないかと疑うことはある。前の周の主人公を確かに覚えている者はDOM-10が決め、ミオとレイの2人である。
2. 跡のイベントでは、街の人々が、話し方や仕事の手口から前の周の者ではないかと疑う。歩き方は手がかりにしない。体の癖は元の持ち主の神経の型から来るので（[ADR-0061](./adr-0061-nerve-pattern-of-former-owners.md)）、歩き方は体ごとに変わるからである。
3. ジンが気づかないのは、ミオが毎周、主人公を新しい運び屋として紹介するので、診療所が別の人を回してきたと思っているからとする。勢力の評判は、勢力が裏通りの診療所から来る者をどう見ているかとし、診療所から来る者が替わっても続く。
4. ジンには決まった居場所を置かない。ふだんは通信で話すが、ジンの人物のイベントでは会うこともある。
5. DOM-10のミオを「主人公を前の周から覚えている、被験体でないただ1人の人物」と直す。レイの役から「同業者の挑戦」を外す。

## 理由

ジンの扱いと評判を、ミオの診療所という1つの筋で説明したのは、ジンが気づかないことと、勢力が評判を覚え続けることを、同じ理由で両立させられるからである。街の人々の手がかりを「疑う」までにしたのは、確かに覚えているのがミオとレイだけという決まりと食い違わないようにするためである。

ジンの決まりを改め、DOM-13の場面を変えなかったのは、画面の文を書き直さずに済むからである。

レイの役から「同業者の挑戦」を外したのは、画面の相手がもともと見知らぬハッカーで、レイが画面に出るのはレイの人物のイベントだけという決まりとも合うからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ジンは通信でしか会わないので癖が見えず、作業用の名前は毎周変える | 跡のイベントで作業用の名前から気づかれることと食い違う |
| 評判の説明だけを直す | ジンが気づかず街の人々が気づく食い違いが残る |
| 跡のイベントの手がかりを歩き方のまま残す | 体の癖は元の持ち主から来るので、体ごとに変わる |
| DOM-13のジンの2段目と3段目を、通信の場面に書き直す | 画面の文を書き直すことになる |
| 「同業者の挑戦」の相手がレイだったと分かる文を足す | レイが画面に出るのはレイの人物のイベントだけという決まりと合わない |

## 影響

DOM-09に見分けの決まりを足す。DOM-10のミオ・ジン・レイの行を直す。DOM-22に評判が付く相手の説明を、DOM-27に跡のイベントの手がかりを足す。DOM-15とDOM-16は変えない。数値は変えない。

画面の文のうち、ザンダー・ファミリーの男が歩き方が似ていると言う場面（`event.thief_hunt.desc`）と、ジンが通信で「見ない顔だな」と言う場面は、#136で確かめる。

## 見直しの条件

ジンや勢力が主人公の正体に気づく話を足すときに、見分けの決まりを見直す。
