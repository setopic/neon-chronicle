# 第二部の第2章で、昔の仲間を迎えて仕事を任せる

- 日付: 2026-10-20
- 状態: stable

## 背景

[ADR-0075](./adr-0075-part-two-after-reclaim.md)は、第二部を4つの章に分け、第2章の題を「名前」、新しい遊び方を仲間（仕事を任せられる人）とした。第2章から先は、1章ずつissueに分けて作る（issue #182）。第1章の最後の出来事で、ジンが「お前の名前を取り戻す手がある」と言い、昔の仲間の名前をいくつか挙げる。

第2章を作るには、仲間に何を任せられるか、消された名前と身元をどう取り戻すか、第2章の長さと章の目標を決める必要があった。

## 決定

1. 仲間は、主人公が意識を抜き取られる前に組んでいた昔の一味の3人とする。運び屋のサキ、用心棒のゴウ、主人公が手ほどきをした若いハッカーのトワである。3人とも下層街の人物なので、カタカナで書く。
2. 仲間は、章の出来事の選択肢で迎える。迎えた仲間は、第二部のあいだ残る。
3. 仲間1人に、仕事を1つ任せる。迎えたときは得意な仕事を任せていて、仲間のスキルのレベルが就く条件を満たす仕事に替えられる。何も任せないこともできる。仲間は自分の身元を持っているので、偽の身元が要る仕事にも就ける。
4. 仲間は疲れず、休まない。任せた仕事は、仲間のスキルのレベルで、主人公が休んでいる間も稼ぐ。稼ぎの4割を分け前として仲間が取り、残りが主人公に入る。主人公のスキルの経験は増えず、主人公のインプラントやスキルの節目は仲間の稼ぎに効かない。仲間のスキルのレベルは上がらない。
5. 名前と身元は、3人の仲間と一緒に、ヨミ・システムズの記録庫から消された身元の記録を抜き出して取り戻す。名前そのものは、第一部の記憶の断片「名前」と同じく画面に出さない。取り戻したあとの遊び方の効き目は付けず、話の区切りとして次の章を開く。
6. 第2章の章の目標は、交渉をLv18にする（サキの居場所を聞き出す）、ゴウの借金20000クレジットを肩代わりする、ハッキングをLv22にする、記録庫に入る手はずを250000クレジットで買う、の4つとする。章の出来事は、ジンが3人の名前を挙げる出来事、サキ・ゴウ・トワを1人ずつ迎える出来事、記録庫で記録を抜き出す出来事の5つで、この順に起きる。
7. 第2章の長さは、人が遊んで約90分とする。`game/ci/part_two.gd`は、第1章に続けて第2章を終えるまで遊び、第2章にかかったゲーム内の時間が40分より短いか70分より長いときに失敗とする。人の時間への換算は、ADR-0075の決定9と同じ比を使う。

ADR-0075は置き換えない。第二部の章の組み立て、第1章の長さ、20時間に届くかを章ごとに確かめることは、そのまま生きている。

## 理由

仲間を疲れさせず、休みを要らないことにしたのは、主人公の体調の配分に、仲間の体調の配分を重ねないためである。第二部の遊びの中心は、主人公の1つの体を保つことにある。仲間の稼ぎは時間がたつだけ入るので、主人公が休んでいる間も暮らしが進む。

分け前を取ることにしたのは、仲間が主人公より稼ぎすぎないようにするためである。仲間のスキルのレベルを上げないことにしたのは、主人公のスキルを伸ばす意味を残すためである。

名前を画面に出さないのは、第一部でも名前を出さずに、ジンが呼ぶ名前として扱ってきたからである。遊ぶ人が自分の主人公を思い描く余地を残す。取り戻したあとの効き目を付けないのは、第二部の偽の身元が一度買えば失われないので、本当の身元に置き換えても遊び方が変わらないからである。

第2章の目標と長さは、自動で遊ぶ検査で決めた。検査では、第2章は50分（51日）で終わり、人の時間で約83分にあたる。サキを迎えるのは約20分後で、そのあとの約30分は、仲間の稼ぎが記録庫の手はずの支払いを支える。スキルの目標をさらに上げると、仲間を迎えたあとも主人公のレベル上げを待つだけの時間が延びる。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 仲間にも体調を持たせ、休ませる | 主人公の体調の配分と同じ遊びを、人数分くり返すことになる |
| 仲間の稼ぎを分け前なしで全額入れる | 傭兵を任せたゴウだけで、主人公の稼ぎに並ぶ |
| 取り戻した本当の身元で、偽の身元を買わずに橋の向こうの仕事に就けるようにする | 第二部の偽の身元は一度買えば失われないので、効き目にならない |
| 主人公の名前を決めて画面に出す | 第一部で名前を出してこなかった扱いと食い違う |
| 仲間を別のドメインノードに書く | 仲間は第二部の状態の一部で、章の出来事で迎える。章と分けて書くと、第二部の暮らしを変えるたびに2つの文書を合わせて直すことになる |
| 第2章を、スキルの目標を上げて3時間にする | 中身が増えないまま、レベル上げを待つ時間だけが延びる |

## 影響

[DOM-34](../20-domain/dom-34-part-two-life.md)に、第二部の状態の仲間、仲間の属性、昔の一味の3人、仲間の稼ぎの式、迎える仲間の選択肢の属性を足す。[DOM-10](../20-domain/dom-10-characters.md)の登場人物の定義を、反復計画に関わる4人に絞る。昔の一味の3人はDOM-34に書く。DOM-10に書くと、DOM-10が第二部を前提にすることになり、DOM-34との参照が循環する。

第二部の画面では、体の状態の欄に、迎えた仲間ごとに任せる仕事を替えるボタンが1行に並ぶ。`game/data/part_two.json`に、第2章と仲間を置く。`game/ci/part_two.gd`は第2章まで遊び、`game/ci/layout.gd`は仲間を3人迎えた第2章の画面が1280x720に収まるかを見る。

## 見直しの条件

自動で遊ぶ検査で、第2章が40〜70分の範囲を外れたら、章の目標の値を見直す。実際に遊んだ人が、仲間に任せる仕事を替えないままで終わるなら、仕事ごとの稼ぎの差か分け前を見直す。第3章で拠点を足すときに、仲間を拠点の仕事にも任せるかを決める。
