# 下層街に、ギャングのザンダー一家と住人の屋台組合を置く

- 日付: 2026-10-19
- 状態: deprecated（[ADR-0029](./adr-0029-zander-family-name.md)が置き換えた）

## 背景

下層街にいる企業に属さない勢力は、「下層街の住人」と「路地のチンピラ」の2つだけだった（[DOM-15](../20-domain/dom-15-city-places-and-powers.md)）。路地のチンピラは小さな集まりで、イベント「路地の通行料」の「話をつける」では、顔の利く名前を出すと道を空ける。その名前が誰のものかは決めていなかった。

企業が強く、モンフォール警備が治安を請け負う街なら、下層街にも大きなギャングや、住人がまとまる自治組織があるほうが自然ではないか、という問いが出た（issue #63）。issueでは、ギャングと自治組織を置くか、置くなら何をしていて互いや企業とどう関わるか、路地のチンピラをどう扱うか、画面のどこに出すかを決めることにしていた。

## 決定

1. 下層街に、ギャングを1つ置く。名前はザンダー一家（英語ではZander Family）で、頭の家の名前で呼ばれる。裏通りと闇市場を仕切り、闇市場で売り買いする者から場所代を、屋台通りの店からみかじめを取って稼ぐ。どの企業にも属さない。
2. 企業は、下層街で表に出せない仕事を、闇市場を通してザンダー一家に回す。モンフォール警備は、ザンダー一家から金を受け取って、裏通りでの一家の商売を見逃している。
3. 住人の自治組織として、屋台組合を置く。屋台通りと下層街の奥の屋台や修理屋がまとまったもので、雨水のタンクと浄水の分け方、盗電の線の引き方、住人どうしのもめごとの仲裁をまとめている。みかじめは、店ごとではなく屋台組合がまとめて払い、額をザンダー一家と話し合って決める。
4. 路地のチンピラは、ザンダー一家とは別の小さな集まりのままにする。「路地の通行料」で顔の利く名前として出すのは、ザンダー一家の名前とする。
5. 下層街の住人は、路地のチンピラの群れを、ダニやハイエナと蔑む（英語ではticks and hyenas）。どちらも決まった名前ではなく、群れを見下すときの言い方である。本人たちに共通の自称は無く、群れごとに、たむろする路地の角の名前などを勝手に名乗っている。群れごとの名前は決めず、画面にも出さない。用語は「路地のチンピラ」のままにする。
6. 画面には、「街と人物」の資料と、新しいイベントで出す。資料に「ザンダー一家」と「屋台組合」を足し、資料「下層街」と「闇市場」に文を足す。運び屋のイベント「みかじめの運び」を足す。地図は変えない。イベントと資料の仕組みは変えない。

## 理由

ギャングを1つにしたのは、下層街の大きな勢力が増えすぎると、企業の4社と並べたときに読む設定が多くなるからである。複数のギャングが争う形は、争いの相手を決める分だけ設定が増える。

人の名前で呼ばれる一家にしたのは、3本の橋と同じく、名前だけで通じる顔として扱えるからである。「路地の通行料」の顔の利く名前にも、そのまま当てられる。

裏通りと闇市場を仕切らせたのは、闇市場の入口が裏通りの1つだけで（[ADR-0020](./adr-0020-city-districts-and-map.md)）、入口を押さえれば場所代を取れるからである。企業の買い手が身元を隠して闇市場に出入りしているので、企業が一家に仕事を回す道としても筋が通る。

自治組織を屋台組合にしたのは、下層街の住人がすでに屋台や修理屋を営んでいて、水も電気も自分たちで手当てしているからである（[ADR-0021](./adr-0021-city-infrastructure.md)）。まとめる役が要るのは、その分け方ともめごとである。屋台組合がみかじめをまとめて払うことで、ギャングと住人の関係が、奪うだけのものではなくなる。

路地のチンピラを一家の下っ端にしなかったのは、「路地の通行料」で一家の名前を出すと道を空けるという振る舞いが、別の集まりのほうが自然だからである。下っ端なら、自分の頭の名前を出されて道を空けることになる。

蔑みの言い方を決めたのは、作者が、まとまりの無い集団でも呼び方があったほうがよいと考えたからである。どちらも、通る者にたかって金を取る振る舞いから取った。日本語には、たかって生きるチンピラを「街のダニ」と呼ぶ言い方がもとからあるので、説明しなくても蔑んでいると伝わる。ハイエナは、群れでうろつき、弱い者を狙う連中という響きを足す。1つの呼び名に決めて用語にしなかったのは、作者が、住人が口にする蔑みとして2つを並べる文を選んだからである。

共通の自称を置かなかったのは、1つの組織ではないことを保つためである。作者が、群れごとに名乗る形を選んだ。

イベントを運び屋の仕事にしたのは、屋台通りから裏通りへ金を運ぶのが運び屋の仕事だからである。選択肢で、ザンダー一家と屋台組合の間で選ばせることで、仕事中に2つの勢力が目に入る。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ギャングを置かず、路地のチンピラだけにする | 企業が強い街で、下層街に大きな勢力が無いのは不自然だという問いに答えられない |
| ギャングを2つ置き、下層街の区画を分け合わせる | 争いの相手と境を決める分だけ、設定が増える |
| ギャングを通り名（「ドブネズミ」のような）で呼ぶ | 橋と同じく人の名前にしたほうが、顔の利く名前として扱える |
| 自治組織を置かず、住人はまとまらないままにする | 水と電気を自分たちで手当てしている住人に、分け方を決める役が無くなる |
| チンピラの群れを、野良犬・路地ネズミのような、振る舞いに結び付かない呼び名にする | 作者が、振る舞いから付けた名前を選んだ |
| 振る舞いから取ったほかの呼び名（辻取り・関守・通せんぼ・たかり屋） | 作者が、たかる動物に例える言い方を選んだ |
| ヒルを使った呼び名（ヒル・ヒル野郎・ドブヒル・路地ヒル・ロジヒル、英語ではLeeches） | 作者が、意味は合うが、もっと伝わりやすい言い方にしたいと考え、ダニとハイエナを選んだ |
| 蔑みの呼び名を1つ決め、用語として「路地のチンピラ」を改名する | 作者が、住人の蔑みとしてダニとハイエナを並べる形を選んだ。決まった名前にすると、1つの組織に読める |
| 共通の自称（路地番）を置き、通行料を見張り賃だと言い張らせる | 作者が、群れごとに名乗る形を選んだ。共通の自称があると、1つの組織に読める |
| 路地のチンピラをザンダー一家の下っ端にする | 一家の名前を出されて道を空ける振る舞いと合わない |
| 地図にザンダー一家の仕切る範囲を描く | 範囲は裏通りと闇市場の区画と同じで、描き足しても情報が増えない |

## 影響

[DOM-15](../20-domain/dom-15-city-places-and-powers.md)の勢力の表にザンダー一家と屋台組合を足し、路地のチンピラの行に、顔の利く名前と住人の蔑みを書く。用語「ザンダー一家」「屋台組合」「みかじめ」「場所代」「路地のチンピラ」を足す。[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)の資料の一覧に「ザンダー一家」と「屋台組合」を足す。

`game/data/events.json`にイベント「みかじめの運び」を、`game/data/profiles.json`に資料`zander`と`union`を足す。言語ファイルでは、新しいイベントと資料のキーを足し、資料「下層街」と「闇市場」の説明に文を足す。「路地の通行料」の説明と資料「下層街」の文に、住人がダニやハイエナと蔑むことを書く。英語ではチンピラをgangと書いていたので、ザンダー一家と紛れないようthugsに改める。

## 見直しの条件

ザンダー一家や屋台組合の人物を、名前のある登場人物として出すときは、[DOM-10](../20-domain/dom-10-characters.md)に置くかを見直す。下層街に区画が増えたときは、一家の仕切る範囲を見直す。
