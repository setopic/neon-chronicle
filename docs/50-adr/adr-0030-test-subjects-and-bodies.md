# 被験体は借金の契約で集め、使い捨ての体は闇市場の部品で組み立てる

- 日付: 2026-10-19
- 状態: stable

## 背景

[反復計画](../20-domain/dom-09-consciousness-copy.md)が誰の意識を使っているかが、決まっていなかった（issue #69）。画面に出ているのは、主人公が借金を消す代わりに体を差し出す契約書に署名したこと（記憶の断片「契約書」）、ヨミ・システムズがハッカーの腕を目当てに意識を抜き取ったこと（断片「名前」）、レイが前の周を覚えている被験体であること、企業の金庫に被験体の名簿があることだけだった。

[ADR-0028](./adr-0028-life-course-and-body-parts.md)は、主人公が毎周目覚める体の出どころも、このissueに回していた。

## 決定

1. 被験体は、下層街で腕を持ち、借金を返せなくなった者から集める。ヨミ・システムズの研究部門が、汚れ仕事に使える腕を持つ者を選び、身元を隠して闇市場でその借金をザンダー・ファミリーから買い取る。ファミリーが、借金を消す代わりに体を差し出す契約書に本人を署名させる。
2. 社の身元を持つ者は、被験体にしない。
3. 主人公とレイは、どちらも借金を返せなくなった下層街のハッカーで、この契約書に署名して被験体になった。
4. 意識を抜き取った被験体の体は、意識の写しが壊れたときに抜き取り直すため、中枢サーバーの奥で眠ったまま保存する。主人公の本当の体も、その1つである。
5. ふつうの被験体は、ヨミ・システムズの施設で目覚めるたびに、前の周の記憶を封じられる。レイは自分の封じを内側から外したので、前の周を覚えている。主人公は、ミオが書き換えた読み込み先で目覚めるので、記憶を封じられない。
6. 使い捨ての体は、闇市場で買った体の部品を組み立てて作る。ふつうの被験体の体はヨミ・システムズの研究部門が施設で、主人公の体はミオが裏通りの診療所で組み立てる。体の種類は、組み立てに使う部品で分かれる。
7. 画面には、資料「ネオン・シティ」と「レイ」の追記、資料「ミオ」の説明、レイの人物のイベント2段目の文で出す。イベントと資料の仕組みは変えない。記憶の断片の文は変えない。

## 理由

借金の契約で集めるとしたのは、作者がこの案を選んだからである（issue #69のスレッドの選択）。主人公の契約書と同じ道なので、主人公が特別な経緯で被験体になったのではなく、多くの被験体の1人だと伝わる。借金で人を縛るのは、遺体の取り立て（[ADR-0028](./adr-0028-life-course-and-body-parts.md)）と同じファミリーのやり方である。企業が表に出せない仕事を闇市場を通してファミリーに回すこと（[ADR-0024](./adr-0024-lower-city-gang-and-union.md)）とも合う。

社の身元を持つ者を外したのは、社員や私兵がいなくなれば属する企業が探し、ヨミ・システムズの計画が他社に知られるからである。

本当の体を保存する理由を写しの抜き取り直しにしたのは、断片「中枢サーバー」の、本当の体が眠ったまま保存されているという文に、ヨミ・システムズの側の理由を与えるためである。

記憶を封じるとしたのは、前の周を覚えている被験体が主人公とレイだけであること（[DOM-10](../20-domain/dom-10-characters.md)）に理由を与えるためである。封じがあれば、ふつうの被験体が命令に従う理由にもなる。レイが名簿でほかの被験体を探すことと、エンディング「ネットの亡霊」で使い捨ての体の意識を解き放つことも、封じられた者を助ける話として読める。

使い捨ての体をミオが組み立てるとしたのは、作者がこの案を選んだからである（issue #69のスレッドの選択）。闇市場の体の部品の出どころ（[ADR-0028](./adr-0028-life-course-and-body-parts.md)）と1つにつながり、部品の寄せ集めなので早く劣化する理由になる。闇医者が部品を買うのはふつうのことなので、ヨミ・システムズが主人公の体に気づかない理由にもなる。

記憶の断片の文を変えなかったのは、いまの文がこの決定と食い違わないからである。画面に出すのは、すでにある追記の仕組みと、人物のイベントの文で足りる。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 橋で捕まった身元の無い者を、モンフォール警備が引き渡す | 主人公の契約書とは別の道が増え、契約書を書かせる理由が薄くなる |
| 契約と引き渡しの両方で集める | 道が2つになり、名簿に並ぶ人の見え方がまとまらない |
| 社員も被験体にする | 社員がいなくなれば属する企業が探し、計画が他社に知られる |
| 使い捨ての体を、ミオがヨミ・システムズの施設から1つずつ回させる | 体が施設から下層街へ届くたびに、ヨミ・システムズに気づかれない理由が別に要る |
| ヴァルデック義体に体を作らせる | ヴァルデック義体はヨミ・システムズと客を奪い合っていて、計画を知られる |
| ふつうの被験体も前の周を覚えている | 主人公とレイだけが前の周を覚えているという人物の決まりに、理由が付かない |

## 影響

[DOM-20](../20-domain/dom-20-test-subjects-origin.md)を新しく置き、被験体の集め方、本当の体、記憶の封じ、使い捨ての体を書く。[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)の資料の一覧で、「ネオン・シティ」と「レイ」の追記を足し、依存先にDOM-20を足す。

`game/data/profiles.json`に、資料「ネオン・シティ」の追記`subjects`（断片「計画書」で出る）と、資料「レイ」の追記`origin`（レイの2段目で出る）を足す。言語ファイルに、その2つのキーを足す。資料「ミオ」の説明に、ミオが毎周の体を闇市場の部品から組み立てていることを足す。レイの2段目の説明の文3つと、「名簿を一緒に抜き取る」の結果の文に、被験体の出どころを足す。

## 見直しの条件

ほかの被験体を人物として画面に出すときは、記憶の封じとその外し方を見直す。ヨミ・システムズの施設や体を組み立てる場面を画面に出すときは、体の組み立て方を見直す。
