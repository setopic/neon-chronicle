# 記憶ポイントの見込みと伸びを見せ、閉じていた間の成果をログに出す

- 日付: 2026-10-20
- 状態: stable

## 背景

Anthony Pecorellaは、転生で得る通貨を何から計算するかで、遊び手がいつ転生するのが得かが決まると述べている。また、少し開いただけで大きく伸びているようにすると、戻る動機が強くなると述べている（issue #141）。

本作では、画面の上の段に持っている記憶ポイントを、転生の画面にその周で得た記憶ポイントを出していた。周の途中で、いまの周がどれだけの記憶ポイントになりそうかは見えなかった。前の周より伸びたかも見えなかった。閉じていた時間を進めたときは、ログに進んだ時間の1行だけを残していた（[ADR-0007](./adr-0007-away-progress.md)の決定6）。

本作では、遊ぶ人が自分で周を終えることはできない。周は耐久が0になるか、エンディングにたどり着いたときに終わる。そのため、見込みは「いつ転生するか」を決める材料ではなく、周の中での伸びの手応えとして見せる。

## 決定

1. 周の途中は、画面の上の段の記憶ポイントの横に、記憶ポイントの見込みを「（この周 +5）」の形で出す。記憶ポイントの見込みは、いま周が終わったら得る記憶ポイントである。果たした依頼の上乗せと、まだ破っていない縛りの上乗せを含む。
2. 転生の画面では、その周で得た記憶ポイントの行の後ろに、前の周の記録の記憶ポイントとの差を出す。多ければ「前の周より +3」、少なければ「前の周より -2」、同じなら「前の周と同じ」とする。第1周のあとは、前の周が無いので出さない。
3. 閉じていた時間を進めたときにログに残す1行に、閉じていた間に稼いだクレジットと、記憶ポイントの見込みの伸びを足す。ログに残すのは、これまでどおり60秒以上進めたときだけである。閉じている間に周が終わったときは、ADR-0007の決定5のとおり転生の画面で待つ。

ADR-0007は置き換えない。ログに1行残すという決定6はそのまま生きており、このADRはその1行に中身を足すだけである。

## 理由

見込みを上の段に出すと、仕事やスキルのレベルが上がるたびに、周の成果が増えていくのが見える。上乗せを含めるのは、周が終わったときに転生の画面に出る値と、直前に上の段で見た値をそろえるためである。縛りは周の途中で破れることがあるが、そのときは見込みが下がるので、破った結果も見える。

比べる相手を前の周にしたのは、永続強化を買った効果が、すぐ次の周の差に出るからである。

閉じていた間の成果は、ログの1行を伸ばすだけにした。新しい窓を作ると、1280x720に収めるための調整と、閉じる操作が増える（[ADR-0049](./adr-0049-fit-screens-1280x720.md)）。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 見込みに上乗せを含めず、経験とスキルのレベルの分だけ出す | 周が終わったときに出る値と食い違い、依頼を果たした手応えも見えない |
| 見込みを見せない | 周の中で伸びている手応えが無い |
| 比べる相手を、これまでで最も多かった周にする | 永続強化を買った直後の伸びが見えにくい。最も多かった周を超えないあいだは、毎回減ったように見える |
| 開いたときに、閉じていた間の成果を小さな窓で出す | 画面の高さの調整と、閉じる操作が増える |
| 閉じていた間の成果を出さない | 開いたときに、何が進んだかが分からない |

## 影響

[DOM-05](../20-domain/dom-05-rebirth.md)に、導出値として記憶ポイントの見込みを足し、用語表に載せる。画面の上の段・転生の画面・閉じていた時間のログの1行が変わる。`game/ci/away.gd`は、閉じていた時間のログの1行に、稼いだクレジットが出ることも確かめる。

## 見直しの条件

遊ぶ人が自分で周を終えられるようにしたら、見込みがいつ転生するかの材料になるので、見せ方を見直す。周の数が増えて、前の周との差よりも長い傾向を見たくなったら、比べ方を見直す。
