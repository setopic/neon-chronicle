# 仕事の様子を、ログの左に線と点で描く

- 日付: 2026-10-20
- 状態: stable

## 背景

仕事に就いている間、画面には数字が増えるところしか出なかった。作者は、仕事の様子が画面に出て、画面を見ていること自体を楽しめるようにしたい（issue #121）。仕事は1回ずつ終わり、終わると報酬が入る（[ADR-0051](./adr-0051-job-pays-on-completion.md)）。

issueでは、様子の描き方と、絵を自作するか外部の素材を使うかと、置き場所と、進み具合・報酬が入る瞬間との合わせ方を決めることにしていた。

## 決定

1. 様子は2Dで、線と点と四角だけで描く。絵は外部の素材を使わず、`game/scripts/job_scene.gd`（`JobScene`）がコードで描く。色は[ADR-0052](./adr-0052-ui-style-foundation.md)の`UiStyle`から取る。
2. 仕事ごとに描くものを変える。運び屋は、街の道を荷が届け先へ進む。ハッカーは、防壁のセルを順に開けていく。傭兵は、地面を進みながら前の敵を撃って倒していく。中枢サーバーへの侵入は、中枢を囲む防壁の輪を外から1つずつ破る。
3. どの様子も、いまの1回の進み具合（1回の長さに対する割合）で進む。1回が終わると最初の位置に戻る。
4. 報酬が入ったときは、様子の欄を桃色に0.9秒光らせ、入った額を浮かび上がらせて消す。
5. 様子は、メインの画面の下の段で、ログの左に幅300pxの欄を置いて描く。仕事に就いていないときは、仕事を選ぶと様子が出ることを書いておく。

## 理由

線と点で描くのは、外部の素材のライセンスと書き出しの管理を増やさず、ADR-0052の細い線の見た目にそろえるためである。仕事ごとに形を変えたのは、どの仕事に就いているかが、ボタンを見なくても分かるようにするためである。

進み具合で動かすのは、様子と仕事の進み具合のバーを同じ値で動かし、見えている動きと報酬が入る瞬間をずらさないためである。

置き場所をログの左にしたのは、高さが変わらない欄だからである。体の状態の欄は、周の始まりにジンの依頼や縛りの行が増え、上の帯は高さが140pxしかない。ログは横に長く、幅を300px譲っても読める。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 上の帯の3Dの街の上に、仕事の様子を出す | 帯の高さが140pxしかなく、題と状態の板とボタンで横もほとんど埋まっている |
| 体の状態の欄の空いたところに出す | 周の始まりに依頼や縛りの行が増えると、欄の高さを超える |
| 外部の絵の素材を使う | ライセンスと書き出しの管理が増え、細い線の見た目とそろえにくい |
| 進み具合とは別に、一定の速さで動かし続ける | 報酬が入る瞬間と動きの区切りがずれる |

## 影響

ARCH-01の部品の表に`job_scene.gd`を足す。`main.gd`は、ログの欄の左に仕事の様子の欄を置き、ログの欄はその残りの幅に広げる。言語ファイルに、欄の見出しと、仕事に就いていないときの文を足す。

## 見直しの条件

様子が単調で見なくなるという声が出たら、決定の2の描き方を見直す。仕事を足すときは、その仕事の描き方を足す。描き方の無い仕事は、仕事に就いていないときの文が出る。
