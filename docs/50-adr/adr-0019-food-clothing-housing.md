# 衣食住は文だけで書き、食べ物は合成食の企業が握る

- 日付: 2026-10-19
- 状態: stable

## 背景

街の人々の衣食住は決めていなかった。画面に出ていたのは、下層街の資料にある屋台や修理屋と、イベント「薬の配達」の屋台の店主だけだった（issue #51）。

[ADR-0018](./adr-0018-companies-places-and-residents.md)を決めたissue #47の話し合いで、食べ物は合成食を作る企業を足し、下層街の屋台がそれを調理して売る形にすると決めていた。issueでは、食料の企業の名前と握っているもの、衣服と住居を誰が作り誰が握るか、画面のどこに出すかの3つを決めることにしていた。空腹や家賃のような新しい仕組みは足さないことも、issueの時点で決めていた。

## 決定

1. 食料の企業をリンドホルム食品と名付け、[DOM-15](../20-domain/dom-15-city-places-and-powers.md)の勢力に足す。自社の縄張りにある工場の培養槽で合成食を作り、街のほとんどの店へ卸す。兵器は、培養槽で育てた毒を作る。
2. 本物の肉や野菜は、企業区画にしか出回らない。下層街の屋台は、リンドホルム食品の合成食を煮たり焼いたりして売る。
3. 衣服を作る企業は足さない。企業区画では、各社が社員と私兵に自社の制服を着せる。下層街の住人は、企業区画から流れてきた古着や合成繊維を仕立て直して着る。
4. 住居を握る企業は足さない。社員は、自社の縄張りの中にある社宅に住む。下層街の住人は、ビルの足元や橋の下に小屋やコンテナを積み上げて住み、家主はいない。
5. 画面には、「街と人物」の資料と、新しいイベントで出す。資料「リンドホルム食品」を足し、資料「企業」「企業区画」「下層街」に衣食住の文を足す。運び屋のイベント「合成食の荷運び」を足す。イベントの仕組みは変えない。

## 理由

衣服と住居に企業を足さなかったのは、各社が私兵も兵器も自前で持つというADR-0018の決まりと揃うからである。制服と社宅も、各社が自前で用意するものとして書ける。下層街の住まいに家主を置かないのは、下層街を企業に属さない人々の街とした[DOM-15](../20-domain/dom-15-city-places-and-powers.md)の決まりとぶつからないようにするためである。

食べ物だけ企業を足したのは、#47で決めたとおり、下層街の屋台が売る物の出どころを書くためである。社名はADR-0018の決まりどおりヨーロッパ系にし、ヴァルデック義体（ドイツ系）とモンフォール警備（フランス系）と系統が重ならない北欧系にした。

資料だけでなくイベントでも出すのは、イベントの文は仕事中に必ず目に入り、リンドホルム食品が街に出てくるからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 食料の企業をロスベルク食品・ベルトラン食品にする | ヴァルデック義体・モンフォール警備と国の系統が重なり、名前を見分けにくい |
| 衣服を売る企業を足す | 社名と縄張りを新しく決めることになり、設定が増える |
| 下層街の住まいを持つ不動産の企業を足す | 家主と住人の争いという新しい筋が増え、下層街を企業に属さない人々の街とした決まりとぶつかる |
| 資料だけで出す | 仕事中には目に入らない |
| 空腹や家賃の仕組みを足す | 新しい数値と画面が要り、遊び通しての確認が増える |

## 影響

DOM-15に、勢力「リンドホルム食品」、衣食住の表、用語「リンドホルム食品」「合成食」「社宅」を足す。[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)の資料の一覧に「リンドホルム食品」を足す。

`game/data/events.json`にイベント「合成食の荷運び」を、`game/data/profiles.json`に資料「リンドホルム食品」を足す。言語ファイルでは、新しいイベントと資料のキーを足し、資料「企業」「企業区画」「下層街」の説明に文を足す。

## 見直しの条件

食べ物や住まいを、数値として扱いたくなったら見直す。
