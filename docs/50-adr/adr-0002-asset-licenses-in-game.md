# 素材のライセンスの一覧をゲームの中に置く

- 日付: 2026-10-18
- 状態: stable

## 背景

ブラウザ版を公開すると、使った素材のライセンスを表示する必要がある。ゲームに入っている外部の素材は、フォントのNoto Sans JPと、エンジンのGodotである。Noto Sans JPはSIL Open Font License 1.1で、フォントを配るときにライセンスの全文を添えることを求める。GodotはMITライセンスで、著作権の表示と許諾の文を残すことを求める。Godotの中には、FreeTypeなどの第三者の部品が入っていて、それぞれに別のライセンスがある。

決める前は、OFLの写しが`game/fonts/`にあるだけで、書き出したゲームには入っていなかった。

## 決定

使った素材とそのライセンスの一覧を、`game/credits.txt`に置く。リポジトリの中の一覧はこのファイルだけで、素材を足したらここに書き足す。

ゲームの画面の右上に「ライセンス」のボタンを置き、押すと次のものを順に表示する。

1. `game/credits.txt`
2. OFLの全文（`game/fonts/OFL-NotoSansJP.txt`）
3. Godotのライセンスの全文と、第三者の部品の著作権の表示とライセンスの全文

1と2は、書き出しに含めるよう`game/export_presets.cfg`の`include_filter`に挙げる。3はファイルに写さず、実行中にGodotから取る（`Engine.get_license_text`・`get_copyright_info`・`get_license_info`）。

itch.ioのページの説明文には、ゲームの中の「ライセンス」のボタンから全文を見られることを書く。

## 理由

ライセンスが求めているのは、配るものに表示や全文を添えることである。itch.ioのブラウザ版で配るのは書き出したゲームそのものなので、ゲームの中に置けば、配り先がどこでも一覧が付いていく。あとでPC版をitch.ioやSteamで配るときも、そのまま使える。

Godotの部分を実行中に取るのは、エンジンの版を上げても一覧が食い違わないようにするためである。第三者の部品は100件ほどあり、手で写すと版を上げるたびに追従が要る。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| itch.ioのページだけに書く | ページはゲームと別に編集するので、素材を足したときに書き忘れても気づけない。PC版をSteamで配るときに、もう一度書くことになる |
| リポジトリにだけ置く | 遊ぶ人が公開版から辿れない（issue #2の受け入れ条件を満たさない） |
| Godotの第三者の部品のライセンスを、ファイルに写して同梱する | 版を上げるたびに写し直しが要る。Godotが実行中に同じ内容を返すので、写す理由が無い |
| タイトル画面にクレジットを作る | いまのゲームにはタイトル画面が無い。一覧を見せるためだけに画面の流れを変えることになる |

## 影響

ARCH-01の構成に`game/credits.txt`が加わり、素材を足すときはここに書き足すことになる。UC-01で上げるzipに、一覧とライセンスの全文が入る。

## 見直しの条件

音楽・効果音・画像など、外部の素材が増えて、1つの画面で読むには長くなったとき。タイトル画面を作ったときは、ボタンの置き場をそちらへ移すかを考える。
