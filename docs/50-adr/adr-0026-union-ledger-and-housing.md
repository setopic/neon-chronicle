# 屋台組合が、台帳でみかじめを割り振り、外から来た人に住む場所を割り振る

- 日付: 2026-10-19
- 状態: stable

## 背景

[ADR-0024](./adr-0024-lower-city-gang-and-union.md)は、屋台通りの店のみかじめを屋台組合がまとめて払い、額をザンダー一家と話し合って決めることにした。組合の中で、誰からいくら集めるかは決めていなかった。

[ADR-0025](./adr-0025-city-history-before-corporations.md)は、下層街の住宅の持ち主が市の財政破綻で無くなり、家主がいなくなったことにした。作者から、外から来た人が下層街に住みつくときにどうなるのか、という問いが出た（issue #64のスレッド）。

## 決定

1. 屋台組合は、屋台通りで店を開く者を、組合の台帳に載せる。ザンダー一家と話し合って決めた額を、店の場所と大きさで分けて集める。店を持たない住人は、みかじめを払わない。
2. 屋台通りと下層街の奥では、外から来た人が住みつくとき、屋台組合が空いた場所を割り振り、台帳に載せて、水と電気を分ける。
3. 裏通りでは、外から来た人は、ザンダー一家に金を払って住む。
4. 屋台組合もザンダー一家も、住む場所を割り振るだけで、家主にはならない。下層街の住まいに家主がいないことは変えない。
5. 画面には、資料「屋台組合」と「ザンダー一家」の文で出す。イベントは足さない。

## 理由

台帳で割るのは、総額を組合が一家と話し合って決める今の設定と合い、店を持たない住人まで払わされないからである。作者がこの案を選んだ。

住む場所を組合が割り振るのは、組合がすでに水と電気の分け方をまとめていて、住む場所が決まらないと分けられないからである。作者がこの案を選んだ。裏通りは一家が仕切っているので、裏通りに住む者は一家に金を払うことにした。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| みかじめを、組合に入っている店が同じ額ずつ払う | 作者が台帳で割る案を選んだ。小さな屋台と大きな店が同じ額になる |
| みかじめの店ごとの額を、ザンダー一家が決める | 作者が台帳で割る案を選んだ。総額を組合が話し合って決める設定と合わない |
| 空いた場所に勝手に住んでよく、組合に入らないと水と電気の分け前がもらえない | 作者が、組合が割り振る案を選んだ |
| 下層街のどこでも、ザンダー一家が空いた場所を売る | 作者が、組合が割り振る案を選んだ。一家が家主のようになり、家主がいないという設定とずれる |

## 影響

[DOM-15](../20-domain/dom-15-city-places-and-powers.md)の屋台組合の行と、ザンダー一家と屋台組合の段落、衣食住の表の「住」に書き足し、用語「組合の台帳」を足す。言語ファイルの資料「屋台組合」と「ザンダー一家」の文に書き足す。

## 見直しの条件

住む場所やみかじめを、イベントの選択肢や数値に結び付けるときは、台帳の扱いを見直す。
