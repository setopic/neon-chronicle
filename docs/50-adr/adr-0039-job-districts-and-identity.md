# 仕事に区画を持たせ、傭兵の仕事には偽の身元を要る

- 日付: 2026-10-20
- 状態: stable

## 背景

仕事やイベントに場所が無く、区画（[DOM-15](../20-domain/dom-15-city-places-and-powers.md)）と身元（[DOM-18](../20-domain/dom-18-resident-classes.md)）は読み物にとどまっていた（issue #86）。DOM-18は、身元の無い者は橋を渡れないとしているが、主人公はどの仕事にも身元なしで就けていた。地図には、いまどこで働いているかが出ていなかった。[ADR-0022](./adr-0022-city-map-in-game.md)は、仕事やイベントに場所を持たせると決めたときに、地図の見せ方を見直すとしていた。

issueでは、仕事ごとの区画と身元の要る仕事、身元の得方と周の終わりで残るか、地図に今の仕事の区画を示すかの3つを決めることにしていた。作者からは、推奨の案で進めてよいと言われている。

## 決定

1. 仕事ごとに区画を1つ持たせる。運び屋は屋台通り、ハッカーは闇市場、傭兵はヴァルデック義体の縄張り、中枢サーバーへの侵入はヨミ・システムズの縄張りとする。
2. 身元が要る仕事は、傭兵だけにする。傭兵は企業区画で働くので、橋を渡れる身元が要る。
3. 身元は、闇市場で偽の身元を300クレジットで買う。体の状態の欄のインプラントの下に、買うボタンを置く。
4. 偽の身元は周の終わりに失い、次の周には持ち越さない。
5. 地図に、いまの仕事の区画を名前の色を変えて示し、「いまの仕事」と添える。仕事に就いていないときは示さない。
6. 前の版のセーブで、傭兵に就いていた周は、偽の身元を持っていたものとして読む。

## 理由

身元が要る仕事を傭兵だけにしたのは、ほかの仕事は下層街か、橋を渡らずに済む場所でしているからである。ハッカーは闇市場からネット越しに仕事をし、中枢サーバーへの侵入もネット越しである。運び屋は下層街を走る。

偽の身元を周の終わりに失うのは、偽の身元が体ではなく、その体に付けた登録だからである。周ごとに買い直すので、稼いで身元を買い、橋の向こうの仕事に移るという段取りが毎周生まれる。値段を300にしたのは、運び屋とハッカーで数分働けば届き、最初のインプラント（100）より後、2つめ（500）より前に買えるからである。

地図にいまの仕事の区画を示すのは、仕事に場所ができたので、地図を見れば、いまどこで働いているかが分かるようにするためである。ADR-0022が却下した「今いる場所を示す」は、仕事に場所が無いときの判断だった。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 企業区画で働く仕事すべてに身元を要る | 中枢サーバーへの侵入はネット越しで、橋を渡らない |
| 偽の身元を転生しても残す | 一度買えば身元が要ることを気にしなくなり、毎周の段取りが生まれない |
| 偽の身元をインプラントの1つにする | インプラントは体に組み込む部品で、身元はネットの登録である |
| 偽の身元を、イベント「偽の身元」で消されるようにする | 周の途中で傭兵を続けられなくなり、取り返しが付かない |
| 仕事ごとに複数の区画を持たせる | 地図にどこを示すかが決まらない |

## 影響

DOM-24を新しく起こし、仕事の区画・身元が要る仕事・偽の身元を定義する。

`game/data/jobs.json`の仕事に`district`と`needs_identity`を足す。`game_state.gd`は、その周に偽の身元を持っているかをセーブに書き、身元の要る仕事に就けるかを決める。体の状態の欄に偽の身元を買うボタンを置き、仕事のボタンの条件に身元を出す。`city_map.gd`は、いまの仕事の区画を示す。`playthrough.gd`は、買えるときに偽の身元を買う。

## 見直しの条件

偽の身元を買うのが当たり前になり、迷う場面が無くなったら、値段か、身元の要る仕事を決め直す。イベントに場所を持たせたくなったら、イベントにも区画を持たせるかを決める。
