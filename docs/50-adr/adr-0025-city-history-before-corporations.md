# 企業の時代より前の街を市とし、市の財政破綻で企業の時代が始まったことにする

- 日付: 2026-10-19
- 状態: stable

## 背景

3本の橋は、企業が街を分け合うより前の時代に、その橋を架けた人の名前で呼ばれる（[ADR-0023](./adr-0023-bridge-names-and-terrain-map.md)）。ADR-0023は、架けた人について名前のほかは決めず、物語に出すときに見直すことにしていた。企業の時代より前に街が何だったのかも、決まっていなかった。

橋が人の名前で呼ばれていることに筋が通るように、街の歴史を決めることにした（issue #64）。issueでは、企業の時代より前の街を誰が治めていたか、橋を架けた3人の人物と関係、企業の時代の始まり、崖と排水路が橋より前からあったか、画面のどこに出すかを決めることにしていた。

## 決定

1. 企業の時代より前、ネオン・シティは、市議会と市役所が治める市だった。この時代を市の時代と呼ぶ。発電所・浄水場・路面電車・橋は、市のものだった。
2. 崖と川は、橋より前からあった。市は高台にあり、崖の下は川沿いの湿った低い土地だった。市は川をまっすぐにして排水路にし、乾いた低い土地に、工場で働く人のための住宅を建てた。
3. 3本の橋は、市の技師が架けた。最初にオルセンがオルセン橋を架け、弟子のヴィラールとハーゲンが、師匠の図面を引き継いでヴィラール橋とハーゲン橋を架けた。橋のたもとには、架けた人の名前を刻んだ銘板が残っている。3人は企業の時代を見ていない昔の人で、いまの街には出てこない。
4. 市は財政破綻した。借金を返すために、発電所をヨミ・システムズへ、浄水場をリンドホルム食品へ、高台の土地を企業の各社へ売り払った。これで企業の時代が始まった。市役所は無くなり、市議会も開かれなくなった。
5. 路面電車は買い手が付かずに止まり、橋は手入れに金がかかるのでどの社も買わなかった。低い土地の住宅は、家主がいなくなって崩れ、残った人々が下層街の住人になった。
6. 画面には、「街と人物」の資料と、新しいイベントで出す。資料「街の歴史」を、資料「ネオン・シティ」のすぐ後ろに足す。運び屋のイベント「古い銘板」を足す。資料「企業区画」の橋の文を、市の技師が架けたと書き直す。地図と記憶の断片は変えない。

## 理由

財政破綻にしたのは、企業が買ったものと、誰も買わずに残ったものの違いで、今の街のいくつもの設定が説明できるからである。電気と水を2社が握っていること（[ADR-0021](./adr-0021-city-infrastructure.md)）は、2社が発電所と浄水場を買ったことから来る。橋がどの社の持ち物でもないこと、街に公共の交通が無いこと、下層街の住まいに家主がいないことは、買い手が付かなかったか、持ち主が無くなったことから来る。主人公も借金を消す代わりに体を差し出しているので、街と主人公の成り立ちが重なる。

技師の師匠と弟子にしたのは、3人の関係が1行で伝わり、架けた順も決まるからである。人の名前で橋を呼ぶのは、市の人々が架けた技師を覚えていたからとした。

崖と川を橋より前からあったことにしたのは、高台と低い土地に分かれた土地だから橋が要った、という順にするためである。

記憶の断片に出さないのは、断片が主人公自身の記憶だからである。資料だけだと、読みに行かないと橋の名前の由来に気づかないので、イベントも足した。イベントは運び屋の仕事にした。運び屋は合成食をハーゲン橋から運んでいるので、橋のたもとで荷を待つ場面に無理が無い。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 大きな洪水で低い土地が沈み、復旧の金を出した企業が見返りに街を分け合う | 作者が財政破綻を選んだ。橋がどの社の持ち物でもない理由が、別に要る |
| 暴動と内戦で市が治安を保てなくなり、企業の私兵が街を分け合う | 作者が財政破綻を選んだ。電気と水を2社が握る理由が、別に要る |
| 市長・技師・金を出した商人の、同時代の3人が架けた | 作者が師匠と弟子を選んだ |
| 別々の時代の、互いに面識の無い技師が1本ずつ架けた | 作者が師匠と弟子を選んだ。3人の名前を並べても、つながりが伝わらない |
| 資料だけに出し、イベントを足さない | 資料を読みに行かないと、橋の名前の由来に気づかない |
| 屋台組合の古株を名前のある人物にし、昔話をする人物のイベントにする | 名前のある人物が1人増え、DOM-10と人物のイベントの設定が増える |
| 記憶の断片に街の歴史を入れる | 記憶の断片は主人公自身の記憶で、街の歴史とは関わらない |

## 影響

[DOM-17](../20-domain/dom-17-city-history.md)を足し、市の時代・企業の時代・橋を架けた3人・銘板を定義する。[DOM-15](../20-domain/dom-15-city-places-and-powers.md)の「名前のほかは決めていない」を、DOM-17への案内に改め、場所と橋の表に「古い銘板」を足す。[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)の資料の一覧に「街の歴史」を足す。

`game/data/events.json`にイベント`old_plaque`を、`game/data/profiles.json`に資料`history`を足す。言語ファイルでは、新しいイベントと資料のキーを足し、資料「企業区画」の橋の文を書き直す。

## 見直しの条件

市の時代のことを記憶の断片や人物のイベントに出すときは、記憶の断片と人物の設定に合うかを見直す。企業の時代が始まってからの年数を画面に出すときは、屋台の年寄りが親から聞いたという話と合うかを見直す。
