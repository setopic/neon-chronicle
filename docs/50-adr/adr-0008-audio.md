# 音楽と効果音をスクリプトで作り、最初の操作から鳴らす

- 日付: 2026-10-18
- 状態: stable

## 背景

ゲームには音が無かった（issue #8）。音を入れるには、素材をどこから持ってくるかと、ブラウザで最初に音を鳴らすときの扱いを決める必要があった。外部の素材を足すと、`game/credits.txt`への記載とライセンスの確認が要る（[ADR-0002](./adr-0002-asset-licenses-in-game.md)）。ブラウザは、遊ぶ人が一度クリックかキー入力をするまで、ページに音を出させない。

## 決定

音楽と効果音は、`game/audio/make_sounds.py`で合成して作る。標準ライブラリだけで動き、乱数の種を固定しているので、回し直すと同じWAVができる。音を変えるときは、このスクリプトを直して回し直す。

作る音は、繰り返して流す曲1つと、効果音4つである。

| ファイル | 鳴らすとき |
| --- | --- |
| `music.wav` | 起動してから流し続ける |
| `click.wav` | ボタンを押したとき |
| `event.wav` | イベントが起きたとき |
| `fall.wav` | 周が終わったとき |
| `rebirth.wav` | 新しい体で目覚めたとき |

ブラウザで最初に音を鳴らすための画面は置かない。起動したときから曲を流しておき、遊ぶ人が最初にクリックかキー入力をしたときから聞こえるようにする。この解除はGodotのWeb書き出しが行う。

音楽と効果音は、右上の「音楽」と「効果音」のボタンで別々に消せる。設定は、言語と同じ`user://settings.json`に`music`・`sfx`として保存する。どちらも最初は入っている。

## 理由

自作の音は外部の素材ではないので、ライセンスを確かめる手間が無い。`credits.txt`には「Neon Chronicleのために作った」ものとして書くだけで済む。合成した電子音は、サイバーパンクの街の雰囲気にも合う。あとでCC0の素材や依頼した曲に差し替えるときも、同じ名前のファイルを置き換えれば鳴らす側は変わらない。

放置ゲームは、開いてすぐ仕事を選ぶので、最初の操作はすぐに来る。開始の画面を足しても、曲の聞こえ始めが少し早まるだけで、画面が1枚増える。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| CC0の素材を集めて同梱する | 音の質は上がるが、選ぶ手間とライセンスの記録が要る。ブラウザ版の公開には自作の音で足りる |
| ゲームの中で実行中に合成する | スレッドを使わないWeb書き出しでは、生成した音が途切れやすい |
| 「クリックで開始」の画面を置く | 画面が1枚増える。最初の操作はすぐ来るので、得られるのは数秒だけである |
| 音を最初は消しておく | 音があることに気づかれにくい |

## 影響

ARCH-01の構成に、`game/audio/`と、音を鳴らす自動読み込みの`Sound`（`sound.gd`）が加わる。

CIのヘッドレスの起動では、音を出す先が無い（AudioServerのドライバーがDummyになる）ので、`Sound`は何も鳴らさない。そのため、CIは音が鳴ることを確かめていない。

## 見直しの条件

PC版を出すときや、音への不満が寄せられたときは、自作の音を素材や依頼した曲に差し替えるかを考える。差し替えたら、`credits.txt`に書き足す（[ADR-0002](./adr-0002-asset-licenses-in-game.md)）。
