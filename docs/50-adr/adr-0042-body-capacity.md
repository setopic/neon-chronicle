# 体の種類ごとに容量を持たせ、インプラントを外せるようにする

- 日付: 2026-10-20
- 状態: stable

## 背景

インプラントは3種で、買うと外せなかった（[DOM-04](../20-domain/dom-04-implants.md)）。稼げば3つとも買えたので、体の種類とインプラントの組み合わせに迷う場面が無かった（issue #89）。

issueでは、体ごとの容量と超えたときの扱い、取り外せるかどうかと足すインプラントの2つを決めることにしていた。作者からは、推奨の案で進めてよいと言われている。

## 決定

1. 体の種類ごとに容量を持たせる。汎用の体は3、作業用の体は4、戦闘用の体は5、試作の体は2とする。
2. インプラントに大きさを持たせる。大きさの合計が体の容量を超えるときは、組み込めない。
3. インプラントを4つ足し、7つにする。痛覚抑制（300、大きさ1、劣化 -15%）、相場読みの義眼（600、大きさ1、稼ぎ +20%）、反射配線（800、大きさ2、稼ぎ +30%・劣化 +10%）、記憶補助野（1500、大きさ2、経験 +40%）である。既存の神経加速チップは大きさ1、強化骨格は2、信用スコア偽装は0とする。
4. 組み込んだインプラントは外せる。外しても代金は戻らない。インプラントのボタンを押すと、組み込んでいなければ買い、組み込んでいれば外す。
5. インプラントの欄に、使っている容量と体の容量を出す。転生の画面の体の種類のボタンにも、容量を出す。
6. 前の版のセーブで、容量を超えて組み込んでいた周は、そのまま読む。外すまで新しく組み込めない。
7. 体の容量は、新しいドメインノード[DOM-26](../20-domain/dom-26-body-capacity.md)に書く。

## 理由

容量を体の種類ごとに変えたのは、体を選ぶときに、組み込みたいインプラントを考える理由ができるからである。試作の体は経験が大きく増えるので、容量を小さくして釣り合いを取った。戦闘用の体は劣化が速いので、容量を大きくして、劣化を下げるインプラントを積めるようにした。

超えたときに組み込めないとしたのは、超えた分の害を決めると、劣化と効果の2つの釣り合いを見ることになるからである。

外せるようにしたのは、容量が埋まったあとに、別のインプラントに入れ替える場面を作るためである。代金を戻さないのは、入れ替えに重みを持たせるためで、戻すと、いつでも最適な組み合わせに入れ替えられる。

信用スコア偽装の大きさを0にしたのは、体ではなくネット上の身元に組み込むという説明（DOM-04）に合わせるためである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 容量を超えて組み込めるが、劣化が増える | 劣化と効果の2つの釣り合いを見ることになる |
| 外すと、代金の半分を戻す | いつでも入れ替えられ、組み合わせに迷う場面が減る |
| インプラントを外せないままにする | 容量が埋まったあとに、選ぶ場面が無い |
| 容量を永続強化で増やせるようにする | 永続強化の釣り合いを決め直すことになる |
| 外すボタンを別に置く | インプラントの欄の行が2倍になる |

## 影響

DOM-26を新しく起こし、体の容量・大きさ・外すことを定義する。

`game/data/bodies.json`に`capacity`、`game/data/implants.json`に`size`と4つのインプラントを足す。`game_state.gd`は、容量に収まるかを見て組み込み、外す操作を持つ。インプラントの欄に使っている容量を出す。セーブの形は変えない。

## 見直しの条件

どの体でも同じ組み合わせが選ばれるようになったら、容量か大きさを決め直す。外す操作が誤って押されるという声が出たら、確かめのダイアログを置く。
