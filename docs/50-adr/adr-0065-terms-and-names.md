# 用語と名前の揺れを直す

- 日付: 2026-10-20
- 状態: stable

## 背景

設計文書の点検で、用語の食い違いと、名前の系統の揺れが見つかった（issue #155）。DOM-04の用語「組み込む」はインプラントを外せないとしていたが、[ADR-0042](./adr-0042-body-capacity.md)とDOM-26は外せるとしている。[ADR-0031](./adr-0031-western-terms.md)の背景は、ネオン・シティはヨミ・システムズのほかは欧米の名前の企業と人物でできているとしていた。しかし、ミオ・ジン・レイはアジアの響きの名前で、ジンとレイはヨミ・システムズの人物でもない。

ほかに、次の揺れがあった。橋を架けた技師の名前が、企業の名前と国の系統で1対1に重なっていた。元の持ち主の話が、用語の上では勢力の話のイベントにもなっていた。「進み具合」と「上乗せ」が、いくつもの意味で使われていた。モンフォール警備の隊員を私兵と呼んでいたが、私兵の意味は自社の縄張りを守る兵だけだった。市の時代の街の名前が決まっていなかった。

## 決定

置き換えるADRは無い。ADR-0019・ADR-0031・ADR-0042の決定は、どれもそのまま生きている。

1. DOM-04の用語「組み込む」から、外すことはできないという記述を消す。外すことはADR-0042とDOM-26のとおりとする。
2. 欧米の名前にそろえるのは、ヨミ・システムズのほかの企業と、その社の人物とする。どの企業にも属さない下層街の人物は、名前の系統を問わない。九条は、ヨミ・システムズの人物なのでアジアの名前で漢字で書き、画面には出さない。ミオ・ジン・レイの名前は変えない。
3. 橋を架けた技師と企業の名前が国の系統で重なるのは、意図したものとする。名前は変えない。
4. 元の持ち主の話は、用語「元の持ち主の話のイベント」と呼び、勢力の話のイベントとは別の種類とする。段は、人物のイベントの段と同じ意味で使う。まとめて呼ぶ語は置かない。
5. 「進み具合」と「上乗せ」の語は変えない。仕事の1回の進み具合は、依頼の進み具合・話の進み具合とは別のものとする。スキルの上乗せは割合で、依頼の上乗せ・縛りの上乗せは量とする。
6. 私兵の意味を、企業が自前で抱える兵で、自社の縄張りを守るか、モンフォール警備の隊員のように請け負った場所を見張る兵、と広げる。
7. 市の時代も、街はネオン・シティと呼ばれていたとする。

## 理由

どれも、いまある文書と画面の文をなるべく動かさない直し方を選んだ。

名前の系統を企業に属するかどうかで分けたのは、ADR-0031が欧米の語にそろえた理由が、企業の街の世界観だったからである。下層街は企業に属さない人々の街なので（[DOM-15](../20-domain/dom-15-city-places-and-powers.md)）、名前が混ざっていても世界観とぶつからない。九条だけが漢字なのは、画面に名前を出さないので、並べたときの調子のずれが画面には出ない。

橋と企業の名前の重なりを残したのは、橋の名前には「橋」が、社名には「義体」「警備」「食品」が付くので見分けられるからである。[ADR-0019](./adr-0019-food-clothing-housing.md)が系統の重なりを避けたのは、企業どうしを見分けるためで、橋は企業ではない。市の時代の技師と今の企業が同じ土地の人々だと読めることも、街の歴史と合う。

元の持ち主の話を別の種類にしたのは、[DOM-30](../20-domain/dom-30-branch-chart.md)の分岐図が、すでに3つを別の種類として並べているからである。まとめて呼ぶ語を置かなくても、どの文書もそれぞれの種類の名前で書ける。

「進み具合」と「上乗せ」を変えなかったのは、それぞれの複合語で意味がすでに分かれていて、画面の文も変えずに済むからである。

私兵の意味を広げたのは、DOM-18の住民の階級と、ジンの1段目の「私兵の張っている橋」を、そのままで正しく読めるようにするためである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ミオ・ジン・レイを通り名とし、本名を別に決める | 本名という設定が増え、資料と断片の文に書き足すことになる |
| ミオだけを元ヨミ・システムズの技師として説明し、ジンとレイの名前の出どころを別に決める | 人物ごとの出どころの設定が増える |
| ADR-0031を置き換える | ADR-0031の決定（語の言い換えと九条の名前）は変わらないので、置き換えると参照の張り替えだけが増える |
| 橋の技師の名前を、企業と重ならない系統に改める | 資料・イベント・断片の文と橋の名前がすべて変わる |
| 周をまたぐ話をまとめて呼ぶ語を置く | どの文書もその語を使っておらず、語が増えるだけである |
| モンフォール警備の隊員を「警備員」と呼ぶ | DOM-18とジンの1段目の文を書き換えることになる |
| 市の時代の街に別の名前を付ける | 名前が1つ増えるが、その名前を出す場面が無い |

## 影響

[DOM-04](../20-domain/dom-04-implants.md)の「組み込む」の意味から、外せないという記述を消す。[DOM-10](../20-domain/dom-10-characters.md)に、人物の名前の系統の決まりを書く。[DOM-25](../20-domain/dom-25-body-former-owners.md)の用語表に「元の持ち主の話のイベント」を足し、[DOM-23](../20-domain/dom-23-stall-street-feud.md)の「勢力の話のイベント」の意味に、段の意味を書く。[DOM-03](../20-domain/dom-03-jobs-and-skills.md)の「進み具合」と「スキルの上乗せ」の意味に、ほかの語との違いを書く。[DOM-15](../20-domain/dom-15-city-places-and-powers.md)の「私兵」の意味を広げる。[DOM-17](../20-domain/dom-17-city-history.md)に、ネオン・シティという呼び名が市の時代からのものだと書く。

数値・仕組み・画面の文は変えない。

## 見直しの条件

ジン・レイのほかに、名前を持つ下層街の人物や企業の人物を足すとき。周をまたぐ話の種類が4つめに増え、まとめて呼ぶ語が要るようになったとき。
