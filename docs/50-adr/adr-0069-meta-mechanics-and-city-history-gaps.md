# 遊ぶ人の側の仕組みを挙げ、街の歴史の穴を埋める

- 日付: 2026-10-20
- 状態: stable

## 背景

設計文書の点検で、遊びの仕組みの一部に世界の中での理由が無いことと、街の歴史に小さな穴があることが分かった（issue #156）。エンディングのあとも転生して遊び続けられること、縛りの上乗せ、話の選び直しには、世界の中での理由が無い。街の歴史では、市の時代の工場が誰のものでどこにあったか、発電所と土地を買った企業がそれまでどこにいたか、各社に欠かせない橋が手入れされずに残っている理由が無かった。

## 決定

1. エンディングのあとの転生、縛りの上乗せ、話の選び直しは、遊ぶ人の側の仕組みとし、世界の中では説明しない。DOM-09に、世界の中で説明しないものとして挙げる。
2. いまの企業の各社は、市の時代から高台で商売をしていた会社である。市の時代の工場は、その各社が高台に持っていたものである。街を治めていたのは市で、会社は商売をしていただけである。
3. 発電所と高台の土地を買った企業は、もとから街の中にいた会社である。外の街は、[ADR-0027](./adr-0027-resident-classes-and-identity.md)のとおり、引き続き決めない。
4. 各社がモンフォール警備に出し合う金には、橋が落ちない程度に直す費用も含まれる。持ち主になると手入れをすべて負うので、どの社も橋を買わない。
5. 画面の資料「街の歴史」の文は変えない。

[ADR-0025](./adr-0025-city-history-before-corporations.md)と[ADR-0027](./adr-0027-resident-classes-and-identity.md)の決定は改めず、足すだけである。

## 理由

3つの仕組みを世界の中で説明しないことにしたのは、説明を付けると、エンディングで物語が閉じたあとにも新しい設定が要るからである。転生・記憶ポイント・永続強化のように、1周の中で遊ぶ人が毎回触れる仕組みとは違い、この3つは物語の外で遊び方を選ぶためのものである。

工場を各社のものにしたのは、市の時代の工場と、いまの企業区画の工場が1つにつながり、企業の出どころも同じ一文で決まるからである。外の街を決めずに済む。

橋の手入れを出資に含めたのは、「手入れに金がかかるので買わなかった」という歴史を変えずに、各社が橋を使い続けられる理由になるからである。

画面の文を変えないのは、足した内容が穴を埋める説明で、遊ぶ人に新しく伝えることではないからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| エンディングのあとの周を「クロニクルを読み返すこと」と位置づける | 物語が閉じたあとの設定が増える。縛りの上乗せと話の選び直しには別の説明が要る |
| 市の時代の工場も市のもので、財政破綻のときに各社へ売った | 企業がそれまでどこにいたかが、別に要る |
| 企業は外の街から来た | 外の街を決める必要が出る |
| 橋は傷んだまま使われていて、いつ落ちてもおかしくない | 各社に欠かせない橋を放っておく理由が、かえって弱くなる |
| 資料「街の歴史」の文にも足す | 画面の文が増えるわりに、遊ぶ人に伝わる新しいことが無い |

## 影響

DOM-09に、世界の中で説明しない仕組みの表を足す。DOM-17に、企業の各社が市の時代から高台で商売をしていたことと、橋の手入れの費用の出どころを足す。数値と仕組みと画面の文は変えない。

## 見直しの条件

エンディングのあとの周に物語を足すときは、3つの仕組みを世界の中で説明するかを決め直す。外の街を決めるときは、企業の出どころとの食い違いを確かめる。
