# 運び屋の仕事のミニゲームを、追っ手をかわして升目を進む遊びにする

- 日付: 2026-10-20
- 状態: stable

## 背景

仕事の1回をミニゲームで置き換える仕組みを、[ADR-0054](./adr-0054-minigame-frame.md)で作った。issue #124では、運び屋の仕事のミニゲームの遊び方と、難しさをスキルのレベルでどう変えるかを決めることにしていた。issueの例には、道を選んで届けることと、追っ手をかわすことが挙がっていた。

## 決定

1. 遊び方は、8列5行の街の升目を1歩ずつ進み、左の端から右の端の届け先へ荷を運ぶものにする。届け先の行は、遊ぶたびに変わる。
2. 追っ手は3人いて、それぞれ決まった列を縦に行き来する。自分が1歩進むか待つたびに、追っ手も1歩動き、端で折り返す。追っ手と同じ升目に入るか、すれ違うと捕まる。追っ手が次に動く向きは、画面に印で出す。
3. 使える歩数には上限がある。上限は、追っ手がいないときのいちばん短い歩数に、余りを足した数とする。余りは、運び屋の対応スキルである交渉のレベル0で3つあり、5レベルごとに1つ増え、7つまで増える。
4. 成功の度合いは、届けたときに余りの歩数をどれだけ使ったかで決める。いちばん短い歩数で届けたら1、余りを使い切って届けたら0.5とし、その間は使った数に比例させる。捕まったときと、歩数を使い切ったときの度合いは0とする。
5. 地図は、追っ手の位置を決めたあと、レベル0の上限の歩数で届けられる手があるかを確かめる。無ければ作り直す。そのため、どの地図でも必ず届けられる。
6. キーボードでは、矢印のキーかWASDで進み、空白のキーで待つ。マウスでは、隣の升目を押すとそちらへ進み、上・下・左・右・待つのボタンでも進める。

## 理由

1歩ずつ交互に動く形にしたのは、追っ手の動きを読んで道を選ぶ考えどころを作るためである。手の速さが要らないので、マウスでもキーボードでも同じように遊べる。

追っ手の動く向きを見せるのは、読めば避けられる形にして、捕まったときに運のせいにならないようにするためである。

レベルが上がるほど易しくする向きと、余らせた分で度合いを決める形は、ハッカーのミニゲーム（[ADR-0055](./adr-0055-hacking-minigame.md)）とそろえた。どのミニゲームでも、スキルを上げた手応えと、うまく終えた手応えが同じ形で返る。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 時間とともに追っ手が動き続ける形にする | 手の速さが要り、キーボードとマウスで遊びやすさが変わる |
| 追っ手が自分を追いかけて動く形にする | 動きが読みにくく、避けられるかが運に寄る |
| 捕まっても始めの升目に戻るだけにする | 何度でもやり直せて、上限の歩数のほかに緊張が無い |
| 地図を確かめずに作る | 届けられない地図に当たることがある |

## 影響

DOM-03のミニゲームの種類に、運び屋のミニゲームが加わる。`game/data/jobs.json`の運び屋の`minigame`を`courier`にする。`game/scripts/minigame_courier.gd`がこのミニゲームを持ち、`ci/minigame.gd`で、作った地図を確かめたときの手で届けられることを確かめる。

## 見直しの条件

捕まってばかりで遊ぶ気が起きないという声が出たら、追っ手の数か余りの歩数を見直す。易しすぎて、いつも度合いが1になるなら、余りを減らす。
