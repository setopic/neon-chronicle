# 転生の画面とメインの画面を1280x720に収める

- 日付: 2026-10-20
- 状態: stable

## 背景

縛りの欄・体の質・元の持ち主の特性を足したあと、転生の画面が1280×720の右と下にはみ出すようになった（issue #113）。体のボタンや縛りの選択肢の文を折り返していなかったため、その最も長い行がパネルの幅を決めていた。永続強化から体のボタンまでを1列に積んでいたので、高さも720を超えていた。

メインの画面も、英語では右端が切れていた。仕事の条件やインプラントの文を折り返さないため、中段が1280より広くなり、右上のボタンと中段のスクロールバーが画面の外に出ていた。中段の高さは356しかなく、周の始まりでもインプラントの欄の途中から下はスクロールしないと見えなかった。分岐図の話の名前も、英語では「Former owner of the」で切れていた。

[ADR-0017](./adr-0017-header-and-dialog-look.md)は、転生の画面が1280×720の高さに収まらなくなったら見直すとしていた。

## 決定

1. 転生の画面は、画面の幅いっぱいのパネルを左右の列に分ける。左の列には周の結果と永続強化を、右の列には年代記・縛り・体のボタンを置く。体のボタンは2列2段に並べる。
2. 転生の画面の残りの記憶ポイントは、永続強化の見出しの行に置く。
3. メインの画面の中段は、仕事とスキル・体の状態・インプラントの3つの列に分ける。インプラントの列はログの横まで下に伸ばし、ログは仕事と体の状態の列の下に置く。ログの高さ（180）は変えない。
4. 列の幅に収まらない文は、ボタンでも列の幅で折り返す。対象は、仕事・ジンの依頼・インプラント・偽の身元・永続強化・体のボタン・転生の画面の説明の文である。
5. 数が多いボタン（仕事・ジンの依頼・インプラント・偽の身元・永続強化・選び直し）は、文字を14にし、上下の余白を4に詰める。
6. 縛りの選択肢は、いちばん長い項目の幅に合わせず、列の幅で切る。
7. 分岐図の話の名前は、名前の欄の幅で折り返す。段の箱の幅は、英語でいちばん長い段の名前が収まる210にする。

## 理由

ログの高さを守ったまま中段に高さを足せる場所は、ログの横しか無かった。中段の高さは、画面の高さから上の街の帯（140）とログ（180）を引いた356で決まる。インプラントは7つと偽の身元の8行あり、体の状態の列に積むと、この高さに収まらない。インプラントの列をログの横まで伸ばすと、使える高さは546になる。

体の状態の列は、周の始まりにジンの依頼のボタン・縛り・評判が並ぶので、いちばん高くなる。そのため3つの列のうち、体の状態の列をいちばん広く取り、仕事の列は狭くして折り返させる。仕事の列は、文が折り返しても高さに余りがある。

転生の画面を左右の列に分けたのは、1列に積むと、永続強化9つと体のボタンだけで高さが足りないからである。周の結果と年代記を上の段で左右に並べ、その下の段で永続強化と体のボタンを左右に並べると、上下の段で列の幅がそろう。

どちらの画面にもスクロールは残す。永続強化の選び直しのボタンが増えたときや、文の長い言語を足したときにも、画面の外に出たまま操作できなくなることは無い。1280×720で確かめた状態では、スクロールしなくても全体が見える。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ログの欄を低くして中段に高さを回す | [ADR-0016](./adr-0016-show-effects-on-screen.md)で、ログの高さは中段をスクロールにしてまで守ると決めている |
| 中段をスクロールのままにして、横幅のはみ出しだけを直す | 周の始まりからインプラントの欄が切れて見え、作者が見切れていると指摘した |
| 画面の文字をすべて小さくする | 仕事・体の状態・ログの読みやすさが下がる。数の多いボタンだけを詰めれば収まる |
| 転生の画面の体のボタンを横に4つ並べたままにする | 右の列の幅に4つ並べると、1つのボタンが狭くなり、文が4〜5行に折り返して高さが足りない |
| 永続強化の説明をボタンから外し、ツールチップだけにする | 排他の組や「取っている」の表示も消え、選ぶ前に分からなくなる |

## 影響

メインの画面の作り（`game/scripts/main.gd`）が変わる。インプラントと偽の身元は、体の状態の欄から外れて3つ目の列になる。ジンの依頼のボタンは、[ADR-0034](./adr-0034-choose-jin-request.md)のとおり体の状態の欄に残る。転生の画面と分岐図（`game/scripts/branch_chart.gd`）も変わる。セーブやゲームの進み方は変わらない。

## 見直しの条件

インプラントや永続強化の数が増えて、1280×720で欄の中のスクロールが要るようになったら見直す。言語を足して、文の長さがいまの英語より長くなったときも見直す。
