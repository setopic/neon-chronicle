# 人物のイベントは、まだ戻っていない断片の中身を先に明かさない

- 日付: 2026-10-20
- 状態: stable

## 背景

設計文書の点検で、記憶の断片より先に、人物のイベントが真相を明かしてしまう順があると分かった（issue #154）。断片は「白い部屋」「契約書」「名前」「計画書」「中枢サーバー」の順に戻る。

[ADR-0043](./adr-0043-mio-character-events.md)は、ミオの2段目で、ミオが読み込み先を書き換えたことを話すとしていた。2段目は「白い部屋」が戻れば起きるが、主人公だけがミオの診療所で目覚めていることは、4つ目の断片「計画書」で明かす。

レイの段には要る断片が無かった。1段目でレイは主人公も被験体だと言い、2段目で借金を消す契約書に「わたしも」署名したと話す。主人公が白い部屋で被験体として意識を移されたことは「白い部屋」で、契約書に署名したことは「契約書」で明かす。

[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)の不変条件は、断片で明かすことを断片より先に資料へ出さないとしていたが、イベントの文には当てていなかった。

## 決定

ADR-0043の新しく決めた5つのうち、4つはそのまま引き継ぐ。ADR-0043が引き継いでいたADR-0014の7つも、そのまま引き継ぐ。

1. ミオにも3段の人物のイベントを置く（そのまま）
2. 1段目は、代金を取らずに患者を診ている夜で、手伝うかを選ぶ（そのまま）
3. 2段目は「白い部屋」が戻ってから起き、聞くとミオが読み込み先を書き換えたことを話す（改める。下記の1）
4. 3段目は「計画書」が戻ってから起き、追跡から診療所をどう守るかを選ぶ（そのまま）
5. 1段目と3段目で選ぶと、資料「ミオ」に追記が加わる（そのまま）

この決定で、次のことを決める。

1. ミオの2段目の要る断片は「白い部屋」のままにする。ミオが話すのは、主人公の意識を抜いたのが自分たちで、自分は途中で計画を降りたことまでとする。読み込み先を書き換えて主人公を逃がしたことは、ミオの3段目の文で明かす。
2. レイの1段目の要る断片を「白い部屋」にする。
3. レイの2段目の要る断片を「契約書」にする。記憶の封じは、どの断片の文にも書いていないので、2段目の文に残す。
4. 資料「ネオン・シティ」の、被験体の出どころの追記は、「計画書」で出すまま変えない。借金で被験体を集めることは、どの断片の文にも書いていない。そのため、レイの2段目で先に分かっても、断片より先に明かすことにはあたらない。
5. 人物のイベントの文は、まだ戻っていない記憶の断片で明かすことを出さない。DOM-13の不変条件に足す。要る断片を持たない段にも当てる。
6. DOM-10の、ミオの「明かされるところ」を、明かす場所ごとに分けて書く。ミオが自分の記録を書き換えて、事故で死んだ技師になっていることは、画面に出さない。

## 理由

ミオの2段目で降りたことまでにしたのは、ミオの話が「白い部屋」の後に動き出す流れを残せるからである。2段目の要る断片を「計画書」にすると、2段目と3段目が4つ目の断片の後に詰まる。1つの周で進むのは人物ごとに1段までなので、3段目を見る前に最後の仕事へ進む人が出やすくなる。3段目は、研究部門が書き換えられた読み込み先を辿る話なので、書き換えを明かす場所として、もともと文の中身に合う。

レイの段に断片を付けたのは、文を変えずに順を直せるからである。1段目の「あなたも被験体でしょう」は、白い部屋で技師が被験体の意識を移すと話していたことを先に言っている。2段目の「わたしも、借金を消す契約書に署名した」は、主人公も署名したことを含む。レイの3段目が触れる中枢は、街の地図に最初から出ているので、断片は付けない。

不変条件をイベントの文に広げたのは、資料にだけ当てていたことが、今回の食い違いの原因だったからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ミオの2段目の要る断片を「計画書」にする | ミオの2段目と3段目が4つ目の断片の後に詰まり、3段目を見ないまま最後の仕事へ進む人が出やすい |
| レイの1段目の文から「あなたも」を外し、断片は付けない | レイが主人公に声をかける理由が弱くなる。断片を付ければ文を変えずに済む |
| レイの2段目から主人公の契約に触れる言い方を外し、被験体の出どころを「計画書」以後に移す | レイの2段目の頼みの理由が薄くなり、文と資料の追記を両方書き直すことになる |
| 被験体の出どころの追記を、レイの2段目でも出す | 同じことが資料「レイ」の追記ですでに分かる。2か所に同じ追記を置くことになる |

## 影響

[DOM-13](../20-domain/dom-13-character-events.md)の人物のイベントの一覧で、レイの1段目と2段目に要る断片を書き、ミオの2段目と3段目の中身を直す。不変条件に、イベントの文の決まりを足す。[DOM-10](../20-domain/dom-10-characters.md)の、ミオの「明かされるところ」を書き直す。[DOM-14](../20-domain/dom-14-city-and-people-profiles.md)には、被験体の出どころがどの断片の文にも無いことを1文で書く。

`game/data/events.json`のレイの1段目と2段目に、要る断片を足す。ミオの2段目の「白い部屋のことを聞く」の結果の文と、ミオの3段目の説明の文は、#136で書き直す。

## 見直しの条件

断片の戻る順を変えたら、人物のイベントの要る断片を見直す。レイの話が始まるのが遅すぎると感じられたら、1段目の文を書き直して要る断片を外すかを見直す。
