# 主人公の写しは廃棄した写しとして記録され、ミオは死んだことになっている

- 日付: 2026-10-20
- 状態: stable

## 背景

設計文書の点検で、ヨミ・システムズが何周も主人公に気づかない理由が足りないと分かった（issue #149）。

ヨミ・システムズの装置は、毎周、主人公の意識の写しを読み込み、同期で主人公の記憶を中枢サーバーの写しへ送り返す（[DOM-09](../20-domain/dom-09-consciousness-copy.md)）。ふつうの被験体は施設で目覚めるのに、主人公だけが毎周施設に現れない。気づかない理由として書いてあったのは、闇医者が部品を買うのはふつうだから、の1つだけだった（[DOM-20](../20-domain/dom-20-test-subjects-origin.md)、[ADR-0030](./adr-0030-test-subjects-and-bodies.md)）。研究部門が読み込み先を辿り始めるのは、断片「計画書」が戻ってからである（[ADR-0043](./adr-0043-mio-character-events.md)）。

DOM-09は、前の身元の口座をヨミ・システムズが凍結するとしていた。これでは、ヨミ・システムズが毎周、主人公の口座を扱っていることになる。

ミオにも穴があった。ミオは計画の技師から途中で降りたが、企業区画から下りる道は解雇だけである（[DOM-18](../20-domain/dom-18-resident-classes.md)）。計画の中身を知る技師が裏通りで開業しても追われない理由が無かった。

## 決定

1. ミオが読み込み先を書き換えたとき、主人公の意識の写しは、反復計画の記録の上で、壊れて廃棄した写しにされた。ヨミ・システムズの装置は、中枢サーバーの廃棄の領域にある写しを監視しない。同期も、廃棄の領域の写しへ送られる。DOM-09に書き、廃棄の領域を用語表に足す。
2. 研究部門が気づき始めるのは、記憶の断片「計画書」が戻ってからとする。計画の中身を含む記憶が廃棄の領域へ送られ、それを見つけた研究部門が、読み込み先を辿り始める。ADR-0043のミオの3段目は、この流れの後に起きる。
3. DOM-09の、クレジットが0に戻る説明を直す。前の身元の口座は体に結びつけて登録してあるので、体が倒れると凍結される。ヨミ・システムズは凍結に関わらない。これは[ADR-0060](./adr-0060-account-only-identity.md)の口座だけの身元に合わせたものである。
4. DOM-20の、ヨミ・システムズが気づかない理由に、主人公の写しが廃棄の領域にあることを足す。闇医者が部品を買うのはふつうだから、という理由は残す。
5. ミオは計画を降りる前に、自分の記録も書き換えた。記録の上では事故で死んだ技師になっているので、ヨミ・システムズに追われない。DOM-10のミオの隠された事情に書く。

## 理由

廃棄した写しにしたのは、主人公が施設に現れないこと、同期の記憶が届いていること、毎周読み込まれていることの3つを、1つの理由でまとめて説明できるからである。「計画書」の記憶が廃棄の領域に届いたことを、追跡の始まりにすれば、ADR-0043の3段目も変えずに済む。

ミオが自分の記録を書き換えたことにしたのは、主人公の写しを書き換えたのと同じ手で説明でき、DOM-18の階級の行き来の決まりを変えずに済むからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ヨミ・システムズは異常に気づいているが、どの被験体のどの写しかを特定できていない | 毎周の読み込みと同期の両方で主人公の写しを扱っているのに、特定できない理由を別に書く必要がある |
| 企業がわざと主人公を自由にさせている | [ADR-0009](./adr-0009-world-rationale-and-characters.md)が却下している |
| DOM-18に、計画を降りた技師は記録の上で死んだことにされる扱いを足す | 下層街へ下りる道が解雇のほかに増え、階級の行き来の決まりを直すことになる |

## 影響

DOM-09に、廃棄した写しの説明と、廃棄の領域の用語を足す。クレジットが0に戻る説明を直す。DOM-20とDOM-10に1文ずつ足す。数値と`game/`の文言は変えない。画面の文言は#136で確かめる。

## 見直しの条件

主人公の写しを研究部門が見つけたあとの話（エンディングや追跡の続き）を足すときに、廃棄の領域の扱いを見直す。
