# 体の元の持ち主から取ったのは神経の型とする

- 日付: 2026-10-20
- 状態: stable

## 背景

設計文書の点検で、体の元の持ち主の決まりでは部品が足りないと分かった（issue #148）。

[DOM-25](../20-domain/dom-25-body-former-owners.md)と[ADR-0040](./adr-0040-body-former-owners.md)は、体の種類ごとに、神経と腕の部品を同じ1人の死者から取るとしていた。元の持ち主は、周によって変わらない。一方で、ミオは毎周、新しい体を組み立てる（[DOM-20](../20-domain/dom-20-test-subjects-origin.md)）。1人の死者の神経と腕は1組しか無いので、毎周同じ人から取ることはできない。ADR-0040は「同じ組み立て方なら出どころも同じ」を理由にしていたが、組み立て方が同じでも提供者が同じになるとは言えない。

あわせて、[DOM-19](../20-domain/dom-19-resident-life-course.md)は体の部品を「インプラントと臓器」と定義していて、神経と腕の部品はこの定義に入らなかった。

## 決定

ADR-0040の6つのうち、5つはそのまま引き継ぐ。

1. 体の種類ごとに、元の持ち主を1人決める。元の持ち主は周によって変わらない（改める。下記の1）
2. 特性は元の持ち主の生き方が体に残した癖で、体の種類ごとの効果を持つ（そのまま）
3. 特性は乱数でも周番号でも決めず、体の種類に1つずつ固定する（そのまま）
4. 特性の効果は体の種類の効果に足し、スキルごとの経験は仕事で得る経験にだけ効く（そのまま）
5. 転生の画面の体の種類のボタンと、体の状態の欄に、元の持ち主と特性を出す（そのまま）
6. 元の持ち主と特性は、DOM-25に書く（そのまま）

この決定で、次のことを決める。

1. ミオが元の持ち主から取ったのは、神経や腕の組織ではなく、神経の型である。神経の型は、元の持ち主の神経から一度だけ写し取った、体の動かし方の手本である。ミオは神経の型を手元に持ち、体の種類を組み立てるたびに、新しい体の神経へ焼き付ける。そのため、毎周の体が別の部品でできていても、同じ元の持ち主の癖が残る。
2. 神経の型は体の部品に含めない。DOM-19の体の部品の定義（インプラントと臓器）は変えない。神経の型はDOM-25の用語表に定義する。

## 理由

神経の型にしたのは、元の持ち主を体の種類ごとに1人に固定する決まりと、元の持ち主の話を周をまたいで進める決まり（[ADR-0041](./adr-0041-former-owner-memories.md)）を、そのまま残せるからである。腕前の型を次の体の神経へ読み込む手順は、才能の継承として[DOM-09](../20-domain/dom-09-consciousness-copy.md)にすでにあるので、型を体の神経へ焼き付けることは、世界の決まりに合う。

体の部品の定義を変えなかったのは、元の持ち主から取ったのが部品ではなく型なので、定義を広げる理由が無いからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| ミオが前の周の体から神経と腕を回収して使い回す | 使い回すたびに傷むので、体の質の説明まで直すことになる |
| 元の持ち主を、その体の種類の部品の仕入れ先の筋とし、話も同じ筋の人々の記憶にする | DOM-25の話の書き方が大きく変わる |
| 体の部品の意味に、神経と腕も入れる | 元の持ち主から取ったのが型なら、定義を広げる理由が無い |

## 影響

DOM-25の定義と用語表を、神経の型で書き直す。元の持ち主・特性・話の数値と中身は変えない。DOM-19の体の部品の定義は変えない。

`game/`の文言には、元の持ち主から神経や腕を取ったと書いたものが無いので、変えない。

## 見直しの条件

元の持ち主の話に、遺体や部品そのものを扱う場面を足すことになったら、神経の型との関係を決め直す。
