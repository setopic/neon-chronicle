# 橋に人名を付け、地図を地形の分かる描き方にする

- 日付: 2026-10-19
- 状態: stable

## 背景

[ADR-0022](./adr-0022-city-map-in-game.md)は、ゲームの画面に街の地図を出し、区画を箱、橋を小さな箱、つながりを線で描くことにした。3本の橋は「北の橋・中の橋・南の橋」と方角で呼んでいた。

作者から、橋に名前があったほうが現実味があり、地図も実際の地図のように地形が分かる描き方がよい、という要望が出た（issue #61）。地図では企業区画が上、下層街が下にあり、橋は左から北・中・南と並んでいたので、方角の呼び名と地図の向きも合っていなかった。

## 決定

ADR-0022の決定のうち、橋の呼び名と地図の描き方を改める。ほかはそのまま引き継ぐ。

1. 区画と、高台と低い土地を3本の橋でつなぐこと、橋・闇市場の入口・裏通りの診療所・変電所・中枢サーバーの位置（そのまま）
2. 地図を「街と人物」の画面に置き、資料とタブで切り替える（そのまま）
3. 区画と橋は最初から見せ、中枢サーバーは記憶の断片「中枢サーバー」が戻るまで描かない（そのまま）
4. 名前と添える文を言語ファイルに書き、画像を用意しない（そのまま）
5. 地図を箱と線で描く（改める。下記）

3本の橋に、人の名前を付ける。北の橋はオルセン橋、中の橋はヴィラール橋、南の橋はハーゲン橋と呼ぶ（英語ではOlsen Bridge・Villard Bridge・Hagen Bridge）。どれも、企業が街を分け合うより前の時代に、その橋を架けた人の名前である。架けた人については、名前のほかは決めない。

高台の縁は崖になっていて、崖の下を下層街の排水路が流れる。3本の橋は、高台から排水路をまたいで下層街へ下りる。

地図は、上から見た地形として描く。高台と低い土地を色で分け、崖の縁に短い線を並べ、排水路を水の色の帯で描く。建物は小さな四角、下層街の通りと路地は線、屋台通りの屋台は小さな印で描く。区画の名前と添える文は、箱で囲まずに地図の上に置く。闇市場は地下にあるので、点線で囲む。裏通りの診療所と闇市場の入口は印で示し、添える文を印の横に置く。記号が何を表すかは、地図の隅の凡例で示す。画像は今までどおり用意せず、Godotで描く。

## 理由

人の名前にしたのは、名前を聞いただけで別の場所と分かり、方角の呼び名と地図の向きが合わない問題も無くなるからである。役割の名前（電線橋・検問橋・配給橋）も案に挙げたが、作者が人の名前を選んだ。

排水路を足したのは、橋が何をまたいでいるのかを地図に描くためである。崖だけだと、橋ではなく坂や階段でもよいことになる。

Godotで描くのは、ADR-0022と同じ理由である。言語を切り替えたときに、名前を言語ファイルから引いて描き直せる。外部の素材を使わないので、ライセンスの表記も増えない。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 役割の名前（電線橋・検問橋・配給橋） | 作者が人の名前を選んだ |
| 方角の呼び名のまま、描き方だけ変える | 名前があったほうが現実味がある、という要望に応えられない |
| 地図を画像で用意する | 言語ごとに絵が要る。外部の素材を使うとライセンスの表記も要る |
| 崖だけを描き、排水路を置かない | 橋が何をまたいでいるのかが分からない |

## 影響

DOM-15の橋の表と図を新しい名前にし、崖と排水路を書き足す。DOM-16は、描き方と描くものの表を改める。言語ファイルの橋のキーを`map.olsen_bridge`・`map.villard_bridge`・`map.hagen_bridge`に改め、排水路のキー`map.canal`と凡例のキー`map.legend.*`を足す。資料の「企業区画」と「下層街」の文も、新しい橋の名前で書く。

## 見直しの条件

DOM-15に区画や橋が増えたときは、地図の配置が収まるかを見直す。橋を架けた人を物語に出すときは、名前のほかに何を決めるかを見直す。
