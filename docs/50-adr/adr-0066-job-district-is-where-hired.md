# 仕事の区画は仕事を請け負う場所とし、イベントの舞台とは分ける

- 日付: 2026-10-20
- 状態: stable

## 背景

設計文書の点検で、仕事の区画とイベントの舞台が文書ごとにずれていると分かった（issue #151）。[ADR-0039](./adr-0039-job-districts-and-identity.md)とDOM-24は、運び屋の区画を屋台通りとしていた。一方でDOM-15は、裏通りを「運び屋の走る路地」と書いていた。

DOM-24は、仕事の区画を「その仕事をする場所」としていた。しかし、傭兵の仕事の間に起きるイベントには、「遺体の取り立て」や屋台通りの対立の2段目と3段目のように、下層街を舞台にしたものが多い。DOM-15は、運び屋のイベントである「ジンの忠告」を企業区画の行に挙げていた。中枢サーバーへの侵入はヨミ・システムズの縄張りでするのに身元が要らない理由は、ADR-0039の理由の節にしか書いていなかった。

## 決定

ADR-0039の6つのうち、5つはそのまま引き継ぐ。

1. 仕事ごとに区画を1つ持たせる。運び屋は屋台通り、ハッカーは闇市場、傭兵はヴァルデック義体の縄張り、中枢サーバーへの侵入はヨミ・システムズの縄張りとする（区画の意味を改める。下記）
2. 身元が要る仕事は、傭兵だけにする（そのまま）
3. 身元は、闇市場で偽の身元を300クレジットで買う（そのまま）
4. 偽の身元は周の終わりに失い、次の周には持ち越さない（そのまま）
5. 地図に、いまの仕事の区画を示す（そのまま）
6. 前の版のセーブで、傭兵に就いていた周は、偽の身元を持っていたものとして読む（そのまま）

改めるのは、仕事の区画の意味である。仕事の区画は、その仕事を請け負う場所とする。イベントの舞台は仕事の区画とは別に、イベントごとに決まる。傭兵が下層街を舞台にしたイベントに出会っても、そのイベントに身元は要らない。

身元が要る仕事は、仕事の区画が橋の向こうにあり、橋を渡って働く仕事とする。ハッカーと中枢サーバーへの侵入はネット越しにする仕事で、橋を渡らないので身元が要らない。このことをDOM-24に書く。

DOM-15の裏通りの説明からは、「運び屋の走る路地」を外す。DOM-15の場所の表の「出る仕事とイベント」の列は、「出る仕事」と「舞台になるイベント」に分ける。「ジンの忠告」は橋の表のオルセン橋にだけ挙げ、企業区画の行からは外す。

運び屋のミニゲーム（[ADR-0056](./adr-0056-courier-minigame.md)）で余りの歩数を交渉のレベルで増やすことは、変えない。説明の文も直さない。

## 理由

運び屋の区画を屋台通りのままにしたのは、運び屋のイベントが屋台通りの周りに集まっているからである。屋台への合成食の荷運び、ハーゲン橋の古い銘板、屋台組合の台帳がそうである。区画を移すと、`game/data/jobs.json`と地図の表示まで変わる。

区画を請け負う場所としたのは、仕事を請け負う場所とイベントの舞台が同じでなくてよいからである。傭兵はヴァルデック義体の縄張りで雇われ、雇い主の用で下層街にも出向く。イベントにも区画を持たせると、地図にどこを示すかがまた決まらなくなる。ADR-0039が仕事に複数の区画を持たせる案を却下したのと同じ理由である。

ネット越しの仕事に身元が要らないことをDOM-24に書くのは、身元が要るかどうかの決まりが、DOM-24の定義だけで読み切れるようにするためである。

ミニゲームを変えないのは、難しさを対応スキルで変えるという[ADR-0054](./adr-0054-minigame-frame.md)の決まりどおりで、遊びとしての筋が通っているからである。

## 却下した案

| 案 | 却下理由 |
| --- | --- |
| 運び屋の区画を裏通りに移す | 運び屋のイベントは屋台通りの周りに集まっている。`jobs.json`と地図の表示まで変わる |
| イベントにも区画を持たせ、傭兵の下層街のイベントには身元を要らないとする | 地図にどこを示すかが決まらない。コードとデータにも手が入る |
| 運び屋のミニゲームの説明の文に、交渉と結ぶ一言を足す | ADR-0054の決まりどおりで、遊びとしての筋は通っている |

## 影響

DOM-24の定義・属性の表・用語を、仕事を請け負う場所としての区画に書き直す。ネット越しの仕事は橋を渡らないので身元が要らないと書き足す。

DOM-15の裏通りの説明と用語から「運び屋の走る路地」を外し、場所の表の列を「出る仕事」と「舞台になるイベント」に分ける。

コード・データ・画面の文言は変わらない。

## 見直しの条件

イベントに場所を持たせ、地図に示したくなったら、イベントにも区画を持たせるかを決め直す。偽の身元を買うのが当たり前になり、迷う場面が無くなったら、値段か、身元の要る仕事を決め直す。
